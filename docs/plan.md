## 1. 自然な歩き方: 「お手本を真似させる」(方法 B)

### 1.1 何をお手本 (参照モーション) にするか

| 候補 | 中身 | 権利 | 手間 | 採用 |
|---|---|---|---|---|
| **① 生物学の歩容パターンから作る** | 動物の歩き方の研究で知られている「どの脚をどの順・どのタイミングで出すか」(位相差・接地時間の割合) と歩幅・足の上げ高さから、足先の軌道を計算で作る。トロット (対角の脚が同時)・ウォーク (1 本ずつ順番)・バウンド など | 事実・数値なので問題なし。自作 | 小 | **第 1 段階で採用** |
| ② 犬のモーションキャプチャー | 実際の犬の関節の動きの記録。研究 ([Peng et al. 2020](https://arxiv.org/abs/2004.00784)) で使われた方法 | よく使われるデータ ([AI4Animation](https://github.com/sebastianstarke/AI4Animation)) は **CC BY-NC 4.0 (非商用のみ)**。MIT のリポジトリに含められない | 中 | 保留 (使うなら非商用であることを明記し、リポジトリには入れない) |
| ③ 動物の動画から作る | 動画 → 動物の姿勢推定 (関節の位置を AI で検出) → 3 次元に復元 → ロボットの寸法に合わせる。単眼動画だけから学ぶ研究もある ([npj Robotics 2025](https://www.nature.com/articles/s44182-025-00048-x)) | **自分で撮影した動画**なら問題なし。他人の動画は不可 | 大 (精度・3D 復元が難しい。CPU だと遅い) | 第 3 段階の試験 (任意) |

→ まず ① で「動物らしい歩き方」を実現し、余力があれば ③ を「自分の家の犬や猫の動画から学ぶ」実験として試す。

### 1.2 お手本の使い方 (データの流れ)

```
歩容パターン (位相差・接地割合・歩幅・足の高さ)
   │  ① 足先の軌道を計算
   ▼
足先の軌道 (4 本 × 時間)
   │  ② 逆運動学 (既存の LegKinematics / legInverse) で関節角に変換 = ロボット用に「リターゲット」
   ▼
お手本の関節角 q_ref(φ)  … φ = 歩行の位相 (脳に入力しているリズム sin/cos と同じ)
   │  ③ 学習の評価に「お手本との近さ」を加える
   ▼
評価 = 課題の評価 (前進・ゴール) × w_task
     + お手本との近さ × w_imit
         ・関節角の誤差        exp(-k1 Σ (q - q_ref)²)
         ・足先の位置の誤差     exp(-k2 Σ |p_foot - p_ref|²)
         ・接地タイミングの一致  (お手本で接地している脚が実際に接地しているか)
         ・胴体の高さ・傾き
```

- お手本は「位相 φ ごとの姿勢」なので、脳は**リズムに合わせてお手本に近い動きをすると高評価**になる
- 速さ・曲がる量に応じてお手本の歩幅を変える (いまの TrotGait と同じ考え方) ので、曲がる・壁をよける課題とも両立できる
- 課題の評価も残すので、「お手本そっくりだが進まない」にはならない

### 1.3 いまの状態から続けて学習する (継続学習)

- **出発点**: いま一番できる脳 = 課題 4b (壁 1 枚) 第 100 世代 (曲がる・壁をよけるができる)
- **お手本の重みを少しずつ上げる**: w_imit を 0 → 目標値まで数十世代かけて増やす (急に変えると今の能力が崩れるため)
- **忘れ防止**: 1 世代の評価を「平地でお手本 + 曲がる + 壁 1 枚」の混合にする。
  さらに毎回、学習に使わないコース 12 個で「曲がる・壁 1 枚」の成功数を測り、下がったら重みを戻す (回帰チェック)
- 動画用には、第 1 世代 (ランダム) から「お手本あり」で学習した記録も別に作る (「最初からお手本を見せたらどうなるか」の比較)
  - 時間がかかるため任意

### 1.4 自然さの確認 (数値)

| 指標 | 内容 | 目安 |
|---|---|---|
| 対角脚の同時接地率 | トロットなら FL と RR、FR と RL が同時に着地している割合 | 高いほどトロット |
| 足の持ち上げ高さ | 遊脚の最高点 | 5〜8 cm (お手本と同程度) |
| 胴体の高さ | 平均と揺れ | 0.27 m 以上、揺れが小さい |
| お手本との誤差 | 関節角の平均誤差 | 学習前より小さい |
| 課題の成功数 | 初めてのコース 12 個 | 曲がる・壁 1 枚が下がらない |

## 2. 音声入りの動画 (VOICEVOX ずんだもん)

### 2.1 流れ

```
台本 (film-script.js) に「ナレーション文」を追加 (字幕とは別に、ずんだもん口調: 〜なのだ)
   ▼
VOICEVOX で 1 文ずつ音声 (wav) を作る  … 話者: ずんだもん
   ▼
音声の長さを測り、場面の秒数・字幕の表示時刻をそれに合わせる
   ▼
効果音: シミュレーションの「足が着地した瞬間」「転倒」「ゴール」を記録 → 自作の音を並べる
BGM   : 自作 (プログラムで合成)
   ▼
ffmpeg で 映像 + ナレーション + 効果音 + BGM を合成 (ナレーション中は BGM を小さく)
   ▼
最後の画面と README に「VOICEVOX:ずんだもん」
```

### 2.2 VOICEVOX をどこで動かすか

| 方法 | 内容 | 懸念 |
|---|---|---|
| A. このクラウド環境 | VOICEVOX エンジン (CPU 版) を入れて自動で作る | この環境から GitHub の配布ファイルを直接取得できるか未確認 (ページは 403)。**最初に試す** |
| B. 本人の PC | 台本からテキスト一覧を書き出す → 本人が VOICEVOX アプリで wav を作る → リポジトリに置く | 手作業が入る。ローカル接続すれば Claude が実行することも可能 |

### 2.3 規約 (ずんだもん)
- 商用・非商用ともに利用可。**「VOICEVOX:ずんだもん」のクレジット表記が必要** (表記しない商用利用は有料契約)
- 実装前に公式の規約 ([音源利用ガイドライン](https://zunko.jp/con_ongen_kiyaku.html) と VOICEVOX の利用規約) を再確認し、README に要点を書く

## 5. リスクと対策

| リスク | 対策 |
|---|---|
| お手本を重視しすぎて、曲がる・壁をよける能力を忘れる | 重みを段階的に上げる、混合評価、回帰チェックで下がったら戻す |
| お手本どおりに脚を動かしても、物理的にうまく進めない (滑る・転ぶ) | 課題の評価も残す。お手本の速さを物理で試して調整 |
| VOICEVOX をこの環境に入れられない | 本人の PC で音声を作る方法に切り替え |
| 学習が作業していない間に止まる | 再開機能 (RESUME=1) を使う。作業ツール管理の形で起動する |
| 動画から学ぶ実験の精度が低い | 任意の実験扱い。本編はパターンから作ったお手本で完成させる |

## 6. 決めていただきたいこと

1. お手本は ① (歩容パターンから作る) で始めてよいか。② 犬のモーションキャプチャー (非商用) は使わない方針でよいか
2. 歩き方の種類: トロットのみ / トロット + ウォーク (ゆっくりのときウォーク、速いときトロット)
3. 任意の作業 (2.6 ランダムからのお手本学習、4.1 自分の動画から学ぶ実験) をやるか
4. 動画 v3 の長さの目安 (いまの v2 は約 3 分)
