# Society 2.0（農耕社会）調査メモ ― 村から町・文字まで

作成日: 2026-10-07
直した日: 2026-10-09 (G6 を作るときに、7. と 9. の G6 のところを直した。直したところには、それぞれ注をつけた。G6_design.md の 24.)
目的: 新石器（Neolithic）に入ったばかりの小さな集団（大人3人・家1つ・植えたナッツの木 約59本・1季節=30日）を、
「農耕の村 → 町・記録（文字）」まで進めるための下調べ。工業化の前で止める。

## 0. この資料の使い方と注意

- ここに書くのは、考古学・人類学の「通説」（多くの研究者がだいたい認めている説明）です。
- 数字は「だいたいの目安」です。遺跡や地域によって、何倍も違うことがあります。
- 「(c) 到達の判定」の数字は、**すべてこの資料が提案する仮の値（仮定）** です。学問的に決まった値ではありません。
- 通説には反論もあります。とくに Graeber & Wengrow『万物の黎明（The Dawn of Everything）』(2021) は
  「農耕 → 余り → 不平等 → 国家」という一本道の考え方を強く批判しています（7章参照）。
- 用語メモ
  - **cal BC**: 放射性炭素年代を補正した「紀元前◯年」。ここでは単に「前◯年」と書きます。
  - **定住**: 1年中、同じ場所に住むこと。
  - **余剰（よじょう）**: 自分たちが食べる分より多くとれた食べ物。

## 1. 全体の流れ（通説のあらすじ）

| 時期（西アジアの例） | 何が起きたか | 代表的な遺跡・文化 |
|---|---|---|
| 前12500〜前9500年 | 狩猟採集民が定住を始める | ナトゥーフ文化（レバント） |
| 前9500〜前8500年 | 穀物の栽培が始まる。大きな共同建築 | イェリコ（PPNA）、ギョベクリ・テペ |
| 前8500〜前7000年 | 麦・豆・ヤギ・ヒツジが家畜・作物になる。村が大きくなる | PPNB の村々、チャタルヒュユク（前7100〜前6000年頃） |
| 前7000〜前6000年 | 土器が広まる。印章・トークン（粘土の数え札） | ハラフ文化 など |
| 前6500〜前3800年 | 灌漑農業、神殿、首長のような人 | ウバイド文化（南メソポタミア） |
| 前4000〜前3100年 | 都市・国家・大量生産・文字の誕生 | ウルク期（ウルク市） |

中国では、雑穀（アワ・キビ）と稲の栽培（前8000〜前6000年頃）→ 仰韶（ヤンシャオ）文化（前5000〜前3000年頃）
→ 龍山（ロンシャン）文化（前3000〜前1900年頃、城壁のある集落・格差）→ 二里頭（前1900〜前1500年頃、初期国家）
→ 殷の甲骨文字（前1250年頃）という流れが通説です。

## 2. G1 村ができる（人が増える・よそから人が来る）

### (a) 通説

- 定住すると、子どもが生まれる間隔が短くなり、人口が急に増えた。これを
  **新石器時代の人口転換（Neolithic Demographic Transition, NDT）** と呼ぶ（Bocquet-Appel）。
- 証拠は世界の約200の墓地。農耕が始まったあと、墓の中の「子ども・若者の骨の割合」が急に上がる。
  これは「生まれる子が増えた」しるしと読まれる。
- 理由の説明: 移動しなくなり、子を長く抱いて歩かなくてよい。穀物のおかゆで早く離乳できる。
  母親の体のエネルギーに余裕ができ、次の妊娠が早くなる。
- 増え方は「農耕開始から1000年以内」に強く出る。ヨーロッパ・北アフリカ・アメリカで似た形が見られる。
- 一方で、人が密集して病気（感染症）が増え、死ぬ人も増えた。だから長い目で見ると増加はゆっくり。
- 村は近くの集団からの移住・結婚で人を受け入れて大きくなった（ヨーロッパでは農耕民の移住が古代DNAで確認されている）。

### (b) 数字（シミュレーションのパラメータ候補）

| 項目 | 目安 | メモ |
|---|---|---|
| 出産間隔（移動する狩猟採集民） | 約3.5〜4年 | !Kung などの民族誌 |
| 出産間隔（定住農耕民） | 約2〜3年 | 早い離乳による |
| 女性1人が一生に産む子（合計出生率） | 狩猟採集 約4〜6人 → 農耕 約6〜8人 | 幅が大きい |
| 15歳までに死ぬ子の割合 | 約40〜50% | 狩猟採集民の平均で 約半分（Volk & Atkinson 2013） |
| 乳児（1歳まで）の死亡 | 約20〜30% | 同上 |
| 短期の人口増加率 | 年 0.5〜1%（ブーム期） | NDT の時期 |
| 長期の人口増加率 | 年 0.03〜0.1% | 病気・飢饉・争いで相殺 |
| 村の大きさ | 初期 数十人 → PPNB 数百人 → 大きい村 1000人前後 | チャタルヒュユクは 600〜800人説から 3000〜8000人説まで幅 |
| 村が分かれる目安 | 約150〜300人 | Dunbar 数 150、Bandy (2004) は「規則がないと約300人前後で分裂」 |

### (c) 到達の判定（仮定）

- 定住地で、**子どもが2人以上生まれて育っている**（1歳を越える）。
- **人口が 10人以上**、または最初の3人から **3倍以上**。
- **よそから来た人が1人以上**、仲間として住み着いている。
- 1年中、同じ家（または家の集まり）に住んでいる（移動の季節がない）。

## 3. G2 畑と家畜（麦をまいて育てて刈る・ヤギやヒツジを飼う）

### (a) 通説

- 西アジアの「最初の作物」: ヒトツブコムギ、エンマーコムギ、オオムギ、レンズマメ、エンドウ、ヒヨコマメ、亜麻。
  前9500〜前8500年頃に栽培が始まり、穂が落ちない「栽培型」になるまで1000〜2000年かかった（ゆっくりした変化）。
- 家畜: ヤギはザグロス山地（イラン、ガンジ・ダレ遺跡）で約1万年前に管理が始まった。
  若いオスを先に食べ、メスを残す「群れの管理」がわかる。ヒツジ・ウシ・ブタも前8500〜前7000年頃。
- ヤギ・ヒツジの乳は、前7千年紀にはザグロスで広く使われていた（土器の脂の分析）。
  毛や乳など「生きたまま使う」利用（Sherratt の「二次産品革命」）は前4千年紀に強まる、というのが通説。
- 中国: 北でアワ・キビ（前8000〜前6000年頃）、南（長江）で稲。家畜はブタ・イヌが中心。
- 農耕に頼ると、食べ物は安定するが、日照りや病気で一気に飢える危険もある（作物の種類が少ないため）。

### (b) 数字

| 項目 | 目安 | メモ |
|---|---|---|

| まいた種 : とれた量 | 1:5〜1:15 | 上の実験で 1:15（ヒトツブ）、1:8.5（エンマー）。悪い年は 1:3 以下も |

### (c) 到達の判定（仮定）

- **麦の「まく → 育つ → 刈る」を2年続けて成功**している。
- 収穫の一部を **次の年の種として残して** いる（種を食べてしまわない）。
- **ヤギかヒツジを 5頭以上**飼い、子が生まれて群れが増えている。
- 1年の食べ物の **半分以上（カロリー比）が畑と家畜** から来ている（採集・狩猟は半分未満）。

## 4. G3 余りと分業（毎日食べ物をとらない人が出る）

### (a) 通説

- 毎年少し多めに作る「ふつうの余り（normal surplus）」は、もともと不作に備えるためのもの（Halstead）。
  不作の年がなければ余りが残り、それが交換や祭り、職人を養うことに使われる。
- 西アジアの土器は前7000年頃から広まる（東アジアの土器はもっと古く、農耕より前から）。
- 最初の専門化は「季節の片手間」や「家ごとの得意」だった。フルタイムの職人は後に出る。
- 土器のろくろ（前4000〜前3500年頃、メソポタミア）、銅の精錬（前5000年頃）で、専門家の必要が増えた。
- ウルク期には「面取り縁の鉢（bevel-rim bowl）」が型で大量に作られ、働く人への配給の器と考えられている。
- 中国の龍山文化では、とても薄い黒色土器（卵殻陶）など、腕のいい職人の作品が出る。

### (b) 数字

| 項目 | 目安 | メモ |
|---|---|---|
| 余りの量 | 自家消費の 1〜1.5倍を作る | Halstead の normal surplus（量は仮定） |
| 専門家1人を養うのに必要な農家 | 約 5〜10世帯 | 前近代の農業で、全人口の 10〜20% が非農業というのが一般的な上限（仮定） |
| 土器作りの手間 | 鉢1個 成形数時間、乾燥数日〜1週間、焼成1日 | 民族誌の目安（仮定） |
| 土器が必要になる時期 | 乾季・冬で、家で煮炊き・保存するとき | |
| 季節の片手間 → 専任 | 村 数百人規模から | 仮定 |

### (c) 到達の判定（仮定）

- 1年の終わりに、**全員が1年食べても 20%以上余る** 食べ物がある（2年続けて）。
- **土器（または石器・布）を作る仕事を主にする人が1人以上** いて、その人は1季節のうち半分以上、食べ物をとる仕事をしない。
- 職人の作った物と食べ物の **交換（またはお礼の分配）が記録として3回以上** ある。

## 5. G4 持ち物と差（家の財産・土地・相続・貧富の差）

### (a) 通説

- 狩猟採集民の多くは食べ物を分け合う。でも畑や家畜は「手間をかけた人の物」になりやすい。
  とくに家畜・畑・家は **親から子に引き継げる（相続できる）** ので、差が世代をこえて大きくなる。
- Kohler ほか（2017, Nature）は、63遺跡の **家の大きさ** から不平等の度合い（ジニ係数）を測った。
  結果: 狩猟採集 約0.17 → 小さな農耕（園耕） 約0.27 → 大きな農耕社会 約0.35。
- 旧大陸（ユーラシア）では後の時代にさらに差が大きくなった（最大 約0.59）。
  理由として、牛や馬など大きな家畜がいたこと（耕す力・騎馬の戦士）が挙げられている。
- 墓の副葬品の差も目安になる。ブルガリアのヴァルナ墓地（前4500年頃）では、一部の墓に大量の金製品がある。
- ただし、チャタルヒュユクのように、大きな村でも家の大きさの差がとても小さい例もある（平等な村）。

### (b) 数字

| 項目 | 目安 | メモ |
|---|---|---|
| ジニ係数（家の大きさ） | 狩猟採集 0.17 / 園耕 0.27 / 農耕 0.35 / 最大 0.59 | Kohler et al. 2017 |
| ジニ係数の意味 | 0 = 全員同じ、1 = 1人が全部持つ | |
| 富の伝わりやすさ（親→子） | 狩猟採集・園耕は低い、牧畜・農耕は高い | Borgerhoff Mulder ほか 2009（Science）の比較 |
| 墓の差 | 副葬品の多い墓が全体の 5〜10% 程度に集中 | ヴァルナなどの印象からの粗い仮定 |

### (c) 到達の判定（仮定）

- **家（世帯）ごとに倉・畑・家畜の持ち主が決まっている**（共有ではない）。
- **相続が1回以上**起きている（亡くなった人の持ち物を子や家族が受け継ぐ）。
- 世帯ごとの財産（倉の穀物＋家畜＋家の大きさ を点数化）の **ジニ係数が 0.3 以上**。
- 最も豊かな世帯が、最も貧しい世帯の **3倍以上** の財産を持つ。

## 6. G5 リーダーと決まり（まとめ役・きまり・もめごとの解決）

### (a) 通説

- 人類学の古い段階分け（Service 1962）: バンド → 部族 → 首長制（チーフダム） → 国家。
  今は「一本道ではない」と批判されるが、大まかな目安としてよく使われる。
- **スカラー・ストレス（Johnson 1982）**: 話し合いに加わる単位（人や世帯）が増えると、決めるのが急に難しくなり、
  もめごとが増える。だいたい **6単位** をこえると、まとめ役（階層）を作るか、集団が分かれる。
- **Dunbar 数**: 人が顔と名前と関係を覚えていられる相手は 約150人。これをこえると、ルールや役職が必要になる。
- **Carneiro の囲い込み説（1970）**: 逃げ場（使える土地）が周りにないと、争いで負けた側が従うしかなくなり、
  首長制・国家ができやすい（ナイル川・メソポタミアの谷など）。
- ウバイド期（前6500〜前3800年）には神殿を中心にした村ができ、まとめ役がいたらしいが、家の差はまだ小さい。
  ウルク期（前4000〜前3100年）に、神殿や役所が人を働かせ、配給を行う「国家」ができたとされる。

### (b) 数字

| 項目 | 目安 | メモ |
|---|---|---|
| 決めごとの単位の上限 | 約6単位 | Johnson 1982 |
| 顔見知りの上限 | 約150人 | Dunbar |
| 村が規則なしで分裂する規模 | 約300人前後 | Bandy 2004 |
| 首長制の規模 | 数千〜数万人、2段階の集落（中心村＋周りの村） | Johnson & Earle、Wright & Johnson 1975 |
| 国家の規模 | 数万人以上、3〜4段階の集落の階層 | Wright & Johnson 1975（集落の階層の数で判定） |

### (c) 到達の判定（仮定）

- **世帯（または話し合いの単位）が 6 をこえた** あと、誰か1人が「まとめ役」に選ばれる/認められる。
- 村に **決まり（ルール）が 3つ以上** あり、破った人に **罰や償い** を実際に与えた例が1回以上ある。
- **もめごとを、まとめ役が裁いて解決** した例が 2回以上ある（村が分裂しなかった）。
- まとめ役が、**共同の仕事（倉・壁・水路）に人を集めた** 例がある。

## 7. G6 交易・町・記録（村どうしの交換・町・トークンから文字へ）

### (a) 通説

- **黒曜石（こくようせき）** の交易: アナトリア（トルコ）の黒曜石が、数百km 離れたレバントやザグロスまで運ばれた。
  チャタルヒュユクはカッパドキアの黒曜石を大量に使った（カッパドキアまでは、ふつう約190 km とされる。この数は確かめていない）。
  600 km より遠い東アナトリアの黒曜石も届いていた（Carter ほか 2008）。(2026-10-09 G6 を作るときに直した。G6_design.md の 24.)
- Renfrew ほか（1968）は、産地から離れるほど黒曜石の割合が規則的に減ることを示した
  （約300 km 以内を「供給地帯」とした）。減り方は、ある距離で急に落ちるのではなく、なだらか
  （割合の対数が、距離とともにまっすぐ減る形）。「約300 km」「石器の 8 割が黒曜石」という地帯の区切りには、民族誌のよりどころがない。
  (2026-10-09 G6 を作るときに直した。G6_design.md の 24.)
- 「村から村へ手渡しで運ばれた」という読みには、異論がある。手渡しだけで遠くまで届くのは、村と村が約100 km 離れているか、
  受け取った村が約9割を次の村へ渡すときだけ（模型での計算。Ortega ほか 2014、Ibáñez ほか 2015）。
  遠くに相手を持つ村もあるつながり（スモールワールド）や、親族どうしのつながりのほうが、よく合う。
  (2026-10-09 G6 を作るときに直した。G6_design.md の 24.)
- **トークン（粘土の数え札）**: 「前8000年頃から西アジアで使われ、形ごとに『穀物1かご』『ヒツジ1頭』などを表した」というのは、
  Schmandt-Besserat の読みと年代。較正年代では、トークンは前10千年紀（前1万〜前9千年ごろ）から出てくる。
  その多くは、いろいろに使える道具で、数えるのに使ったらしいのは一部の場所だけ（Bennison-Chapman 2018、2019）。
  (2026-10-09 G6 を作るときに直した。G6_design.md の 24.)
- Schmandt-Besserat の説: トークンを粘土の玉（ブッラ）に入れ、外にも押し付けて中身を示した →
  やがて玉をやめて粘土板に押すだけになった → 数の記号と物の記号に分かれ、**文字** になった。
  このうち、数の記号がトークンを押したあとから来たことは、広く認められている。物の記号（言葉を表す記号）が、形の込み入ったトークンから
  来たという点は、よりどころが弱い（Zimansky 1993、Michalowski 1993、Englund 1993、Kelley ほか 2024。Kelley ほかは、一部の物の記号は
  印の図柄から来たとする）。また、トークンは文字ができたあとも使われ続けた。(2026-10-09 G6 を作るときに直した。G6_design.md の 24.)
- 最初期の文字（原楔形文字）はウルク市の前3300〜前3000年頃。中身は、全体で約85% が役所の帳簿（穀物・家畜・労働者の配給）。
  ウルク IV 期の板はほとんど全部が帳簿で、ウルク III 期は約8割（Englund 2011）。(2026-10-09 G6 を作るときに直した。G6_design.md の 24.)
  ウルクは前3100年頃に、世界最大の町だったとされる。住んでいた人の数 4〜5万人は見積もり（Nissen 2003 は約4万人）。
  ただし、ウルクは最初の町ではない。北メソポタミアのテル・ブラク（LC2、前4200〜3800年頃）やハムーカルのほうが早い。
  (2026-10-09 G6 を作るときに直した。G6_design.md の 24.)
- エジプトでも前3200年頃に文字。中国の甲骨文字は前1250年頃（それより前の記号は議論中）。

### (c) 到達の判定（仮定）

- **別の村（AI の別集団でも可）と 4季節以上続けて交換** をしている。片道の距離は 1日歩く距離（約20〜30 km）以上。

## 8. 議論と不確かさ（正直に書いておくこと）

- **一本道ではない**: Graeber & Wengrow（2021）は、農耕が始まってもすぐに不平等や国家にはならなかった、
  季節ごとに平等と階層を切り替えた社会もある、と主張する。
  「穀物 → 国家」という矢印は決まっていない、という指摘。
  反論として「例外を強調しすぎ」「一般的な傾向（Kohler らのデータ）は否定できない」という書評もある。
- **James C. Scott『反穀物の人類史（Against the Grain）』(2017)**: 国家は穀物（数えやすく、税にしやすい）を利用した。
  初期の農民は狩猟採集民より健康が悪かった、という指摘。
- **NDT の証拠の弱さ**: 骨の年齢の推定は誤差が大きい。子の骨が多いのは「死亡が増えた」せいかもしれない、という反論もある。
- **人口推定の幅**: チャタルヒュユクは 600〜800人説と 3000〜8000人説がある。
- **トークン説**: 有名だが、トークンの形と文字の形の対応には疑問を出す研究者もいる。
- **地域差**: 中国・アメリカ・アフリカでは順序や速さが違う。土器は東アジアでは農耕より先にある。
- このシミュレーションは「ナッツの木」から始まっている。これは西アジアの麦より、
  縄文の栗やドングリ、アメリカ東部の木の実の利用に近い。木の実だけでは大きな余りは作りにくい（毎年の豊凶が大きい）
  ので、G2 で穀物か家畜を加えるのが通説に近い。

## 9. シミュレーションへの入れ方のヒント

考え方: **「世界のしくみ（ルールで自動に動く）」** と **「人が決めること（AI が役を演じて選ぶ）」** を分ける。
人が決めることは、なるべく「理由つきの選択」にする（例: なぜ種を残すのか）。

### G1 村ができる

- 世界のしくみ
  - 女性ごとに「次に産める時期」を持たせる。栄養がよく定住していれば間隔 2〜3年、移動・飢えなら 3.5〜4年。
  - 子は年齢ごとに死亡率（0歳 20〜30%、1〜15歳で合計 さらに 20%前後）。病気は人口密度で上がる。
  - 一定の確率で「よそ者が来る」イベント（食べ物が多い村ほど来やすい）。
- 人が決めること
  - よそ者を受け入れるか。食べ物を分けるか。誰と組んで家族を作るか。
  - 家を増やすか（家が足りないと出生間隔が延びる、などのルールでつなぐ）。

### G2 畑と家畜

- 世界のしくみ
  - 畑のマス: 「耕す → まく（秋）→ 育つ（冬〜春）→ 刈る（初夏）」。季節が合わないと失敗。
  - 収量 = 種の量 × 倍率（平年 1:8、よい年 1:15、悪い年 1:3 など乱数）。労働が足りないと減る。
  - ヤギ: 1年に1回出産（双子確率 40%など仮定）。草が足りない季節は弱る。乳は春夏だけ。
  - 倉の穀物は季節ごとに 1〜3% 減る（虫・ネズミ）。倉を良くすると減りが小さい。
- 人が決めること
  - どれだけ種に残すか、どれだけ食べるか。若いオスを食べるか育てるか。
  - 木の実・採集とのバランス（危険分散）。

### G3 余りと分業

- 世界のしくみ
  - 「土器」があると、貯蔵の損失が減る・煮炊きで食べ物の価値が上がる、など効果をつける。
  - 職人の技能は作るたびに上がる（専門化の得）。でも職人は食べ物をとる時間が減る。
- 人が決めること
  - 誰が職人になるか、職人に食べ物をどれだけ渡すか（お礼・交換）。
  - 余りを祭り（仲間づくり）に使うか、ためておくか。

### G4 持ち物と差

- 世界のしくみ
  - 倉・畑・家畜に「持ち主（世帯）」をつける。死んだら相続ルールで移る。
  - 毎年、世帯ごとの財産からジニ係数を自動計算して表示する。
  - 貧しい世帯は不作の年に借りるしかない → 借りがたまると差が広がる。
- 人が決めること
  - 分け合うか、自分の世帯のために取っておくか。貸すときの条件。相続の決まり（長子・均分など）。

### G5 リーダーと決まり

- 世界のしくみ
  - 「話し合いのコスト」= 単位の数の2乗に比例、など。6単位をこえると、もめごと発生率が上がる。
  - もめごとを放っておくと、一部の世帯が出て行く（村の分裂）。
- 人が決めること
  - まとめ役を選ぶか、誰にするか。決まりを作る・罰を決める・裁く。
  - まとめ役は共同作業（倉・壁・水路）を呼びかける。従うか逆らうかは各人が決める。

### G6 交易・町・記録

- 世界のしくみ
  - 別の村（NPC または別の AI 集団）を数km〜数十km先に置く。それぞれ得意な物（黒曜石・塩・土器）が違う。
  - 運ぶには日数がかかり、途中で失うこともある。
  - 「記録なしの貸し借り」は、時間がたつと覚え違い（量がずれる）が起きる → 記録の価値が生まれる。これは【仮定】で、よりどころのある説ではない。
    記録のきっかけとしてよく裏づけられているのは、倉の蓄え・そこからの取り出し・配給・村どうしの受け渡し
    （サビ・アビヤドの入れ物の封泥: Akkermans & Duistermaat 2004、アルスランテペの倉の 30 の印 (取り出す多くの人の印という読み): Frangipane ほか 2007、
    原楔形文字の配給の帳簿: Englund 2011。G6_design.md の 2. と 11.）。G6 では両方を使う（村の蓄えへの家ごとの出し入れも、貸し借りも、
    記録がなければ「覚え」の幅でしか分からない）。(2026-10-09 G6 を作るときに直した。G6_design.md の 24.)
- 人が決めること
  - 何をどれだけ交換するか。約束を守るか。
  - 記録のやり方（刻み・トークン・記号）を考え、使い続けるか。

## 10. 時間の縮め方（タイムスケール）

### 現実の長さ

- 定住〜栽培の開始: 約2000〜3000年（ナトゥーフ → PPNA）
- 栽培 → 家畜・本格的な村: 約1000〜2000年
- 村 → 首長・神殿（ウバイド）: 約2000〜3000年
- 首長 → 都市・文字（ウルク）: 約1000〜2000年
- 合計: 定住から文字まで **約8000〜9000年**（西アジア）。中国では約5000〜6000年。

### このシミュレーションの前提

- 1ステップ = 1季節 = 30日、1年 = 4ステップ（季節が4つの場合）。
- 1人の人生（約30〜40年）= 120〜160ステップ。そのままでは数千年は進めない。

### 提案（すべて仮定）

1. **2つの速さを使う**
   - 「ふつう」: 1ステップ = 1季節（30日）。日々の決定・もめごと・交易などの物語の場面。
   - 「早送り」: 1ステップ = 1年〜1世代（25年）。人口の増加・群れの増加・財産の偏りを式でまとめて計算する。
   - 早送りの間に起きた大事な出来事（飢饉・分裂・相続）は短い「年代記」にして AI に渡す。
2. **フェーズごとの目安の時間（ゲーム内）**
   - G1: 10〜30年（子が育つまで）。G2: 5〜20年。G3: 10〜30年。G4: 1〜2世代。G5: 1〜3世代。G6: 2〜5世代。
   - 合計 100〜300ゲーム年 ≒ 現実の 数千年 を「圧縮」して表す、と説明する。
3. **縮め方の原則**
   - 「生物の速さ」（妊娠・成長・収穫）は縮めない。縮めると不自然になる。
   - 「技術や制度が生まれるまでの待ち時間」（何百年も誰も思いつかない時間）を縮める。
     つまり、条件がそろえば、AI がすぐに工夫を思いつけることを許す。
   - 人口は現実の 1/10〜1/100 に縮める（現実の町 数千人 → ゲームの町 50〜200人）。判定の数字もそれに合わせる。
4. **世代交代**: 子が大人になって役を引き継ぐ。初代3人の「記憶」は、物語や決まりとして次の世代に残す
   （これ自体が G6 の「記録」の動機になる）。
