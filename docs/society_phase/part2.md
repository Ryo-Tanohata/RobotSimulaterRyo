## 4. 通説と比べて

通説どおりだった点
- 土器・石の鎌・作る人・四角い家・家ごとの倉・受けつぎが、この部のあいだにそろった (調べの 4. の「土器 → 毎日使う土器・鎌 → 作る人 → 家の倉 → 受けつぎ」)
- 差は小さいまま: 食べ物のほとんどは村の蓄えにあり、家の倉は村の蓄えの 5% ほど。人手で決まる農業では差が小さいという見方 (Bogaard, Fochesato & Bowles 2019) と合う。ジニ係数が高く出るのは、持ち物のある家が 2 つしかないため (G4.md の 4.)

通説と違った点
- **順番**: 現実では、四角い家と家ごとの倉 (PPNB) は土器より 1,500〜2,000 年早い。この世界では、鎌 → 土器 → 家族の住まい → 受けつぎ → 家の倉の順だった。人が「目の前の困りごと」(刈りきれない → 鎌、虫やネズミ → 土器、雨の夜に外で濡れる → 家) に一つずつ答えた順
- **速さ**: 現実のおよそ 1,700 年が、ゲームの中では 1 年半。計画 3. の「思いつくまでの待ち時間を縮める」による。G3 は、余りの年を G3 に入る前から数えたので 2 季節で終わった (G3.md の 4.)
- **印**: 調べの 4. にある「持ち主の印 (サビ・アビヤドの印章)」は、この世界にまだ仕組みがない

## 5. 次の部 (第 3 部 まとめ役と神殿、G5) に持ちこすこと

- 家族が 8 つで、Johnson 1982 の目安 (決める単位が 6 ほどをこえると難しくなる) をこえている。G5 のもめごとの見込みは 0.3 × 8 × 7 / 30 = 約 0.56 (祭りの季節は半分)
- G4 の夏、自分の家の畑のない 4 人がナギの家の畑を刈り、刈った草の種はみなナギの家の倉に入った。G5 の仕組みでは、これは「刈る」のもめごとのもとになる
- フウの家・アルの家・トワの家の代表は、家の大人の刈る量を 0 と答えた。刈る人は自分の家の畑から刈り、そのあとは畑の順に刈るので、順の最後のフウの家とアルの家の畑が刈られずに落ちた (トワの家の畑の残りと合わせて 約 3 万つかみ)
- 川辺の家は畑をまかず、家族の住まいもないので、家の倉を望んでも (セナは 4 季節とも望んだ) 食べ物は入らなかった
