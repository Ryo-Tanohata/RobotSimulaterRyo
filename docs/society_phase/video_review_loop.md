# 動画の見直しと直しの流れ (人のモデルの動画)

2026-11-25。本人「このように気になる所があったら任せますので、今回のように修正をお願いします。これは一連のワークフローにしたいです」
「修正を繰り返して終わらないことが考えられるので、その辺をどこで終わらせるか」→ 本人「そのおすすめで書類にまとめて進めて下さい」。

人のモデルで撮る動画 (S1V・G1 の F など。`sim/society/video/render_all.sh`) を、絵コンテ → 見直し → 直し、と回してから本番を撮る。
本人に聞かずに進めてよい。終わらせ方は 3. の決まりに従う。

## 3. 終わらせ方

- 直すために回すのは、**重いものだけ**。軽いものは一覧にして、送るときに書く。
- 次の **どれか** になったら、そこで直すのをやめて本番を撮る。
  1. 重いものがなくなった
  2. **3 回** 直した (1 回 = 直し + 絵コンテ + 見直し)
  3. 直しても、重いものの数が **減らなかった** (同じことのくり返しを防ぐ)
- 終わったときに重いものが残っていたら、それも書いて送る。続けるかは本人が見て決める。

## 4. 守ること

- 村のシミュレーションとデータ (state.json・記録) は変えない。直すのは絵の見せ方だけ。
- 前に撮った動画の見え方を変えない。新しい見せ方は印 (例 `PEOPLE_VIEW` の `v2`) をつけて、その動画だけで入れる。
- 記録にない所 (毎晩の焚き火・動物と植物の形と動き) を描きそえたときは、動画のクレジットに書く。
- mp4・画像・モデルはコミットしない (`app/.gitignore`)。絵コンテの json はコミットする。
- 村を回す作業と、動画を撮る作業は同時にしない (メモリが足りない)。
