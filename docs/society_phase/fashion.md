# 村の人の服の移りかわり (動画の人のモデル)

2026-11-25。本人「以前服を作ったのでそれを着せてください」「Society 1.0 に合わせた服装だったので、各時代や世代、フェーズに合わせてファッションも進化させてください」。

服は見た目だけのもの (村のシミュレーションには何も足さない)。どの服かは **村の記録** で決める: その時代に村が持っていた技術・材料 (テクノロジーツリーの記録)、その人の役・仕事、生まれた年 (世代)。
作り方: `sim/society/tools/human/people.py` の `tunic(sex, k, child, era)` と、時代ごとの印 `PEOPLE_ERA`。人のモデルは時代ごとに作る (`people_glb_<時代>`)。

## 1. 時代ごとの服 (材料と形)

| 時代 (ERA) | いつ | 記録の手がかり | 材料と形 | できている |
|---|---|---|---|---|
| hide | Society 1.0〜G1 (0〜10 年) | 狩りの獲物 (ルク) の皮。ヤギはまだ飼っていない | けものの生皮をそのまま: 灰色がかった茶、丈は短め (女はひざ下、男はひざ上)、すそはまっすぐ、細い紐でしばる | ○ (S1V・G1 の F) |
| leather | ヤギを飼ってから (G2〜) | ヤギの世話・ヤギの皮 | ヤギのなめし革: 明るい茶、女はすねまで、男はひざ、革紐の帯 | ○ (しくみ。動画はまだ) |
| leather + 印 | G6〜 (29 年に初めての家の印) | 家の印 (焼いた粘土) | 家の代表は、帯に家の印を紐で下げる | まだ |
| leather + 役のしるし | G7〜 (48 年 王と役所) | 王・役の人・まとめ役 | 役の人は、肩に色を変えた革の肩掛け | まだ |
| leather + 玉の飾り | G9〜 (119 年 赤い金属) | 銅をとかして玉や道具にする | 首に銅の玉の飾り (はじめは役の人と家の代表、のちに広がる) | まだ |
| leather + 書く道具 | G10〜 (151 年 字を読み書きできる人) | 読み書きできる大人 | 読める人は、腰に板と刻む道具を下げる | まだ |
| 作業の前かけ | G15〜 (199 年 水の作業場・燃える石) | 作業場・燃える石を掘る | 作業場や掘り場で働く人は、厚い革の前かけ。手と服に煤 | まだ |
| 布 | 「布を織る」が届いたら | テクノロジーツリーの「布を織る」(いまは届いていない) | 織った布の衣 (色を足せる) | 届いていない |

季節: 冬の季節は、だれでも毛皮の肩掛けを重ねる (まだ)。

## 2. 世代 (同じ時代の中のちがい)

- 新しい服や飾りは、**若い人から** 広がる: その時代のはじめは、その時代が始まったあとに大人になった人 (15 歳) が新しい服を着て、年寄り (55 歳から) は前の時代の服のまま。
- 子 (15 歳まで) は、大人の服を短くしたもの (丈はひざ上)。飾りは付けない。
- 赤ちゃん (2 歳まで) は、親が抱く包み。

## 3. フェーズと役 (人ごとのちがい)

| 記録 | 服や持ち物 |
|---|---|
| 家の代表 (G6〜) | 帯に家の印 |
| まとめ役・王・役の人 (G7〜) | 肩掛け (役の色) |
| 読める大人 (G10〜) | 腰に板 |
| 作業場・掘り場の人 (G15〜) | 前かけ・煤 |
| 外の仕事が多い人 | 日焼けが濃い (肌の色。服ではない) |

## 4. 決まり

- 服の時代は、その動画の撮る日々の記録で決める (動画ごとに 1 つ。長い動画で時代をまたぐときは、まだ 1 つ目の時代のまま)。
- 前に撮った動画 (D1V など) の見た目は変えない。
- 記録にない所 (形・色) を描きそえていることは、動画のクレジットに書く。
