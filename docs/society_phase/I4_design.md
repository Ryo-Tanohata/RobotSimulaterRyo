# Society 4.0 フェーズ 1 (読み書きと知らせ板) の設計

書いたのは Claude (2026-11-21)。本人の言葉は「お任せします。基本的にあなたに任せますのでフェーズを進めて下さい」(おすすめで進める)。
コードの名前は **i4** (`sim/society/i4.py`・印 `state.era2.g7.i4`・止まりの文の「I4:」)。`s4` (Society 3.0 フェーズ 2 分業と町) とは別。
人が読む所 (年報・この文書) では **Society 3.0 フェーズ 3 (読み書きと知らせ板)** と呼ぶ (2026-11-21 に呼び直した。下の注)。数はみな【仮定】(作る側が決めた数)。

## 0. ひとことで

- 日本の区分で Society 4.0 は情報社会。情報社会の入口を、この村の道具 (音の字・粘土の板・帳) で言いかえると、
  **「字で書いたことが、会わない人にも、同じ形で、たくさんの人に届く」** こと。いまの村では、話は 1 人から聞いた人へ (覚えて 8 つまで) しか届かない。
- これまでで分かったこと (S3・S4 の check):
  1. 村の人は **返りがお題に見えるものを選ぶ** (作業場)。
  2. 村の人は **食べ物を先にする**。食べ物の仕事から人を外へ出す道 (町の家) は、3 年聞いても 0 家だった。
- だから 4.0 フェーズ 1 は、**食べ物の仕事から人をあまり外さずに** 字の得が見える形にする:
  1. **a 知らせ板**: 年の集まりで、答える人は村の知らせ板に知らせを 1 枚書ける (家に読める大人がいるとき)。知らせは村のみなのお題に出る。
     ただし **中身が読めるのは、読める人と、家に読める人がいる人だけ**。読めない人には「N 枚ある。中身はわからない」とだけ出る。
  2. **b 子に字を教える (手習い)**: 読める大人は、仕事「字を教える」を選べる。その日、キャンプにいる 10〜14 歳の子 (その人の家の子が先、のこりは村の子) を 6 人まで教える。
     子は教わった日が 30 日で読み書きできるようになる (大人になると読める大人に数える)。大人が「字を習う」日に、その日「字を教える」人がいれば、2 日分進む。
- **後押しはしない**。どれも「してもよい」道。印・本人の言葉・「作る側」・物差しのことは、お題にも出来事にも出さない。
- 時代 (state の era) は G15 のまま。G15・S3・S4 の世界の仕組み (作業場・燃える石・持ち場・掘り場・町の家・町の市) はそのまま動く。
  **S4 の止まり (相談・入口) と、S4 の年の集まりの節は、i4 の印で閉じる** (S4 は 224年の終わりで閉じた。`S4_check.md` 10.)。

## 1. ほかの案と、これを選んだわけ

| 案 | 中身 | とらなかったわけ |
|---|---|---|
| A. 便り (近い集落へ手紙を運ぶ人) | 読める人が集落へ行き来して、値や蓄えを知らせ合う | 運ぶ人は食べ物の仕事から外れ、得 (交換が少しよくなる) は小さい。S4 で交換は 9 年 0。フェーズ 2 の候補にする |
| B. 帳を「読める人しか見られない」にする | いまお題に出ている数を、読める人だけに見せる | いま見えている数を隠すと、村の人の選びの土台 (蓄えの量など) が急に変わる。前の歩とくらべにくい |
| C. 学び舎の建物を建てる | 板で建物を建て、そこで教える | 建物を数える物差しを作る側が決めることになる。まず「教える日」だけで見る |
| **D. 知らせ板と手習い (この案)** | 一人が書くと、読める人みなに同じ形で届く。読める人を増やす道は、子に教える (大人の畑の日をほとんど減らさない) | 「読めると知らせが分かる」という得がお題に見える。食べ物を先にする村の選びとぶつからない |

## 2. 印と入り方

- 印: `state.era2.g7.i4` = `{day, words, why, start_year, adults0, pop0, board, kids, rows, f, used, …}`。書くのは次のコマンドだけ:
  ```bash
  python3.13 sim/society/step.py resume --i4 "<本人の言葉>"
  ```
  - できるとき: S4 の印がある・26999 日目 (224年の終わり) から・1 回だけ、そして **S4 の相談で止まっている** (`HOLD consult` でわけが「S4:」で始まる) か **止まりがない**。
  - ほかのときは「resume --i4 はできない: … (何も変えない)」(終わりのコード 3)。`--i4` は `resume` だけ (ほかの `--s4*`・`--s3*`・`--push` とは一緒に書かない)。
  - 印を書くと: 止まりを解く・`g7.s4.closed = 日` を書く (S4 の止まりと S4 の節を止める)・この歩のお題を、答えがまだなければ印のあとの形で書き直す。出来事には何も残さない。
- 数えるのは、印の次の暦の年 (225年) から。
- **印がなければ `i4.py` は読みこみもしない** (`g7`・`g15`・`g10`・`step.py` は「i4」の鍵があるときだけ関数の中で読みこむ)。前の歩は 1 バイトも変わらない。
- S4 の `closed` があるとき: `s4.check` は止まりを返さない・`s4.block_lines` (お題の S4 の節) は出さない・S4 の答えの欄 (`town`・`pit`) はお題の欄の宣言から外す。
  S4 の年の行 (f1〜f5) は年報のために数えつづけてよい (止めない)。町の家・掘り場・町の市の世界の決まりは、そのまま (もう人がいなくても動く)。

## 3. 2 つの部分 (`i4.py`)

### 3.1 a 知らせ板

| こと | 決まり【仮定】 |
|---|---|
| 書き方 | 答えの欄 `notice`: `"<知らせの文>"` (60 字まで。null なら書かない)。年の集まりの答えと、季節の答えのどちらでもよい |
| 書ける人 | 答えた人の家に、読める大人 (`g10.readers`) がいるとき。いなければ「できなかったこと」に「字を書ける人がいない」 |
| 数 | 1 家 1 季節 1 枚。板にのるのは新しいほうから 12 枚。1 枚は 4 季節 (1 年) で消える |
| 書いた日 | 書いた家の読める大人のうち 1 人 (名の順でいちばん前) が、その季節のはじめの 1 日を「知らせを書く」にする (その日の仕事の 1 日を使う) |
| 出来事 | 「知らせを書く」: 「〇〇の家の X が、村の知らせ板に知らせを書いた」(中身は出来事に書かない) |
| お題の節 | 大人みなのお題に `## 村の知らせ板` (上のほう)。<br>・読める人: 板の知らせを全部 (書いた家・季節・文)。<br>・読めないが家に読める大人がいる人: 全部 + 「家の X が読んで聞かせた」。<br>・どちらでもない人: 「知らせが N 枚ある。字が読めないので、中身はわからない (家に読める人がいない)」。<br>板が空なら「知らせ板に知らせはない」の 1 行 |
| 欄の宣言 | `notice` を、印のあとのお題の答えの形に足す (書かない言葉は使わない。例は「冬の前に土器のふたを見なおそう」のような村の言葉) |

- 知らせの中身は世界の決まりを何も動かさない (話 `say` と同じく、言ったこと)。村の人がそれを読んで選ぶかどうかが、見たいこと。
- 知らせを読んだ人が、話・掟・知識で中身を使ったら、`used` に数える (知らせの文から 6 字以上が同じ・知らせを出した季節から 4 季節のうち)。物差しだけ。

### 3.2 b 手習い (子に字を教える)

| こと | 決まり【仮定】 |
|---|---|
| 仕事 | 「字を教える」(季節の仕事。読める大人だけ選べる。読めない人の答えは「できなかったこと」) |
| 1 日 | キャンプにいる 10〜14 歳の子を 6 人まで教える。順: 教える人の家の子 → 村の子 (教わった日の多い順、同じなら名の順)。1 人の子は 1 日 1 回だけ |
| 子の進み | `g7.i4.kids{名: 日}`。30 日で `g10.readers[名] = 日` (読み書きできる)。15 歳になると、そのまま読める大人に数える |
| 大人の「字を習う」 | その日、キャンプで「字を教える」人がいれば、習う日が 2 日分進む (ふだんは 1 日分)。教える人 1 人につき大人 2 人まで |
| 出来事 | 「字を教える」: 「X が、子 N 人に音の字を教えた」/ 子が読めるようになったとき「Y (子) は、音の字を読み書きできるようになった」 |
| お題 | `## 字` の節 (なければ新しく): 読める大人の数・名 (いまと同じ)・**字を習っている子と大人 (残りの日)**・「字を教える」を選べること (読める大人のお題だけ) |

- 子は答えを書かない (いまと同じ)。教えるかどうかは、読める大人 (答える人か、答える人に割り振られた人) が決める。

## 4. 物差し (お題には出さない。【シ】)

年の終わり (印の次の年から) に `g7.i4.rows[y]` を書く:

| 鍵 | 中身 | 線【仮定】 | いま (224年) |
|---|---|---|---|
| i1 | 読める大人 / 大人 | 25% 以上 | 25 / 356 = 7% |
| i2 | 知らせ板: この年の知らせの数と、書いた家の数 | 6 枚以上・4 家以上 | 0 |
| i3 | 字の仕事の人日 (字を習う・字を教える・知らせを書く・帳をつける・記録をつける) / 働いた人日 | 4% 以上 | 約 0.6% |
| i4 | 安全: ききん 0・蓄えのいちばん少ない日 120 日分以上・人が印のときの 95% 以上 | みな | ○ |

- **入口**: 新しいほうから 2 年続けて i1 と i2 と i3 がそろい、その 2 年に i4 が割れていない → `HOLD entrance` (わけ「I4: 入口 …」) を 1 回。
- **相談** (`HOLD consult`。わけは「I4:」で始まる):
  - i4 が割れた年の終わり。
  - 知らせ板・字を教える・字を習う を選んだ人が、2 年続けて 0 人。
  - 印から 5 年ごと。
- 読み書きできる人が 1 人以下になったときの G15 の止まり (`READERS_STOP`) は、そのまま。

## 7. 呼び名を直した (2026-11-21、227年の終わり)

- 村の動きは何も変えない。変えたのは人が読む呼び名だけ (`i4.I4_LABEL`・年報の節の見出し・225/226年の年報)。
  印 `g7.i4.why` に入った文 (`i4.I4_NAME`「Society 4.0 フェーズ 1 …」) は、前の歩の state と同じにするため変えない。コードの名前 i4 も変えない。
