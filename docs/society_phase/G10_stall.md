# G10「鉄と広い国」が止まっている理由 (しらべ。2026-11-05)

本物の村 (sim/society/data) は 16079 日目 (134年の年の集まり。お題は出ていて、答えはまだ) で止まっている。
G10 に入ったのは 14279 日目 (119年の年の集まり)。この 15 年、黒い金属 (c1) と字 (c2) の道がほとんど進んでいない。
そのわけを、コードと data を読むだけで調べた (data には書いていない。step.py は `status` だけ回した)。

年の数え方: 年 = (日 + 1) ÷ 120。年の集まりの日は 120 × 年 − 1 (119年 = 14279 日目、122年 = 14639、127年 = 15239、134年 = 16079)。秋の集まりは その 30 日あと。

## 0. みじかい答え

- **字 (c2) は「村の人が選ばなかった」のではなく「仕組みが知らせていなかった」。** 「音 1 つに字 1 つ」[H9-02] を試せるのは、この便りを「知っている人」だけ。
  いま知っている大人は 5 人 (アコ19・キサ16・セオ14・ハソ21・ムイ21) いるが、15 年のあいだ、お題でだれにも「あなたは知っている (try に "H9-02")」と出ていない。
  知らない 2 人 (タユ31・シエ33) が試そうとしたが、2 回とも何も言われずに 30 日「休む」に変えられた。
- **黒い金属 (c1) は 127年のあと「答える人がいない」ので止まった。** 作れるのはケセ19 だけ。ケセ19 の家 (ハソ3の家) が「見本の家」(お題に答える家) だったのは 125〜127年の 3 年だけで、
  128年から見本から外れた。外れた家は、ほかの見本の家の仕事をまねるだけで、まねた先で「黒い金属を作る」を選んだ家は 1 つもない。だから 128〜133年の鎌は 0 本。
- 128年からの「鎌を作る」という答えは、みな **石の鎌** (仕事「道具づくり」) で、黒い金属の話ではない (村の人の選び)。
- c3 は村の外のことで、いまは北の大きな村 N83 が段 3・10 集落 (地域 23 集落)。届くには段 4 以上で 12 集落以上が要る。

### 字はだれが試せるか (0 人の読める人から始められるか)

- 「字を習う」は、村に読み書きできる人がいないと選べない (g10.py 163〜166・432〜438。g7.py 584〜586 でちがえば「休む」)。いまは 0 人なので、だれも習えない。
- 始める道は 1 つだけ: 知っている人が「試す」(try "H9-02") を、進み 200・2 年分 続ける (hint_cards.json の H9-02 `try {days: 200, years: 2}`)。
  試し終わると、試した人が読める人になる (g10.py 289〜294)。知らない人は、知っている人と同じ日に一緒に試せば (with)、次の季節から知っている人になる (hints.py 482〜518)。
- 知っている大人 5 人のうち、セオ14 (ニイ2の家の代表) は 14639〜14909 日目 (122〜124年) と 15959・16079 日目 (133・134年) に答えている。キサ16 も 119〜120・126〜128年に答えている。
  でも、お題では自分が知っている人だと分からない (「## よその便り」が出ず、覚えていることにも H9-02 はない)。
- つまり **始める道はあるが、それを使える人に知らせていない**。

## 3. ケセ19 はなぜ 127年のあと作らなくなったか

ケセ19 の季節ごとの仕事 (`records/season_person.jsonl`、P591、家は H37 = ハソ3の家):

- 119年冬・春 (14369・14399 日目): 「試す」を 60 日。**自分で選んだのではない**。見本でない家なので、手本の家 H96 (テナ29 の家) の仕事をまねた。
  テナ29 は知らない人なので休んだが、まねたケセ19 は知っている人なので本当に試せた (g7.py 1420〜1430 `_fit`)。黒い金属の始まりは、この偶然。
- 120〜124年: 手本の家の仕事をまねて、畑仕事・土器づくりなど (試すは 0)。
- **125〜127年: ハソ3の家が見本の家になり、ケセ19 が代表として答えた。** 自分で試すを選び、126年の冬の終わり (15209 日目) にできあがった。
  127年の秋と冬に「黒い金属を作る」を 60 日 (「黒い金属の作り方を知っているのは村でわたしだけ。村にまだ1本もないので…」) → 鎌 3 本。
  127年春は自分で「畑仕事」(草取り) を選んだ。ケセ19 の覚えていること: 「秋は畑にまき、黒い金属の鎌を作りためるのがよい」(続ける気はあった)。
- **128年から見本の家から外れた** (見本は 3 年で入れかわる。g7.py 1105 `SAMPLE_YEARS = 3`・1201。sample_hist のハソ3の家 = 15359 日目)。
  そのあと 128〜133年 (15389〜16079 日目) はずっと「見本から広げた」= 手本の家 (H17・H69・H90・H29・H16) の畑仕事・狩り・土器づくりをまねた。お題は 1 度も出ていない。
- 「必ず見本に入れる家」は、まとめ役の家・小さい組の家・役の人の家だけ (g7.py 1206)。役の仕事は「記録をつける・取り立てる・守る・戦に出る」だけで、試す・黒い金属を作るは入らない (g7.py 29)。
  だから、ただ 1 人の作れる人の家も、ふつうに外れる。決まりの村の確かめ (G10_check.md 49 行) でも「試した 1 人の家が見本から外れて、だれも作れなくなった」と書いてあり、
  束 G10B1 では「知らない人を一緒に (with) 試させる」でよけていた。本物の村の仕組みは直していない。

### 作り方が広がる道はあるか

- 道はある: 腕のない人が、作れる人 (ケセ19) と **同じ日に** 「黒い金属を作る」をして、with にケセ19 を書くと、次の季節から作れる人になる (g10.py 100〜122)。
- でも、ケセ19 は答えないので、同じ日に作ることがまずない。代表が「黒い金属を作る・with ケセ19」を選ぶと、答えは通る (g7.py 584 の確かめは with を見る) が、
  その日にケセ19 が作っていなければ「黒い金属の作り方が分からず、休んだ」になる (g10.py 108〜113)。
- ケセ19 が作るのは、ちょうどハソ3の家の手本の家の代表が「黒い金属を作る」を選んだときだけ (まねるとき with は消える。g7.py 1415〜1418。ケセ19 は作れる人なのでまねられる)。
  代表はどの家が自分をまねるか知らない。偶然にたよる道で、15 年で 0 回。
  (いま 134年のハソ3の家の手本は ニイ2の家 = セオ14 の家。セオ14 が「黒い金属を作る・with ケセ19」を選べば、ケセ19 もまねて作り、セオ14 も作れる人になる。ただし偶然。)
- 作れる人の一覧 `g7.g10.smiths` は 0 人。H9-01 を知っている大人もケセ19 だけ。ケセ19 は 45 才。ケセ19 が死ぬと、「黒い金属を作る」は仕事の並びからも消える。
- 量の目安: 133年は 3 本で 84 人日 (1 本 1 年 約 28 人日)。c1 には この年なら 2,861 の半分 = 約 1,430 人日、つまり 黒い金属の鎌が 約 50 本 要る (1 本 20 人日なので 約 1,000 人日の働き)。
  ケセ19 1 人が 1 年じゅう作っても 6 本ほど。作れる人を何人もふやさないと、c1 はとても遠い (束 G10B1 でも 11〜12 年目)。

## 5. 直し方の案

どれも、まだしていない (本人が決める)。「前の日がそのままか」は、すでにある答えで回し直したとき、state が 1 バイトも変わらないか。

1. **お題に「知っている人」の名前を出す (いちばん小さい)**
   - g10.py 404 の行に「この便りを知っている人: セオ14・ハソ21・…」と書く。知っている本人のお題には「あなたはこの便りを知っている (試すなら try に "H9-02")」を出す
     (hints.text の 3 年の枠とは別に、G10 の札だけ)。黒い金属の行の「作れる人」と同じ形になる。
   - 変わるもの: G10 のお題の文だけ。state・乱数は変わらない。前の日は、残っている答えで回すので state はそのまま (お題の試し B_Prompts は G10 の日だけ変わる)。
     16079 日目のお題はもう出ているので、書き直す必要がある。
   - これで字は「選べば始まる」状態になる (セオ14 とハソ21 は同じ見本の家なので、家族の 2 人で試せる)。
2. **知らない人の「試す」「黒い金属を作る」を休むに変えたとき、わけを残す**
   - g7.py 581〜586 で、出来事 (例「タユ31 は、その便りを知らないので試せず、休んだ」) を残し、次のお題で本人に見えるようにする。
   - 変わるもの: 出来事が足される (state が変わる)。前の日をそのままにするには、直した日より前は出さない (「○日目から」の形)。
3. **作れる人・試している人の家を、見本の家に必ず入れる**
   - g7.py 1206 の must に、G10 の作れる人 (g10.smith) と、開いた札を試している知っている人の家を足す (ROLE_ACTS は変えない)。
   - 変わるもの: 見本の家の選び (乱数の使い方もずれる) → 次の年からの state が変わる。前の日をそのままにするには、直した日より後の年の選びからだけにする。
   - これで、ケセ19 がお題で毎年「黒い金属を作る」を選べ、ほかの代表も「with ケセ19」で日を合わせやすくなる。
4. **弟子の仕事 (教える) を足す**
   - 例: 作れる人が「黒い金属を作る」をする日は、同じ家の大人で「黒い金属を作る」を選んだ人は with がなくても習える。または、作れる人の with に書かれた人を、その季節は一緒に作らせる。
   - 変わるもの: 仕組み (新しい決まり)。前の日をそのままにするには「○日目から」。c1 には作れる人が何人も要るので、3. と合わせないと効きにくい。
5. **字を、知らない人も試せるようにする**
   - 便りは G10 に入る前に忘れられたが、G10 のお題には全員に「音の字は村で試せる」と出している (g10.py 384)。そこで G10 の札だけ、だれでも試せることにする。
   - 変わるもの: 仕組み。決まりの文と食いちがわなくなる。前の日をそのままにするには「○日目から」(過去 2 回の休むはそのまま残る)。
6. **このまま G10 を閉じる**
   - 「本物の村では、見本の家と知らせ方のせいで、鉄と字の道がほぼ閉じていた」と記録して閉じる。何も変えないので、前の日はそのまま。
   - ただし、c2 が届かなかったのは村の人の選びではない (仕組み) ことを、閉じる記録に書くべき。

おすすめ: まず 1. (お題だけ。state は変わらない) と、道の見張りの数え方の見直し (答える人に知っている人・作れる人がいるかで数える)。
c1 も進めたいなら 3. を「○日目から」で足す。それでも c1 は 50 本ほど要るので、15 年では届かないかもしれない (6. も合わせて考える)。
