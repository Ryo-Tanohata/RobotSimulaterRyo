# G8 の入口の設計 (下書き): 外から押す世界

書いたのは Claude (2026-10-24)。本人の決め (2026-10-24): G8 の入口は「村の外から押す世界で回す」(研究のまとめ `docs/research/state_emergence_C.md` 6. の 1)。
この文書は下書き。8. の問いに本人が答えてから、コードを書く。

## 0. なぜ「外から押す」か (研究からわかったこと)

- 国 (決める段 3) への道は、「求める・求められる」から始まる (A1: 村が求めないと 20%、求めると 90〜98%)。
- 今の LLM の代表 (sonnet・opus) は、豊かな村では自分から求めず、税・罰・役の人も作らない (B・本物の G7・C の 20 年で 0)。
- 村は、まわりの集落よりずっと大きい (村 約 200 人・まわり 1 集落 約 30 人)。まわりの決まりは「届く中でいちばん弱い所に、1.5 倍強ければ求める」なので、**だれも村に求めてこない** (A1: 村が求められたのは 1.7% の回だけ。C の 20 年で 0)。
- だから、村が自分から動かなくても、外から「求められる」「苦しい年が来る」世界にすると、村がどう答えるか (払う・戦う・助けを頼む・まとまる) を見られる。

## 1. G8 の名前と条件 (案)

もとの計画 (`society2_extension_plan.md`) の G8 は「遠くとの商いと国どうしのやりとり」で、村が国になったあとの段だった。村は国にならずに G7 を閉じたので、次のどちらかにする。

- **案 A (おすすめ): G8 を「外からの押し」にする。** 条件は G7 と同じ 3 つ (決める段 3 に村がいる・取り立ての記録 2 年・書いた罰の掟で裁く)。F も G7 と同じ 6 つ。世界だけを変える。もとの G8 (遠くとの商い) は G9 にずらす。
  - わけ: 研究で測った「国が生まれるか」を、押しのある世界で続けて測れる。G7 との差は世界だけなので、くらべやすい。
- 案 B: G8 はもとの計画どおり (遠くとの商い)。押しは G8 の世界に足すだけ。国の条件は持ちこさない。
- 案 C: G7 を「第 2 回」としてやり直す (名前は G7 のまま)。

## 2. 押しの仕組み (案)

### 2.1 強い集落 (おすすめ: 入れる)

- 村から届く所 (2〜4 ます) に、**村より強い集落を 1 つ置く** (人は村の 1.5〜2 倍。段 2 で、長と集める役がいる)。A1 の「大きな隣」と同じだが、次の 2 つを変える。
  - **求める相手の選び方**: 今は「届く中でいちばん弱い所」。強い集落だけは「届く中で、払える余りがいちばん多い所」を選ぶ (村は余りが多いので選ばれる)。
  - **分かれない・K で縮まない**: A1 と同じ (ふつうの決まりだと、すぐ小さな集落に分かれてしまうため)。
- 求めの量は今と同じ (相手の毎年の余りの 2 割)。断ると、強い集落は「戦う」か「あきらめる」を損のくらべで選ぶ (今の決まり)。
- 村の答えは今の 4 つから「逃げる」を除いた 3 つ (払う・戦う・ほかの村に助けを頼む)。C の「逃げ場なし」のまま。

### 2.2 苦しい年 (おすすめ: 入れる)

- 悪い年の割合を 0.2 から 0.35 にする (A1 の要因と同じ値)。悪い年は、畑の実りとまわりの集落の余りが減る (今の決まり)。
- 村の蓄えが多い (1 年分以上) ので、すぐにはききんにならない見込み。ききんが来たら、G7 のききんとくらべる。

### 2.3 そのまま使うもの

- 段の数え方 v2・草原を砂地・逃げ場なし (実験 C と同じ)。
- G7 の直し (子が親類の倉から食べる・share)。
- 答え方 (年の集まり + 秋の集まり + 集まり直し)。モデルの割り当て (代表は 8 人に 1 人 opus・のこり sonnet、気持ちは haiku)。

## 3. どの村で回すか (案)

- **おすすめ: 本物の村 (8519 日目、G7 を閉じたところ) から続ける。** G8 は本物の村の次の G なので。
- ほかの案: 実験 C の村 (8279 日目) から続ける / 5849 日目の写しからやり直す (C とくらべやすいが、本物の村の話が切れる)。

## 4. 回す前の確かめ (おすすめ: する)

- 決まりの村 (`lab_village.py`) で、新しい押しの世界を 15 年、束 B0 (G7 の LLM に近い)・B1 (国に寄せた) を種 4 ずつ回す。
- 見ること: 強い集落が村に求めるか・村が払うか戦うか・ききん・c1〜c3。B0 で何も起きないなら、押しが弱すぎるので強める (本人に相談)。

## 5. 止める決まり (案)

- 3 つの条件がそろう / 20 年 / 1 億 2,000 万トークン / 仕組みのまちがい / 村の人がみな亡くなる / 本人が止める。
- 8 年進まなければ相談 (今の決まりのまま)。

## 6. 費用と時間の見込み

- 決まりの村の確かめ: 数時間 (トークンはほとんど使わない)。
- LLM の村: C と同じくらい (1 年 約 600 万トークン。20 年で約 1.2 億。約 6 時間)。押しで集まりが増えると、もう少し多い。

## 7. G1〜G7 との関係

- 押しの仕組みは G8 だけで働く。G1〜G7 は 1 バイトも変わらないことを、前と同じ方法 (`step.py` を写しで回して state のハッシュをくらべる) で確かめる。
