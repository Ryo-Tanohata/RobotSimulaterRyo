## 4. 通説と比べて

物差しは、ウルク IV〜III 期の帳簿と配給、初期王朝期の町の壁と王、利子のある貸し借り、ウル・ナンムの法のような書いた償いの決まり (`G7_design.md` 1.)、強い国への従属と貢ぎ (G8)、古アッシリアのカネシュの商人と粘土の板の約束 (G9。Larsen 2015【二次】)、後期青銅器時代の崩れ (前 1200〜1150 年ごろ。日照り・錫の道が切れる。原因は【議論あり】)。約 2,050 年が、ゲームの中では 70 年。

通説と向きが合った点
- **強い隣に従い、重くなると離れた**: 求められると代表はみな「払う」を選び、村は強い国の従う側に入った (G8 c1)。重い求めで蓄えが尽き子が亡くなると払うのをやめ、強い国のほうも 203 → 89 人に弱っていて、村は国の外にもどった。強い者への従属と、そのあとの「崩れ」(貢ぎが止まる・まとまりがばらける) は、作る側が与えずに起きた (テクノロジーツリーの創発に入れてある)。崩れは史実の第 5 部の終わり (後期青銅器時代の崩れ) にあたる場所に置いていた出来事で、村の世界では G8 の終わりに起きた 【読み】
- **青銅は遠くから「物」として来た**: 村で作られることはなく、運ぶ人から 1 つずつ・2 本ずつ替えた。錫が遠くから運ばれたという形と向きは合う。ただし仕組みとして、そう作ってある
- **利子を村の人が自分でつけた** (G7 の 2 回)。ただ、村の人を演じるモデルが知識から言い出したのかもしれない
- **家ごとの差が開いた**: 持ち物のジニ係数 0.685 → 0.948。ただし、土地や犂で暮らしの形が変わったためではなく、ききんで多くの家が倉を食べつくし、残った倉が受けつぎで一部の家に残り、種を持つ家が村を出たため 【読み】

通説と違った点
- **王・役所・税・書いた法が、70 年出なかった**: ききん (G7)、外からの求め (G8)、遠くとの商い (G9) のどれでも、村の中で取り立てる・記録する・罰で守らせる・役の人を置く、という道は選ばれなかった。G8 では外に払う分を家から集めることもなく、蓄えが尽きると外への払いをやめた
- **記録が消えた**: 第 4 部で生まれた粘土の板の記録は、55年30日目のあと使われなかった。商いの約束を板に刻む話 (札 H8-04) も 3 回届いたが、3 回とも忘れられた
- **遠くとの商いが、商人と約束にならなかった**: 買ったのはその場の取り替えだけ。商人の家 (交換に出かける家) も、書いた約束も生まれなかった。村の人が交換に出かけたのは 44年 (第 4 部) が最後
- **国は、村の中にもまわりにも大きくはできなかった**: 地域でいちばん高い段は 3 (G8 の北の大きな村と、G9 の N21)。戦は第 5 部で村には 0
- **速さ**: 物差しの約 2,050 年が 70 年。見込み (20〜30 年) の 2 倍より長かった

**比べるときの注意**: 第 5 部のあいだに、作る側が仕組み・お題・答え方・モデル・世界を何度も変えた (6. の「決めたこと」)。G7 のききんの多くは作る側のまちがいから、G8 の押しと G9 の運ぶ人は作る側が与えたもの。ここに書いたのは、この世界のこの 1 回の走りで見たことで、一般の決まりではない。

### 「村の中の国」が生まれなかったことについて

この部の結果は、こう残す: **村は、飢えても、外から求められても、遠くと商えても、王・税・書いた法を選ばなかった。外の国には入り、また離れた。青銅は買ってすぐ使ったが、約束はしなかった。**

- 見たこと: 代表 (G7 の 61年120日目から sonnet・opus) は、どの G でも「暮らしをうまく回す」決め (畑を刈り切る・ヤギの多い分を干し肉にする・種をまく量) を選び、もめごとはほとんど「ゆるす」で収めた。案は出ても (G9 だけで 67 本) 採用されないことが多く、税・罰・役の案は 62年春の 4 本のほか出なかった
- 【読み】これは、研究の実験 (A・B・C、論文 2 の実験 3・4) で見た向き (代表のモデルは、決まりで人をしばる道をあまり選ばない) と同じ。答えるのが LLM の代表であること自体が、結果の大きなわけの 1 つと読める
- 【読み】世界の形も効いた。G7 は地域が空いていて、困った人は村を出られた。G8 の求めは、はじめは軽すぎ (蓄えの 0.1% ほど)、重くすると蓄えが尽きるまで外へ払うだけで済んだ。G9 では村が豊かで (蓄えが 1 年分をこえた)、近くの村には村の欲しい物がなく、遠くの運ぶ人の鎌は安かった。どの G でも、村の中に取り立てや約束を「要る」ようにする困りごとが、長くは続かなかった
