書いたのは Claude (2026-11-21)。下書き (係のエージェント) を Claude が読み、231年の結果 (読める大人 26%・知らせ 8 枚 4 家・字の仕事 1.7%) を見て、このまま使うと決めた。`sim/society/data/state.json` は読んだだけ (230年の終わり・27719 日目の値)。
本人の選び (229年の終わりの相談、`I4_check.md` 8.): 「フェーズ 3 は決まりを変えずに 231年の終わりまで続け、そのあと読み書きを使って分業と町にもう一度挑む」。
コードの名前は **p4** (`sim/society/p4.py`・印 `state.era2.g7.p4`・止まりの文の「P4:」)。人が読む所 (年報・この文書) では **Society 3.0 フェーズ 4 (頼み書きと町)** と呼ぶ。

## 0. ひとことで

- これまでで分かったこと:
  1. 村の人は **返りがお題に見えるものを選ぶ** (S3 の作業場)。
  2. 村の人は **食べ物を先にする**。食べ物の仕事から人を 1 年じゅう外へ出す道 (S4 の町の家) は、3 年聞いて のべ 90 人が「出さない」、出した家 0 (`S4_check.md` 10.)。
  3. 村の人は **知らせ板を、食べ物の段取りに使った** (ヤギの数・まく量・水の道。225〜230年に 25 枚、話で中身を使った回 10〜28/年)。板は「読まれる場所」になった (`I4_check.md` 8.)。
- フェーズ 4 は、町の家を「1 年じゅうしばる家」でなく、**字で書いた頼みと約束で、家と家が少しずつ仕事を受けあう形**にする。人を食べ物の仕事から外さず、季節の数日だけ受ける:
  1. **a 頼み書き**: 家に読める大人がいる家は、知らせ板に「燃える石 N kg (か 板 N 束) がほしい。かわりに 〇〇 を渡す」と書ける。かわりの物は、書いたときに分けておく (あとで払えないことがない)。
  2. **b 約束の帳**: ほかの家 (家に読める大人がいる家) がその頼みを受けると、帳に「だれが・何を・いつまでに・かわりに何を」が書かれる。受けた家の大人は、その季節の **10 日まで** だけ頼みの仕事をし、のこりの日はいつもの仕事 (畑・ヤギ・水の道)。
     できた物は頼んだ家の倉に入り、分けておいたかわりの物は受けた家に渡る。帳はお題に出る (読める人と、家に読める人がいる人に)。
  3. **かわりの物に「手間返し」**: 頼んだ家の大人が、受けた家の大人が頼みの仕事をした日と同じ日数、その人のいつもの食べ物の仕事をかわりにする。**受けた家の畑の手はへらない**。
- 頼みを何度も受ける家が、帳の上に「よその家のために働く家」として見えてくる。これを、町の芽と見る (物差しだけ。お題には出さない)。
- **後押しはしない**。どれも「してもよい」道。印・本人の言葉・「作る側」・物差し・Society のことは、お題にも出来事にも出さない。
- 時代 (state の era) は G15 のまま。G15・S3・S4・i4 の世界の仕組み (作業場・燃える石・掘り場・知らせ板・手習い) はそのまま動く。
  **i4 の止まり (相談・入口) は p4 の印で閉じる** (S4 を i4 で閉じたのと同じ形)。知らせ板と手習いは止めない。

## 3. 部分ごとの決まり (`p4.py`)

### 3.1 a 頼み書き

| こと | 決まり【仮定】 |
|---|---|
| 書き方 | 答えの欄 `order`: `{"ほしい": "燃える石", "数": 3000, "かわり": {"手間": 6}}`。null なら書かない。年の集まりの答えと季節の答えのどちらでもよい |
| ほしい物 | **燃える石 (kg)** か **板 (束)**。どちらも家の倉に入る物 (S3 の家の石 `hcoal`・家の板 `hplanks`)。燃える石は 500〜10,000 kg、板は 10〜200 束 |
| かわりの物 | `手間` (人日。頼んだ家の大人が、受けた家の大人のいつもの仕事をかわりにする日数) か、家の倉の `草の種` (つかみ)・`燃える石` (kg)・`板` (束)。1 つだけ |
| 分けておく | 物のかわりは、書いたときに家の倉から「預け」に移す (足りなければ書けない)。手間のかわりは、頼んだ家の大人の数 × 10 日までしか書けない |
| 書ける人 | 答えた人の家に、読める大人がいるとき (知らせ板と同じ)。1 家 1 季節 1 枚 (知らせと頼みで別に数える)。まだ受けられていない頼みは 1 家 2 枚まで |
| 板の上 | 頼みは知らせとは別に、新しいほうから 8 枚。受けられないまま 4 季節たつと消え、預けは家にもどる |
| 書いた日 | 知らせと同じ (書いた家の読める大人 1 人が、季節のはじめの 1 日を「知らせを書く」。i4 の `write_day` の形) |
| 返していない家 | 手間返しがのこっている家は、新しい頼みを書けない (帳に出る) |

- **食べ物は頼めない**。頼みは燃える石と板だけ (食べ物の仕事から人を外す道にしないため)。

### 3.2 b 約束の帳 (受けて、働いて、渡す)

| こと | 決まり【仮定】 |
|---|---|
| 受け方 | 答えの欄 `take`: `{"頼み": 3, "人": ["名前", …]}`。**答えた人の家の大人だけ**。頼んだ家とちがう家で、家に読める大人がいるとき (中身が読めるので)。1 つの頼みは 1 家だけが受ける (同じ季節に 2 家なら名の順で前) |
| 家にある物で渡す | 受けた家の倉に、ほしい物がもうあれば、受けた日に渡して終わる (働く日はいらない) |
| 働き方 | 足りない分は、名を書いた人が、その季節のはじめから頼みの仕事 (燃える石を掘る / 水の作業場で働く) をする。**1 人 1 季節 10 日まで**。11 日目から、その人の答えの仕事にもどる (i4 の `restore` の形)。1 家 4 人まで |
| できた物 | 頼みの分になるまで、掘った石・作業場の板の見つもり (その季節の板 ÷ 作業場の人日) を、頼んだ家の倉に入れる (S3 の「2 割は掘った人の家」は、頼みの日だけは頼んだ家へ) |
| 期限 | 受けた季節と、次の季節まで (2 季節)。間に合えば「果たした」、だめなら「果たせなかった」。果たせなかったら預けは頼んだ家にもどり、できた分だけ渡る |
| かわりを渡す | 果たした日に、預けの物を受けた家の倉へ。手間返しは、次の季節のはじめから、頼んだ家の大人 (名の順。読める人はあと) が、受けた家の頼みの仕事をした人のいつもの仕事を、同じ日数だけする |
| 止めるとき | ききんの集まり直しの季節と、村の蓄えが 120 日分を切った季節は、頼みの仕事をしない (期限は 1 季節のびる。帳に「食べ物を先にした」) |
| 出来事 | 「〇〇の家の X が、△△の家の頼み (燃える石 3000 kg) を受けた」/「頼みを果たした」/「手間を返した」(数だけ。かわりの中身は出来事に書かない) |

- 帳 `g7.p4.book` に 1 件ずつ: 番号・頼んだ家・受けた家・物と数・かわり・働いた人日・渡した数・手間返しの日・果たした / 果たせなかった。
- 手間返しの日は、**頼んだ家の食べ物の仕事が受けた家にうつるだけ** で、村みなの食べ物の仕事の人日は変わらない。頼んだ家は「まき集めの日がへる」と「自分の家の手が出る」をくらべて決める。

### 3.3 お題 (知らせ板の節に入れる。新しい節は作らない)

- `## 村の知らせ板` の中、知らせのあとに「頼み書き」の行。見え方は i4 と同じ 3 つの立場:
  - 読める人・家に読める大人がいる人: 頼み (番号・家・物と数・かわり・期限)・受けられている頼み・この 1 年の帳 (果たした・果たせなかった・返していない手間)。
  - どちらでもない人: 「頼み書きが N 枚ある。字が読めないので、中身はわからない (家に読める人がいない)」。受けることも書くこともできない。
- 事実の行 (くらべるための数。すすめる言葉は使わない):
  - 「燃える石 500 kg = 掘り場で掘る 1 人日。秋と冬に燃やすと、まき集め 約 44 人日」(`s4.dig_saves_pd`)
  - 「あなたの家の、去年のまき集め N 人日・家の倉の燃える石 N kg・板 N 束」(S3 の `fire`・`hcoal`・`hplanks`)
  - 「頼みの仕事は 1 人 1 季節 10 日まで。のこりの日はいつもの仕事。手間返しのときは、頼んだ家の人が同じ日数だけ、あなたの家の人のいつもの仕事をかわりにする」
- 書き方の例は、その答える人が書ける形にする (S4 の 6.1 5. の学び: 書けない例を出さない)。家の倉に物がない家には `手間` の例だけ。
- 答えの形 (JSON) に `"order": null`・`"take": null` を足す (`p4.ANSWER_FIELDS`)。
- 大きさ: 頼み 4 枚・帳 4 件で、節が +約 1.0 KB (読める人)・+約 0.2 KB (どちらでもない人) を見こむ。頼み 8 枚・帳 8 件のいちばん大きいときに 2.5 KB 未満にする。
- 出さないもの: 印・本人の言葉・「作る側」「後押し」「反実仮想」「物差し」「入口」「Society」「P4」「I4」「S4」「p1〜p4」「分業」「町の芽」。
  書かない言葉 (`g15.WORDS`: 賃金・問屋・市場・お金・手形 など) も使わない。村の言葉は「頼み書き」「受ける」「約束の帳」「かわりの物」「預け」「手間返し」。
