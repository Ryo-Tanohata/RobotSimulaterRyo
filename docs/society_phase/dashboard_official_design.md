# 年報のダッシュボードを「国の統計の形」にする設計 (調べと案)

書いた日: 2026-11-22。本人の言葉「ダッシュボードは国の GDP や国勢調査など、公的なものに従った形式にしたい。まず調べて、ここではこれしかないからどうするかを考えて。ないものはこのシミュレーションの未来の話なので、その様な設計をして」を受けた。
コードは変えていない (`tools/year_report.py` もそのまま)。村の記録 (`sim/society/data/`) は読んだだけ。
文の中の [1]〜[20] は、終わりの「7. 出典」の番号。国の決まりを借りた所には、その場で番号をつけた。

## 0. ひとことで

- 国の統計は **「分野ごとに、見出しの数をいくつか・前の期とのちがい・長いうつりかわり・定義の説明・出す日」** という形で出している [1][2][3]。
- この村は、お金も賃金も学校もない。それでも **人口・出生と死亡・食べ物の生産と使い道・働いた日・読み書き・住まい・よその村との交換** は、今の記録から国と同じ式で出せる。
- 「GDP」は、お金のかわりに **熱量 (kcal) を「大人 1 年分の食べ物」に直して** 出せる。国の会計でも、農家が自分で食べる作物は生産と消費に入れる [5]。村の会計 `accounts` はもう毎季節できている。
- お金・物価指数・失業率・学校・町 (都市) などは **まだこの村にない**。ダッシュボードには灰色の枠で「まだこの村にはない」と出し、**何が起きたら点くか** を書いておく。

### 1.3 この村にとって大事な 4 つの点

1. **国の会計は、売らない物も生産と消費に入れる。** 「農家における農産物の自家消費」は家計の消費に入る (帰属計算) [5]。一方で、無給の家の中の家事やボランティアは「SNA 生産境界を超えた」活動とされる [7]。
   → この村の草の種・ヤギ・土器・鎌・板は、みな「村の生産」に入れてよい。
2. **ILO の決議 (2013) では、「就業」は他人のための有給の仕事だけ。** 自分自身のための仕事は別の形の「仕事」[7]。
   → この村の大人は、ほぼ全員が「自分自身のための仕事」をしていて、「就業者」も「完全失業者」も 0 人。失業率はこの村では意味がない。かわりに **時間の使い方 (何の仕事に何人日)** を出す [9]。
3. **食料需給表は、生産・輸入・輸出・在庫・種・減耗の式で、1 人 1 日あたりの熱量まで出す** [13]。この村の帳簿 (ledger) は同じ形 (はじめの残り + 入った − 出た = 終わりの残り) で、kcal でつけている。そのまま使える。
4. **統計には「だれが数えたか」がある。** 国勢調査は数えもれを防ぐために「世帯員の数」を聞く [11]。この村には、村の人がつけた帳 (【村】)、考古学で分かる跡 (【調】)、シミュレーションだけが知る本当の数 (【シ】) がある。**村の帳と本当の数のずれ** も 1 つの統計になる (例: 237年冬、村の帳は「60 家・444 人」、本当は 93 家・754 人)。

### 4.2 1 枚のカードの形 (例: 経済)

```
┌ 経済 (村の生産) ─────────── 札: シ ┐
│ 村の生産   大人 466 人分   ▲ 2.1% (去年 456) │
│ 1 人あたり 大人 0.62 人分                     │
│ ── 12 年の線 ──                               │
│ 使い道: 食べた 110% / 蓄えの増え −10% / 外へ +0.2% │
│ ▸ くわしく  ▸ この数の決まり                    │
│ ░ 名目 GDP (お金) まだこの村にはない            │
│ ░   → お金ができたら点く                        │
└───────────────────────────────┘
```
(「▲ 2.1% (去年 456)」は形の見本で、本当の去年の数ではない)

### 4.3 決まりごと

- **くらべ方**: 割合は「ポイント」、量は「%」と「去年の数」[2]。良い向きだけ緑・悪い向きだけ赤。良い悪いのない数 (人口・トークン) は色なし (今と同じ)。
- **数が小さい数** (乳児死亡・交換の割合) は、1 年の数と 5 年の平均を並べる。
- **村の年**: 1 年 = 120 日、年齢も村の年。国の数とくらべるときは、そのことを定義に書く。
- **区切り**: コードを変えた日 (例 4409 日目の草の上限) は、線に縦の点線を入れる。
- **札**: どの数にも 村 / 調 / シ の小さな札。村の帳と本当の数がちがう所は 2 つ並べる。
- **灰色の枠**: 数を作らない (0 とも書かない)。「まだこの村にはない」と、点く条件だけ。

#### 国の統計では、新しい技術をどう数えるか

- **イノベーション**: 全国イノベーション調査は、OECD と Eurostat の『オスロ・マニュアル 2018』に準拠し [19]、「プロダクト・イノベーション」(新しい又は改善された製品・サービスで、市場に導入されたもの) と「ビジネス・プロセス・イノベーション」(新しい又は改善されたやり方で、自社の中で使われているもの) に分ける [19]。
  → 村では、新しい**物** (土器・鎌・板・町の鎌) を「プロダクト」、新しい**やり方** (持ち場・知らせ板・帳・頼み書き) を「やり方」とし、**その年に初めて出たもの (テクノロジーツリーの「初めての記録」165 件) の数** と、**それを使った家の割合** を出す (国の「イノベーションを実現した企業の割合」にならう)。
- **研究開発**: 科学技術研究調査の研究費は、OECD のフラスカチマニュアルに沿って定義している [20]。
  → 村には研究の仕事はないが、「ためす」日 (`granary` の 水と務め の `try`) があれば「ためした人日」を出す。ないときは灰色。

### 4.7 作る順と大きさ (見積もり)

ここでは作らない。作るときのおすすめの順:

## 5. 新しく記録が要るもの / 今の記録で計算できるもの

### 5.1 今の記録で計算できる (年報の道具だけ直せばよい。村は変わらない)

人口・男女・年齢・世帯・出生・死亡・死因・乳児死亡率・平均寿命・合計特殊出生率・村の生産と使い道 (`accounts`)・仕事ごとの人日・休んだ日・収量・ヤギ・食料需給表・蓄え・識字率・手習い・住まいの差・外で寝た人・よその村との出し入れ・掟・もめごと・燃える石・水の道。
交換の割合は `state.json` の出来事の文 (よその村の申し出) と t5・s3・s4 の帳から数える (文から読むので、読み方の試しが要る)。

### 5.2 新しく記録が要る (世界の記録を足す。必ず印で守る)

足すときは、今までの決まりどおり **新しい印 (例 `g7.stat1`) を書いた日からだけ** 記録し、印がない歩は前と 1 バイトも同じにする (やり直しで確かめる)。ここでは作っていない。

| 足す記録 | なぜ | いつ |
|---|---|---|
| よその村・町との交換の 1 件ごとの帳 (出した物・数・受けた物・数・相手) | 交換の割合 (物価のかわり) を、文から読まずに正しく出す | 次のフェーズを作るとき |
| 水の道・作業場・掘り場を作った・直した人日を「資本を作った」として分けた帳 | 総資本形成 (投資) | 同じ |
| 村の帳 (【村】) の人数・家・蓄えを毎季節残す | 数えもれ (村の帳 ÷ 本当) | 帳はもうある。足すのは季節ごとの残し方だけ |
| お金・賃金・税・学校・町の記録 | 4.4 の灰色の枠を点ける | それぞれの仕組みを作るとき (その設計の中で) |

### 7.2 村の数の出どころ

2.・3.・4.5・4.6 の村の数は、`sim/society/data/records/` (season_village・season_household・people・granary) と `state.json` (`era2.g7` の t5・p4・i4 の行・`events`・`era_log`)・`app_data.json`・`app/dashboard_data.json`・`techtree/plan.json`・`techtree/emerged.json` を 2026-11-22 に読んで計算した。テクノロジーツリーの数は `tools/build_tech_tree.py` の `--out` で一時ファイル (`/tmp`) に出して読んだ (リポジトリのページは書きかえていない)。何も書いていない。
