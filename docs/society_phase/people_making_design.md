# 人を創るプロセスの設計 (村の人の 3D モデル)

2026-11-23。本人「人を創るプロセスを考えたいです」「設計の書類にまとめて下さい」。
いまある 2 つの流れ (パソコンの VRoid、クラウドの Blender) をまとめ、これからの形を決めるための書類。
まだ何も作り変えていない。決めることは 5. に並べた (おすすめつき)。

## 1. ねらい

- 動画で、村の人を「記録どおりの姿で、記録どおりに動く人」として見せる。
- 姿は作る人の好みで決めない。**村の記録から決める** (どこで何日働いたか・けが・年れい・親)。
- 村の人のお題 (シミュレーション) には何も足さない。見た目は動画とアプリのためだけのもの。

## 2. いまの流れ A: パソコン (VRoid の手作り)。できあがっている

ホームのセッションが作り、1 日目の動画 D1P (198.6 秒) を撮った。HANDOFF 3.7 の「D1P」。

| 段 | すること | 道具 | 置き場所 |
|---|---|---|---|
| A1 記録から人物像 | 年れい (1 日目)・体重・仕事の日数・よくいた場所・話した回数と言い方・けが・最期を数え、顔・髪・体・肌を決める | 記録を読むだけ (state.json・archive) | `kawabe_five.md` (本人が貼った表) |
| A2 姿を作る | 表をもとに、一人ずつ手で作る | VRoid Studio | 本人の PC |
| A3 服と動き | 皮の貫頭衣とひも帯を着せる。動きのデータ 12 個 (CMU) をつけて書き出す | Blender 5.2・`export_people_glb.py`・`slim_glb.py` | 本人の PC の `human-model/` (GitHub にない)。1 人 5〜6 MB |
| A4 記録どおりに動かす | 場面と活動・夕方の出来事から、動きと向きを選ぶ | `sim/society/app/replay3d_people.js` | リポジトリ |
| A5 撮る | GPU で撮る | `render_all.sh D1P` (`PEOPLE_DIR`) | 本人の PC。mp4 はコミットしない |

A1 の決め方の例 (川辺の五人):
- 北の林で採集 2680 日 → 濃い日焼け。家の近くの仕事が多い → 日焼けが浅く、手に煤。
- ザガに 4 回けが → 傷。いちばん軽い体重 → いちばん細い体。
- 話し方 (ていねい語・勢いがある・無口) → 目と口の形。

動きの記録 (A3) の名前: idle・walk・search・look・pick・probe・reach・stretch・talk・give・eat・lie。

よいところ:
- 見た目がいちばんよい。
- 本人が手で決めるので、思いどおりの姿になる。

足りないところ:
- 1 人ずつ手で作るので、何百人は作れない (村には今 784 人、これまでに 3,855 人)。
- パソコンがないと作れず、撮れない。
- モデルが GitHub にないので、クラウドから使えない。

## 3. いまの流れ B: クラウド (プログラムで作る)。試している途中

セナ 1 人で試している (2026-11-23)。

| 段 | すること | 道具 |
|---|---|---|
| B1 記録から人物像 | A1 と同じ | 記録を読むだけ |
| B2 体を作る | 性別・年れい・体重・筋肉・体つきの数を入れて、人体の形を作る | Blender 4.5 (Python の bpy)・MakeHuman の人体 (CC0)・MPFB |
| B3 髪・服・肌 | 髪の色と形、皮の貫頭衣、肌の色と傷をプログラムでつける | 同じ |
| B4 絵と書き出し | 前・横・後ろ・顔の絵、`glb` | 同じ (GPU なし) |

よいところ:
- 人の手がいらないので、同じ手順で何人でも作れる。
- 記録から数を出すところまで、自動にできる。

足りないところ:
- 見た目は VRoid のアニメ風とはちがう。写実寄りか、簡単な形になる。
- クラウドのディスクがほとんどないので、作業はメモリの中でする。
- モデルを置く非公開の場所が要る。このリポジトリは公開なので入れない。

## 4. これからの形 (おすすめ): 2 段の人づくり

### 4.1 だれをどちらで作るか

| 段 | だれ | 作り方 | 数の見当 |
|---|---|---|---|
| 主な人 | 動画で名前を出して話の中心になる人 (川辺の五人、各時代の長老・まとめ役・はじめて何かをした人) | 流れ A (VRoid で手作り) | 1 本の動画で 5〜12 人 |
| ほかの村人 | それ以外のみんな | 流れ B (プログラムで自動) | 何百人 |

- 主な人を選ぶ決まり: 動画の「名前を出す人」(`Replay3D.setFeatured`、いま 12 人まで) と同じにする。
- 混んだ日 (700 人) は、遠くの人を軽い形 (今の棒の人か、低い形のモデル) で描く。近くの人と名前の出る人だけを、モデルにする。

### 4.2 記録から姿を決める決まり (表にして自動にする)

A1 で毎回考えていた決め方を、決まりの表にする。主な人では、表で出した案を本人が VRoid で仕上げる。

| 記録 | 姿 |
|---|---|
| 性・年れい (その日の) | 体の大きさ・顔つき・白髪 |
| 体重・飢えた日 | 細さ・頬のこけ |
| 外の仕事 (採集・狩り・畑・掘り場) の日数 | 日焼けの濃さ・腕と肩の筋肉 |
| 家の近くの仕事 (火・土器・字を教える) の日数 | 日焼けが浅い・手の煤や土 |
| けが (ザガ・仕事) | 傷の場所と数 |
| 話し方 (ていねい・勢い・無口) と話した回数 | 目と口の形・表情 |
| 役 (まとめ役・長老・薬をもらった家・読める人) | 持ち物 (帯の飾り・板・包み) |
| 親 (母・父) | 髪の色・目の色・顔の形を受けつぐ (4.3) |

### 4.3 親から子へ

- 村には親子の記録がある (`mother`・`household`・`born_day`)。
- 子は、髪・目・肌のもとの色と、顔の形の数を、両親の数のあいだから受けつぐ。くじは人の名前から決めるので、何度作っても同じ姿になる。
- これで、家族が見た目でわかる。
- 最初の 5 人は親がいないので、その姿が村の人みなのもとになる。

### 4.4 年をとる

- 同じ人を、子ども (0〜14)・大人 (15〜54)・お年より (55〜) の 3 つの姿で持つ。
- その日の年れいで、使う姿を選ぶ。
- 姿の間は、体の大きさだけを年れいでなめらかに変える。

### 4.5 服と道具は時代の記録に合わせる

| 時代の記録 | 服・道具 |
|---|---|
| Society 1.0 (はじめ) | 皮の貫頭衣・ひも帯・はだし |
| 織る技術が届いた年から | 織った布の衣 |
| 土器・石の鎌・町の鎌・子の薬の包み・知らせ板 | その日に持っている物を手に持つ |

技術が届いた年は、テクノロジーツリー (`app/tech_tree.html`) の記録から読む。

### 4.6 動き

- 流れ A の 12 の動き (CMU) を、主な人とほかの村人の両方で使う。
- 足りない動きを足す: 畑を耕す・刈る・土器を作る・掘る・板を書く・子を抱く。
- 動きを選ぶのは、これまでどおり `replay3d_people.js` (記録の活動と出来事から)。

### 4.7 置き場所

| 物 | 置き場所 |
|---|---|
| 作り方の道具 (スクリプト)・決まりの表・動きの割り当て | このリポジトリ (公開でよい) |
| モデル (glb)・Blender の元ファイル | 非公開の置き場所 (5.4)。元ファイル (2.6 GB) は本人の PC |
| 動画 (mp4) | 本人の PC (コミットしない)。見せるときは Google ドライブなど |

## 5. 決めること (おすすめ)

1. **2 段にするか**
   - おすすめ: する。主な人は VRoid で手作り、ほかの村人はクラウドのプログラムで作る。
2. **見た目をそろえるか**
   - アニメ風の VRoid と、写実寄りのプログラムの人が並ぶと、ちぐはぐになる。
   - おすすめ: プログラムの人にも、アニメ風の影 (トゥーン) と輪郭線をつけて近づける。セナの試しの絵を見て決める。
3. **記録から姿を決める表を、自動にするか**
   - おすすめ: する。主な人は、表の案を本人が見て直す。
4. **モデルの置き場所**
   - おすすめ: 非公開の GitHub リポジトリ (例 `human-model`) を作る。パソコンから押し入れて、クラウドは読むだけにする。
   - そのとき、このセッションがそのリポジトリを読むことを本人が許す。
5. **親から子へ・年をとる・時代の服を入れるか**
   - おすすめ: 入れる。順番は、親から子へ → 年をとる → 時代の服。
6. **混んだ日の描き方**
   - おすすめ: 名前の出る人と近くの人だけモデルにして、遠くは今の棒の人のままにする。

## 6. 作る順 (おすすめ)

1. セナで流れ B を試す (いまやっている)。前・横・後ろ・顔の絵と、立つ・しゃがむの絵を作る。
2. 2. の見た目をそろえるかを、セナの絵で決める。
3. 決まりの表 (4.2) と、親から子へ (4.3) の道具を作る。記録を読むだけで、村のデータには何も書かない。
4. モデルの置き場所 (5.4) を作る。パソコンのセッションが開けるときにする。
5. 2 段で 1 本撮る。候補は S3P34 の一場面。

## 7. 守ること

- 村のデータ (`sim/society/data`) には何も書かない。記録を読むだけ。
- 村の人のお題には、姿のことを何も足さない。
- 使う素材は、使ってよい条件 (CC0 など) と出どころを、道具のそばの README に書く。
  - いまの素材: MakeHuman (CC0)、CMU Graphics Lab Motion Capture Database、VRoid Studio (本人が作ったモデル)。
- モデルと mp4 は、公開のリポジトリに入れない。
