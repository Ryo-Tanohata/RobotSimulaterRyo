# G2 (畑と家畜) のメモ

1229 日目に G1 から進んだ。生存 14 人 (大人 11・子 3)。

## 1229〜1529 日目 (10 季節)

- 1229 日目: フウ・モエ・シノを受け入れ、大人が 13 人に。1259 日目の季節の終わりから、家族の代表が答える形になった (`G1_notes.md` の「家族の代表が答える」)
- 家族の代表は、家族の大人に別々の仕事を割り振ることがあった (川辺の家: ウィロに畑仕事、1409 日目の季節にタヒとウィロに「ヤギを捕まえる」)
- 1415〜1436 日目に子ヤギを 4 頭捕まえ、1529 日目に子ヤギが 3 頭生まれて 5 頭。ヤギの世話をした人は 0 人
- 1469 日目にアル・ヨナ、1499 日目にクラを受け入れた。1289 日目にテオ、1529 日目にニイが生まれた。けが・死・村を出た人は 0
- 分け合いの掟 3 本が廃止された (1259・1469 日目)
- **1529 日目に G3 (余りと分業) へ** (一時停止)。G3 の仕組み (土器づくり・蓄えの穀物の害・石の鎌) は、G2 のあいだに作っておいた (`society2_phase_plan.md`)。G3 に入った 1529 日目のお題から、土器づくりが選べる
- 余りの年 (1 年の終わりに、その 1 年に食べた量の 2 割以上の蓄えが残った年) は、数え始めた 1229 日目のあとの 3 年すべて (10・11・12 年目)。G3 の条件のうち、残るのは「作る人が 1 人以上」
- 評価の下書き: `G2.md`。動画: `society_G2.mp4` (1230・1259・1320・1415・1469・1529 日目)
