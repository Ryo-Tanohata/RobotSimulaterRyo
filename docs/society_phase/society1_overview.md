## 3. 通説と比べて

**通説どおりだった点**
- 小さな集団で、分け合う決まりが早くできた
- 大きな獲物の狩りは不安定で、採集に頼る暮らしになった
- 食べ物の幅が、木の実・芋から草の種・小さな獲物・大きな獲物へ広がった
- 蓄えを持つようになり、冬を越えるのに使った (F3 の 2 回目)

**通説と違った点**
- 蓄えが F1 のうちに始まった。世界に最初から「キャンプの蓄え」があったため (作る側の設計の誤り。F1 の評価に記録)
- 移動しなかった。キャンプを移す仕組みを足したあとも、一度も移していない (通説の採集民は食べ物を追って移動する)
- 住まいを建てる発想が出ない。F3 に入った 40 日目からの約 95 日間、夜に決めた予定は採集と狩りばかりで、住まい・火おこし・道具づくり・探索は 0 回。雨で蓄えが傷むようにしてからは「屋根を作ろう」という掟が 2・3 回目あわせて 20 本以上採用されたが、実際に建てに行ったのは 2・3 回目あわせて 5 日だけだった (通説の定住は、蓄えを守る必要から家を建てたとされる。ここでは必要を言葉にはしても、行動にならない)
- 冬に備えて蓄えを増やせなかった。秋の採集はその日のうちに食べる量とほぼ同じで、蓄えは減り続けた (通説の蓄えは、多く採れる季節の余りを取っておくもの)
- 肉の保存 (干す・燻す) をずっと話題にしているのに、火をおこして干すという行動にはつながらなかった

## 4. 模倣と創発

- F1・F2 では、出来事を理由にした掟づくり (創発) がはっきり見られた。例: 肉が腐ったあとの保存の掟、イサの死のあとの「空腹な人を見守る」掟
- 知識の記録では、創発 (自分たちの経験から) と伝承 (人から聞いた) がおおむね半々 (F1) から、創発が多い側 (F2) へ移った
- 一方で、世界にある仕組みのうち、お題に「よいこと」を書いていないもの (住まい・火・道具) は、自分たちで試すことがなかった。経験からの学びは、すでにやっている行動 (採集・狩り・蓄え) の改善に集中している

## 5. 考察

1. **このシミュレーションの人たちは「今やっていることを上手にする」方向には学ぶが、「やったことのないことを試す」方向にはほとんど進まない**。F1 の種まき (8 日目に 1 回) を最後に、新しい種類の行動は出ていない。通説では、定住や栽培は人口や気候の圧力のもとで少しずつ試されたとされるが、ここでは試す行動そのものが起きない
2. **困りごとが「新しい行動」につながるには、その行動で困りごとが解けると分かる必要がある**。3 人の一番の困りごとは肉が腐ることだが、住まいは肉には効かない (植物の蓄えに効く)。困りごとと解決の手段が結びついていない
3. **全滅 2 回は、どちらも作る側が「大人なら誰でも知っていること」を書いていなかったのが原因**だった (キャンプを移せること、冬が来ること)。知識を足すと、人たちは正しく使った (冬を越えた)。どこまでを「最初から知っていること」にするかで、結果が大きく変わる
4. **掟 (言葉) と行動のずれ**。F3 の 2・3 回目では「屋根・住まいが最優先」の掟が 3 人の賛成で何度も採用された。それでも翌朝の予定はほぼ全員が採集だった。決まりを作ることと、その決まりどおりに動くことは別で、このシミュレーションでは後者を後押しするものがない (誰も確かめない・守らなくても困らない日が続く)
5. **見せ方を変えても結果は同じだった**。雨の夜、まだ試していない活動の一覧、住まいのでき具合の表示、自動で食べる仕組みを順に足した。蓄えがあるのに飢える死は防げたが、住まいは建たず、2 回目の冬の初めに 2 回とも飢え死にが出た (どちらも 178 日目にウィロ)。F3 で止まる原因は、お題よりも世界のつくり (秋の採集量と食べる量のつり合い、建てる手間、冬の厳しさ) にある可能性が高い
6. Society 2.0 までの道のりのうち、再現できたのは前半 (F1〜F3 の途中) だけ

## 6. F4〜F6 (2026-10-07 追記)

- F4〜F6 の 306 日間で、3 人とも生き残った (けが 9 回、死 0)
- 進んだのは、人の判断よりも、作る側が足した世界の仕組み (ごみ捨て場から木が育つ、夕方にキャンプでできる「取る」「埋める」、野生の資源の枯渇) による。お題に知識を書くだけでは、行動は変わらなかった
- この世界の人たちは、「昼の予定」を変えない (ほぼ毎日採集)。新しい行動は、「夕方にキャンプでその場でできること」として出したときに選ばれた
- 育てた木に頼るようになったのは、野生の採集が減り、蓄えが減ってから。食べ物が足りているうちは、手近な木の実を取らなかった
- 通説の流れ (定住 → 住まいのそばの植物 → 種まき → 育てた植物に頼る) の順には進んだ。ただし、通説の大きな理由のひとつである人口の増加は、この世界にない (人は 3 人のまま)
- 詳しくは `F4.md`・`F5.md`
