## 3. 3D の人（VRoid の CC0 サンプルから）

作り方は `sim/society/tools/human/README.md` の「作風 4」と同じ。設定は `people.py` の `VROID["sona85"]`。

```bash
BLENDER_USER_RESOURCES=/dev/shm/sena/userres PYTHONPATH=/dev/shm/bpy \
  python3.11 -u sim/society/tools/human/run.py sim/society/tools/human/build_person_vroid.py \
  -- --person sona85 --only sheet,face,guide > /dev/shm/sena/vroid/logs/sona85.txt 2>&1
```

| 部分 | 使ったもの |
|---|---|
| 体・骨組み | HairSample_Female |
| 顔 | Victoria Rubin（五人のだれとも別の顔） |
| 髪 | Victoria Rubin の髪（リボンと横の房を消す）を灰色にして、うなじで結ぶ |
| 服 | スクリプトで作った革の貫頭衣・すそ・帯（`dress()`。外の素材は使っていない） |
| しわ | 顔のテクスチャに、前から光線を当てて描いたうすい線（`face_lines`） |

このために `build_person_vroid.py` に足したもの（ほかの五人の絵は変わらない）：

- `outfit.dress`：革の長い貫頭衣。胴とすそは体の輪切りの外側をなぞる筒（`skirt_loft()`）で、胸から下はまっすぐ落ちる。肩と短い袖は体の表面を切りとった帯。帯は細い革紐。
- `skin.face_lines`：顔のしわ。
- `--only guide`：吹き出し用の胸から上の絵（512×512、無地の背景 #e6e1d8、腕を下ろす）。表情は `VROID["sona85"]["guide"]["expr"]`。
