### 0.3 むずかしいところ

もとの計画 (`society2_extension_plan.md` 3. の G8。今は G9 と読む) は「遠くとの商いと**国どうしの**やりとり」で、村が国になったあとの段だった。村は国にならなかったので、そのままでは前提が合わない。

- ただ、もとの G9 の 3 つの条件 (青銅の道具・商人の家・遠くとの約束を書く) は、どれも【村が決めた】で、**村が国であることを要らない**。国が要るのは「国どうしの手紙と贈り物」だけで、これは計画でも「条件にしない (起きれば記録する)」になっている。
- 史実でも、遠くとの商いを動かしたのは、国の宮殿だけではなく、町の家々の商人だった (古アッシリアのカネシュの商人は、アッシュルの家ごとの商い。宮殿がすべてを集めて配ったという見方は言いすぎ【文献】Larsen 2015【二次】・計画の【議論あり】)。銅や黒曜石の遠い交換は、国より前からある【記憶】。
- だから、「商い」の G としては、国の外の村でも測れる。

## 1. G9 の形 (3 つの案)

- **案 A (おすすめ): G9 =「遠くとの商い」。条件は国を要らない 3 つ。G7 の国の物差しは「ならべて測る」(条件にしない)。**
  - 条件と F は 2. 。国の物差し (c1〜c3・G7 の F1〜F6) は、G9 でも今までどおり数えて記録するが、G9 を進める条件にはしない。国どうしのやりとり (贈り物・同盟) も、起きれば記録する。
  - わけ: もとの計画の順 (G9 遠くとの商い → G10 鉄と広い国) を守れる。村が国でなくても、村の人の答えで届く道がある。G1〜G8 の物差しをこわさない。
  - 弱いところ: 村は「足りていると交換しない」向きがあるので、G9 でも条件に届かないかもしれない (届かないのも、起きてよい結果)。
- 案 B: G9 で、国ができるかを**別のやり方で**もう一度試す (研究の入口 2・3)。
  - 例: 代表を opus を多くする (8 人に 1 人 → 半分以上) / 答えの形を「わけを書いてから選ぶ」に変える (今は「選ぶ → わけ」の順。`state_emergence_B.md`) / 条件を今の村の向き (暮らしの決め・貸し) に合わせて考えなおす。
  - 弱いところ: 世界でなく「答える側」を変えるので、G1〜G8 の村と同じ村とくらべにくい。opus を増やすと、費用が大きく上がる (1 年 2〜3 倍の見込み【仮定】)。本物の村より、写しでの実験 (C と同じ形) のほうが向く。
- 案 C: 先へ飛ぶ。G9 を「鉄と広い国」(もとの G9、今の G10) にする。広い国の条件は「村は中心でも、中でも、外にいてもよい」なので、国の外の村でも測れる。
  - 弱いところ: 遠くとの商い (青銅・錫の道) を飛ばすと、部の終わり (後期青銅器時代の崩れ。錫の道が切れる) の話がなくなる。鉄の仕組み (鉱石・炭) は大きく、作るのに時間がかかる。

**おすすめは案 A。** 案 B は、本人が望めば、G9 と別に写しの村で (C と同じ形で) 試す。

## 3. 足す仕組み (案)

もとの計画の「足す仕組み」は、金属 (鉱石は地図の外・炭・製錬)・遠くへの道と運ぶ日数・遠くの商人が来る決まり・車と道・集落どうしの同盟と贈り物。ぜんぶ入れると大きいので、**小さく 4 つ** をおすすめにする。

### 3.1 おすすめの 4 つ

1. **遠くの商人が来る** (`hints.LAM_FAR` = 0.1。コードには「G8 から」と書いてあり、今の番号では G9 から)。
   - 来るのは、前の年に村が交換をしたときだけ (計画 2.(h) のまま)。商人は地図の外から来て、銅・錫・青銅の刃・ほかの遠い物を見せ、村の草の種・ヤギ・干し肉と替えたいと言う (`hints.THING_WANT` と同じ考え)。
   - 村は申し出を受ける・断る・「次に来るとき、これだけ替える」と約束する、を選ぶ (年の集まり・秋の集まりのお題に出る)。
2. **青銅の道具の使い道**: 青銅の刃・鎌は、石の鎌より刈る・切る仕事が少し速く、こわれにくい【仮定】(数は設計で決める。大きくしすぎない)。使った日を数える (c1)。
   - 作り方 (鋳造) は、札 H8-02「金属を流しこむ職人」か、きっかけのあとに開く。銅と錫は地図の外から (商人から買うか、村が遠くへ取りに行く)。距離は縮めない。
3. **遠くとの約束を書く**: 約束の中身を、今の「記録をつける」(粘土の板) で残せる。書いた約束は、次に商人が来たときに読み合わせる (守られたか・ちがっていたか)。書かなければ、覚えだけで比べる (今の貸し借りと同じ。D7・D8 で「記録はない」が起きた)。
4. **贈り物と同盟の記録**: まわりの集落どうしの贈り物・同盟は、今の地域の決まりのまま。村が知っていれば出来事に残す。仕組みは足さない。

### 3.2 あとに回すもの (案)

- 鉱石を村の近くで掘る・製錬 (炭)・車と道。どれも G10 (鉄と広い国) の「燃料と力の帳簿」といっしょに入れるほうが小さく済む。

### 3.3 よその便り (札)

- G9 は、もとの計画の G8 の札の段を読む (`hints._stage_now`。札の表は変えない決まり)。今あるのは 3 枚: H8-01 赤い石の硬い刃 (もの)・H8-02 金属を流しこむ職人 (人)・H8-03 日照りで捨てられた町々 (話。第 5 部の終わりにあたる)。
- 計画 2.(h) の表にある 2 枚が、札の表にない: 「よその町に住んで、値段を粘土の手紙で送る商人」(商人 / 話。カネシュ【文献】Larsen 2015【二次】) と「兄弟と呼び合い、贈り物をする 2 人の大きな首長」(旅人 / 話。アマルナの手紙 前 14 世紀【記憶】)。
- おすすめ: G9 に入る日を区切りの日として、この 2 枚を足す (札を足すときの決まり。ハッシュを state に残す)。

### 3.4 村の中の国について
