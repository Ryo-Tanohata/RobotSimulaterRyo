# 人間性とテックツリー (接地度)

人類史シミュレーターで「時代が変わっても残る人間性」と「機械の人間らしさ」を調べるための設計です。
2026-10-14 に本人と Claude で詰めた内容を、社会シミュレーション (`sim/society/`) に入れはじめたものです。

## ファイル

| ファイル | 中身 |
|---|---|
| `tech_tree.json` | 人類史の 10 ノード (火と道具 → 宇宙居住) と 8 つのライフステージ、接地度・手綱・判定の仕組み (v0.5.0) |
| `design_note.md` | 設計の思想・設計判断 (D01〜D10)・参考文献 (R00〜R30)・未決事項・作業記録。JSON の `refs` の ID はここの見出しに対応 |
| `score_grounding.py` | `tech_tree.json` の接地度を計算して書き込み、ノートの採点表も作り直す |
| `build_viewer.py`・`viewer_template.html` → `index.html` | 2 つを 1 枚で見るページを作る (`python3 docs/humanity/build_viewer.py`) |

## 社会シミュレーションとの関係

- 10 ノードは人類史全体の粗い地図。Society 2.0 (村と畑 → 土器と家の倉 → まとめ役 → 町と文字) は、その中の **農耕 (N03)・都市 (N04)・文字 (N05)** を細かく走らせている。`docs/tech_tree_design_draft.md` の村の技術の木は、この 3 ノードの拡大図にあたる
- 接地度は「身体や現場にどれだけ根ざして働いているか」の記述 (0〜1、大きいほど深い。良い・悪いではない)。検証済みの尺度で作る (D06・D10): 意味 = 職務特性モデルの技能多様性・完結性・重要性、結果 = 同フィードバック、身体 = O*NET の「一般的な身体活動」の実データ。自律性 (手綱の余地) は別に出す

## 入れ方の 3 段階 (D09)

| 段階 | いつ | 中身 | 状態 |
|---|---|---|---|
| 0 記録 | 季節ごと | `build_records.py` が人ごとの行 (`season_person`) と村の行 (`season_village`) に `grounding` を足す。仕事ごとの日数 (`days_by_activity`) から `sim/society/grounding.py` の表で計算する。世界の進み方・お題・乱数には触れない | **入れた (2026-10-14)** |
| 1 理由 | 季節ごと | お題の答えの `job` に一言の `why` を足し、村の人が自分で理由を書く (手綱の「理由」「理念」を見るため) | まだ。お題が変わると答えが変わりうるので、本人が決める |
| 2 陪審団 | フェーズが進んだとき | 村の人と同じ仕組み (haiku が 1 人 1 体) で村の外の陪審員を動かし、評価の下書き (`docs/society_phase/G?.md`) に「接地度と陪審団の判定」の節を足す | まだ |

## 段階 0 で分かったこと (0年〜38年、140 季節。v0.5 の計算)

- 村の大人の平均の接地度は、どの季節も **0.76〜0.88**。テックツリーの農民 (N03) の 0.72 より高い。ほとんどの日が採集 (延べ 7 万日をこえる) で、採集は狩猟採集民に近い値になるため
- G6 (交易・町・記録) に入って、平均は 0.82〜0.83 と少し下がった。まだだれも「記録をつける」をしていない。記録をつける人が出ると、その人は 0.33 前後になるはず (書記の 0.31 に近い値)

## 仕事ごとの値 (`sim/society/grounding.py`)

職務特性モデルの評定 (1〜7) は Claude が尺度の定義に沿って付けた【評定】、身体は O*NET の近い職業の実データか推定。理由と出どころは `grounding.py` の表にある。

| 仕事 | 多様性・完結性・重要性 | フィードバック | 身体 (出どころ) |
|---|---|---|---|
| 採集 | 5・7・6 | 7 | 0.80 (推定) |
| 狩り | 6・6・6 | 7 | 0.80 (推定) |
| 探索 | 5・4・5 | 4 | 0.75 (推定) |
| 道具づくり・土器づくり | 5・7・5 | 6 | 0.64 (O*NET 家具職人) |
| 火おこし | 3・6・5 | 7 | 0.50 (推定) |
| 住まいを建てる | 6・6・6 | 6 | 0.68 (O*NET 建設作業員) |
| 種まき | 3・4・5 | 2 | 0.76 (O*NET 農作業員) |
| 畑仕事 | 5・6・5 | 5 | 0.76 (O*NET 農作業員) |
| ヤギの世話 | 5・5・5 | 6 | 0.75 (O*NET 農作業員・家畜) |
| ヤギを捕まえる | 4・5・5 | 6 | 0.80 (推定) |

休んだ日は数えない。値を変えたら `python3 sim/society/tools/build_records.py` で記録を作り直す (世界は変わらない)。

## 根拠の強さ (正直なところ)

- 身体の軸は実データ。ただし現代の米国の職業で代えている
- 意味と結果の軸は Claude の評定。次は陪審団 (D08) に同じ項目を独立に評定させ、一致度を見る
- 答え合わせ: ブラウナーの産業比較 (印刷 > 化学 > 繊維 > 組立) と順位は合う (ただし評定はその記述を参考にした)。自律性の評定と O*NET の「決める自由」の一致は弱い (順位の相関 0.37)
