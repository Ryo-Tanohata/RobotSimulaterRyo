# 人間性とテックツリー (接地度)

人類史シミュレーターで「時代が変わっても残る人間性」と「機械の人間らしさ」を調べるための設計です。
2026-10-14 に本人と Claude で詰めた内容を、社会シミュレーション (`sim/society/`) に入れはじめたものです。

## ファイル

| ファイル | 中身 |
|---|---|
| `tech_tree.json` | 人類史の 10 ノード (火と道具 → 宇宙居住) と 8 つのライフステージ、接地度・手綱・判定の仕組み (v0.7.0) |
| `design_note.md` | 設計の思想・設計判断 (D01〜D10)・参考文献 (R00〜R31)・未決事項・作業記録。JSON の `refs` の ID はここの見出しに対応 |
| `score_grounding.py` | `tech_tree.json` の接地度を計算して書き込み、ノートの採点表も作り直す |
| `jury/` | 陪審団による職務特性モデルの評定の材料・答え・集計 (`jury/README.md`) |
| `build_viewer.py`・`viewer_template.html` → `index.html` | 2 つを 1 枚で見るページを作る (`python3.13 docs/humanity/build_viewer.py`) |

スクリプトは `PYTHONUTF8=1` を付けて `python3.13` で動かす (本人の PC は `py -3`)。

## 社会シミュレーションとの関係

- 10 ノードは人類史全体の粗い地図。Society 2.0 (村と畑 → 土器と家の倉 → まとめ役 → 町と文字) は、その中の **農耕 (N03)・都市 (N04)・文字 (N05)** を細かく走らせている。`docs/tech_tree_design_draft.md` の村の技術の木は、この 3 ノードの拡大図にあたる
- 接地度は「身体や現場にどれだけ根ざして働いているか」の記述 (0〜1、大きいほど深い。良い・悪いではない)。検証済みの尺度で作る (D06・D10): 意味 = 職務特性モデルの技能多様性・完結性・重要性、結果 = 同フィードバック、身体 = O*NET の「一般的な身体活動」の実データ。自律性 (手綱の余地) は別に出す

- フェーズごとの平均は G1 0.67・G2 0.67・G3 0.68・**G4 0.70**・G5 0.68・G6 0.67。土器づくりと家の倉が始まった G4 がいちばん高い

## 根拠の強さ (正直なところ)

- 身体の軸は実データ。ただし現代の米国の職業で代えている
- 意味と結果の軸は陪審団 12 人の評定の平均。作り手の評定との相関は接地度で 0.95 だが、作り手は全体に高めだった (だから陪審団の平均を使う)
- 陪審員は今も Claude だけ。人物よりモデルの違いのほうが評定を動かす (同じ人物でモデルを変えると 0.64〜0.87 点ずれる。同じモデルで人物を変えると 0.46 点)。ほかの会社のモデルを混ぜるのが次の課題
- 人物は自分と同じ種類の仕事を高く見る (採集民は採集を、書記は書記を)
- 答え合わせ: 陪審団の評定でも、ブラウナーの産業比較 (印刷 > 化学 > 繊維 > 組立) と順位が合う
- トークン: 陪審員 1 人あたり約 7 万 (ほとんどはサブエージェントの起動の分)。12 人とモデルの入れ替えの 2 人で約 100 万
