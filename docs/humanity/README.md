# 人間性とテックツリー (接地度)

人類史シミュレーターで「時代が変わっても残る人間性」と「機械の人間らしさ」を調べるための設計です。
2026-10-14 に本人と Claude で詰めた内容を、社会シミュレーション (`sim/society/`) に入れはじめたものです。

## ファイル

| ファイル | 中身 |
|---|---|
| `tech_tree.json` | 人類史の 10 ノード (火と道具 → 宇宙居住) と 8 つのライフステージ、接地度・手綱・判定の仕組み (v0.6.0) |
| `design_note.md` | 設計の思想・設計判断 (D01〜D10)・参考文献 (R00〜R31)・未決事項・作業記録。JSON の `refs` の ID はここの見出しに対応 |
| `score_grounding.py` | `tech_tree.json` の接地度を計算して書き込み、ノートの採点表も作り直す |
| `build_viewer.py`・`viewer_template.html` → `index.html` | 2 つを 1 枚で見るページを作る (`python3 docs/humanity/build_viewer.py`) |

## 社会シミュレーションとの関係

- 10 ノードは人類史全体の粗い地図。Society 2.0 (村と畑 → 土器と家の倉 → まとめ役 → 町と文字) は、その中の **農耕 (N03)・都市 (N04)・文字 (N05)** を細かく走らせている。`docs/tech_tree_design_draft.md` の村の技術の木は、この 3 ノードの拡大図にあたる
- 接地度は「身体や現場にどれだけ根ざして働いているか」の記述 (0〜1、大きいほど深い。良い・悪いではない)。検証済みの尺度で作る (D06・D10): 意味 = 職務特性モデルの技能多様性・完結性・重要性、結果 = 同フィードバック、身体 = O*NET の「一般的な身体活動」の実データ。自律性 (手綱の余地) は別に出す

## 段階 0 で分かったこと (0年〜38年、140 季節。v0.6 の計算)

- 村の大人の平均の接地度は、どの季節も **0.58〜0.66**。テックツリーの農民 (N03) の 0.72 より低い。ほとんどの日が採集 (延べ 7 万日をこえる) で、陪審団は採集を「まとまった全体を仕上げる仕事」とは見なかった (完結性 3.0) ため
- フェーズごとの平均は G1 0.60・G2 0.59・G3 0.61・**G4 0.63**・G5 0.61・G6 0.60。土器づくりと家の倉が始まった G4 がいちばん高い
- まだだれも「記録をつける」をしていない。記録をつける人が出ると、その人は 0.24 前後になるはず (書記の 0.24 と同じくらい)

## 根拠の強さ (正直なところ)

- 身体の軸は実データ。ただし現代の米国の職業で代えている
- 意味と結果の軸は陪審団の評定。作り手の評定との相関は接地度で 0.91 だが、作り手は全体に高めで、狩猟採集を理想化していた (だから陪審団の平均を使う)
- 陪審員どうしの一致は 0.80〜0.92 と高すぎる。6 人とも同じモデルなので、人物を変えても評定がほとんど変わらない (平板化)。別のモデルや昔の人物を混ぜて広げるのが次の課題
- 答え合わせ: 陪審団の評定でも、ブラウナーの産業比較 (印刷 > 化学 > 繊維 > 組立) と順位が合う
- 陪審団 6 人で 33 の仕事を評定するのに、約 43 万トークンかかった (1 人約 7 万。ほとんどはサブエージェントの起動の分)
