# 要件定義

最終更新: 2026-10-02

## 1. 背景と目的

- 千葉工業大学 fuRo のデモ ([動画](https://www.youtube.com/watch?v=g8abhEHcFA4)) のように、物理エンジンの仮想空間で
  四足ロボットに歩き方を学習させる**シミュレータ**を作る (ロボットそのものではない)
- 学習によって**ロボットが変化していく過程**を、見て分かる**解説付きの動画**にする
- 個人の学習・研究目的。fuRo とは無関係であることを明記する

## 3. 機能要件 (今回の追加分)

### F1. 自然な歩き方 (R12, R13)
- F1-1 お手本 (参照モーション) の歩き方を用意する: 少なくともトロット、できれば歩行 (walk) も
- F1-2 学習の評価に「お手本との近さ」を加える (関節角・足先の軌道・接地のタイミング・胴体の高さ)
- F1-3 学習済みの脳から続けて学習する (最初からやり直さない)
- F1-4 これまでにできるようになったこと (曲がる・壁 1 枚) を忘れない
- F1-5 自然さを数値で確認できる (対角脚の同時接地率、足の持ち上げ高さ、胴体の高さ、お手本との誤差)

### F2. 音声入りの動画 (R11)
- F2-1 字幕に合わせて、ずんだもんの声でナレーションを入れる
- F2-2 ナレーションの長さに合わせて場面の長さを調整する
- F2-3 足音などの効果音 (シミュレーションの接地に同期) と BGM を入れる (いずれも自作)
- F2-4 「VOICEVOX:ずんだもん」のクレジットを動画内と README に表記する

## 4. 非機能要件・制約

| 項目 | 内容 |
|---|---|
| 費用 | 追加費用なし。GPU・有料 API は使わない (CPU 4 コアのクラウド環境、または本人の PC) |
| 権利 | 他者の動画・音楽・モーションデータを無断で使わない。非商用ライセンス (CC BY-NC など) のデータはリポジトリに含めない。VOICEVOX・ずんだもん・公開先の規約を守り、本人の最終確認を経てから公開する ([plan.md の 8 章](plan.md#8-規約権利の確認)) |
| ライセンス | リポジトリは MIT。同梱する第三者ソフトはそのライセンスに従い表示する |
| 正確さ | 字幕・ナレーションには実際に起きたことと実測の数値だけを書く |
| 再現性 | 学習結果 (世代ごとの重み) と台本から、同じ動画を作り直せる |
| 環境の制約 | このクラウド環境では、作業していない間にバックグラウンド処理が止まることがある → 再開機能で対応 |

## 5. 範囲外 (今回はやらない)

- GPU を使った大規模な強化学習 (fuRo のような 4096 体並列)
- 実機ロボット
- 権利を確認できない動物の動画の利用 (パブリックドメイン・CC0/CC BY・本人撮影のものだけを使う)
