# 計画書: 2 足歩行の人たちの社会シミュレーション (狩猟採集から)

最終更新: 2026-10-01 (改訂 2: クラウドだけで行う・機械学習は使わない) / 状態: **計画 (未着手)**

きっかけ: AI エージェントだけの SNS「Moltbook」で、AI が勝手に宗教を作った話
(k_tccn「AIが勝手に宗教を作った話」note, 2026-02-02)。同じように「勝手に文化が生まれる」様子を、
これまでの 2 足歩行シミュレーションの延長で作ってみる。

設計と仮説は **Claude (AI) が立てたもの**です。数値の多くは仮定の値、または文献の値の目安で、実装前に原典を確認します。

---

## 1. 目的と方針

- 目的は **「それっぽいもの」を作ること** (見て面白く、納得できるシミュレーションとアプリ)。学説や歴史の検証ではない
- **模倣** (既に知られた人間の行動・歴史を与えて再現したもの) と **創発** (教えていないのに、経験から生まれたもの) を区別して見せる
- **クラウドだけで行う** (本人の方針、2026-10-01): GPU・ローカルのモデルは使わない。スケジュール実行した Claude Code が動かす (サブスクの枠内)
- **機械学習 (ニューラルネットの訓練) は使わない**。代わりに、キャラクターが **知識と掟を文章で更新していく「学び」** で変化を作る (5 章)
- 段階:
  1. **狩猟採集** (Society 1.0) … 最初はここだけ
  2. 農耕の芽生え (2.0) … 経験から生まれる上限の目安
  3. 工業・情報・Society 5.0 … 段階を人が与えるモデル (模倣として明示)
  4. 宇宙へ … ヒューマノイドや AI が主役の簡単なモデル (模倣として明示)

## 2. 全体の構成

| 階層 | 中身 | どこで動くか |
|---|---|---|
| 0. 体 | 物理で歩く 2 足歩行 (今までの成果) | 動かさない。**実測した値** (歩く速さ、1 m あたりのエネルギー) と **録画した歩く動画** だけを使う |
| 1. 世界 | 2 次元の地図で、人・動物・植物が暮らす。移動・空腹・採集・昼夜・季節 | クラウドの Python (CPU で数秒) |
| 2. 頭 | その日の行動・会話・振り返り・知識と掟の更新 | クラウドの **Claude** (1 人ずつ別のサブエージェント) |

- 1 時間ごとの細かい動き (目的地へ歩く、食べる、寝る) は、**決まった手順** (4.3) で自動処理する。Claude は「今日なにをするか」「誰に何を話すか」「何を学んだか」を決める
- Claude Agent SDK はサブスクで使えない (API キーが必要) ため使わない。Ollama も使わない

## 4. オブジェクトとパラメータ

値の出どころ: 【体】= 2 足歩行の実測、【文献】= 狩猟採集民 (主に Hadza) の研究の目安 (要確認)、【仮定】= Claude が決めた値。

### 4.3 決まった手順 (1 時間ごとの自動処理)

Claude が決めた「今日の行動」を、世界の中で次のように実行する。これは物理や生理のルールで、行動の中身 (誰に分けるか等) は含まない。

- 目的地へ歩く (速さとエネルギーは【体】)、見つけた食べ物を採る・運ぶ、食べる・飲む、夜は寝る
- 動物は決まった動き (獲物は逃げる、捕食者は夜に近づく)
- 植物は季節で実り、採ると減り、時間で回復する。**落ちた種から育つ** (農耕の芽生えのきっかけとして用意するだけで、教えない)

## 5. 学び: 知識と掟の更新 (機械学習の代わり)

### 5.1 仕組み

| 種類 | 中身 (文章) | 更新のされ方 |
|---|---|---|
| **個人の知識** | 「川の東は秋に木の実が多い」「ウは獲物を分けてくれた」 | 毎晩の振り返りで追加・修正・削除。当たったら確信度を上げ、外れたら下げる |
| **技** | 「石を割ると鋭くなる」「火のそばは夜に安全」 | 試して成功したら技能が上がり、知識になる |
| **伝承** | 他人から聞いた知識 | 会話で伝わる。誰から聞いたかを記録 (広がり方を図にできる) |
| **集団の掟** | 「大きな獲物は皆で分ける」 | 誰かが提案 → 集まりで話し合い → 賛成が多ければ採用。守られなければ見直し・廃止 |
| **受け継ぎ** | 子どもは親の知識の一部と、集団の掟を受け継ぐ | 誕生・成長のとき |

### 5.2 1 日の流れ (1 回のスケジュール実行)

```
1. 朝: 各キャラクター (Claude) が、状況・知識・掟から今日の行動を決める
2. 昼: 世界を 1 時間ずつ進める (4.3 の決まった手順、Python)
3. 出来事: 近くにいる人どうしが会話する (Claude)。分け合い・もめごとなど
4. 夜: 各キャラクターが今日を振り返り、知識を更新する (Claude)
5. (7 日ごと) 集まり: 掟の提案・採用・見直し (Claude)
6. 記録: 世界の状態・会話・出来事・知識と掟の変化を保存し、アプリに反映
```

### 5.3 機械学習との違い (参考)

| | 機械学習 (今回は使わない) | 知識と掟の更新 (今回の方法) |
|---|---|---|
| 変わるもの | 脳の中の数値 | 文章の知識・掟 |
| 必要な計算 | GPU で長時間 | クラウドの Claude で 1 日 1 回 |
| 中身が読めるか | 読めない | 全部読める (いつ・誰が・なぜ変えたか) |
| 人間の知識の影響 | ない (創発が最もきれい) | ある (Claude は人類の文化を知っている) → 6 章の見分け方で対処 |

## 6. 模倣と創発の見分け方

- 知識・掟には、**きっかけになった出来事** (世界の記録の何日目の何) を必ず結び付ける
- ラベル:
  - **創発**: 世界で起きた出来事から生まれ、最初に与えた知識にないもの
  - **模倣と一致**: 最初に与えた知識 (下の一覧) と同じもの
  - **知識の再現の疑い**: きっかけの出来事が弱いのに、人類の既存の文化に似たもの (Claude の知識から来た可能性)
- 最初に与える知識 (模倣の基準。試作ではこれだけ与える):
  1. 食べると空腹が減る、水を飲むとのどの渇きが減る
  2. 夜は捕食者が出る
  3. 名前で呼び合える
- 現実の言葉 (地名・「宗教」「王」など) は与えず、架空の名前を使う
- 観察する指標: 分け合いの割合、集団のまとまり、役割の偏り、掟の数と寿命、呼び名・物語の広がり、種まきの有無

## 7. アプリ (画面)

データを保存できる Web ページ (サロンアプリと同じ仕組み)。スマホでも見られる。

1. **地図**: 上から見た世界。人・動物・植物・キャンプ。日付と季節
2. **人の一覧**: 名前、年齢、性格、技能、空腹、最近の行動、知識の数
3. **会話と出来事**: 時系列
4. **知識と掟**: 誰が・いつ・どの出来事から学んだか、ラベル (創発 / 模倣と一致 / 知識の再現の疑い) 付き。掟の提案・採用・廃止の履歴
5. **グラフ**: 人口、食べ物、分け合いの割合、知識と掟の数
6. **歩く姿**: 2 足歩行の録画 (人物をタップすると再生)

## 8. 試作 (最初に作るもの)

- 5 人、2 km 四方、狩猟採集のみ
- 1 日 1 回のスケジュール実行で 1 日分進む (5.2)
- アプリ: 地図・人の一覧・会話と出来事・知識と掟
- まず 1 週間 (7 回) 動かして、面白さと利用量を確認する

利用量の安全策: 1 回の実行で使う量を記録し、多ければ人数・会話の回数を減らす。この会話や開発作業と同じサブスクの枠を使うことに注意。

## 10. リスクと対策

| リスク | 対策 |
|---|---|
| サブスクの利用上限にかかる、開発作業が止まる | 試作は 5 人・1 日 1 回。1 回ごとの利用量を記録 |
| 知識や掟が「人類の歴史の再現」ばかりになる | 架空の名前、最初の知識を最小限に、きっかけの出来事の記録とラベルで明示 |
| スケジュール実行の途中で失敗して世界が壊れる | 1 日分ずつ保存 (Git の履歴で戻せる)。失敗したら前の日の状態のまま |
| 面白くならない | 1 週間で振り返り、出来事が起きやすい設定 (季節の不作・獲物の群れ・捕食者) を足す |
