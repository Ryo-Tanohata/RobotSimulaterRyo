# 計画書: 2 足歩行の人たちの社会シミュレーション (狩猟採集から)

最終更新: 2026-10-01 / 状態: **計画 (未着手)**

きっかけ: AI エージェントだけの SNS「Moltbook」で、AI が勝手に宗教を作った話
(k_tccn「AIが勝手に宗教を作った話」note, 2026-02-02)。同じように「勝手に文化が生まれる」様子を、
これまでの 2 足歩行シミュレーションの延長で作ってみる。

設計と仮説は **Claude (AI) が立てたもの**です。数値の多くは仮定の値、または文献の値の目安で、実装前に原典を確認します。

---

## 1. 目的

- 目的は **「それっぽいもの」を作ること** (見て面白く、納得できるシミュレーションとアプリ)。学説や歴史の検証ではない
- そのうえで、次の 2 つを **区別して見せる**:
  - **模倣**: 既に知られている人間の行動・歴史を、ルールや知識として与えて再現したもの
  - **創発**: 教えていないのに、仕組みから勝手に現れたもの
- 段階:
  1. **狩猟採集** (Society 1.0) … 最初はここだけ
  2. 農耕の芽生え (2.0) … 創発で狙える上限の目安
  3. 工業・情報・Society 5.0 … 段階を人が与える抽象的なモデル (模倣として明示)
  4. 宇宙へ … ヒューマノイドや AI が主役の簡単なモデル (模倣として明示)

## 2. 全体の構成

### 2.1 3 つの階層

| 階層 | 中身 | 今までの成果とのつながり |
|---|---|---|
| 0. 体 | 物理で歩く (MuJoCo) | 人間らしい歩き方 (`sim/bipedal`, human2) から、速さと 1 m あたりのエネルギーを測って上へ渡す。拡大表示で実際に歩かせる |
| 1. 個体と生態系 | 2 次元の地図で、人・動物・植物が暮らす | 移動のコストは階層 0 の値 |
| 2. 頭 (意思決定と文化) | 何をするか、誰に何を話すか | 下の A / B / C を切り替える |

### 2.2 頭の 3 種類

| 種類 | 作り方 | 模倣か創発か |
|---|---|---|
| **A. ルール** | 既知の狩猟採集民の行動を Claude がルールとして書く (4.2 の一覧) | 模倣 (基準) |
| **B. 学習** | 社会のルールは書かない。空腹・生存・子孫だけを与え、進化・強化学習で行動を学ぶ (GPU) | 創発 |
| **C. 言葉 (LLM)** | キャラクターごとに性格と記憶を持ち、言語モデルが行動と会話を決める | 創発と模倣が混ざる (LLM は人類の知識を持つため) |

### 2.3 動かす場所 (2 通り、世界のデータ形式は共通)

| | ローカル版 (GPU のパソコンがあるとき) | クラウド版 (ないとき) |
|---|---|---|
| 頭 | A・B、C は無料のローカルモデル (`transformers` / `vLLM`、ライセンス確認のうえ選ぶ) | C = **Claude 自身** (スケジュール実行した Claude Code がキャラクターを演じる) |
| 進む速さ | 速い (何年分も) | 1 回の実行で 1 日分など、ゆっくり |
| 費用 | 電気代のみ | サブスクの枠内 (追加費用なし) |
| 向いていること | 長期間の変化・統計 | 物語として面白い会話・決まりごと・神話 |

- Claude Agent SDK はサブスクで使えない (API キー必須) ため使わない。ローカルから Claude を呼ぶ場合は `claude -p` (サブスク)
- Ollama は使わない (本人の希望)

## 3. 世界の設定 (試作)

| 項目 | 試作の値 | 本番の目安 |
|---|---|---|
| 地図 | 2 km × 2 km、25 m 四方のマス (80 × 80) | 10 km × 10 km |
| 時間 | 1 ステップ = 1 時間、昼と夜 | 季節 (1 年 = 4 季節) |
| 地形 | 草原・林・川・丘 (自動生成、乱数の種で再現できる) | 同左 + 気候の変化 |
| 人数 | 5 人 (クラウド版) / 30 人 (ローカル版) | 1 集団 約 30 人 → 数集団 150 人 |
| 期間 | クラウド版: 1 回の実行で 1 日分 / ローカル版: 1 年分 | 数十年 |

## 4. オブジェクトとパラメータ

値の出どころ: 【体】= 階層 0 の実測、【文献】= 狩猟採集民 (主に Hadza) の研究の目安 (要確認)、【仮定】= Claude が決めた値。

### 4.1 人間 (狩猟採集民)

| 分類 | パラメータ | 試作の値 | 出どころ |
|---|---|---|---|
| 体 | 体重 | 45〜55 kg (個人差) | 【文献】 |
| | 歩く速さ | 0.6〜1.4 m/s | 【体】human2 |
| | 1 m あたりのエネルギー | 速さに応じて (0.6 m/s で 1.33、1.4 m/s で 1.94、モデルの単位) | 【体】※筋肉の消費そのものではないので、換算の係数は【仮定】 |
| | 運べる量 | 体重の 20〜30% | 【仮定】 |
| | 見える距離 | 昼 200 m、夜 30 m | 【仮定】 |
| エネルギー | 1 日の消費 | 約 1,900〜2,600 kcal | 【文献】 |
| | 空腹・のどの渇き・疲れ | 0〜1 の値。上がると体力が落ち、限界で死亡 | 【仮定】 |
| 一生 | 大人になる年齢 | 約 15 歳 | 【文献】 |
| | 出産の間隔 | 約 3〜4 年 | 【文献】 |
| | 寿命・子どもの死亡率 | 大人は 60〜70 歳まで生きることも多い / 子どもの死亡率は高い | 【文献】 |
| 性格 (遺伝する) | 協力しやすさ・大胆さ・好奇心・社交性 | 各 0〜1 | 【仮定】 |
| 技能 (使うと上がる) | 採集・狩り・道具づくり・火 | 各 0〜1 | 【仮定】 |
| 記憶 | 食べ物の場所、危険な場所、他人への信頼 (貸し借り) | 最近の 50 件 + 要約 | 【仮定】 |
| 言葉 (C のみ) | 話せる距離、覚えている会話、名前、呼び名 | 話せる距離 30 m | 【仮定】 |

### 4.2 A (ルール = 模倣) で書く行動の一覧

B・C で同じ行動が現れたら「創発」とは数えず、「模倣と一致」と記録するための一覧。

1. 大きな獲物は集団で分ける
2. 集団で移動し、夜は同じ場所で休む (キャンプ)
3. 役割分担 (狩り・採集・子育て)
4. 食べ物の場所を仲間に教える
5. 子どもは親や集団が育てる
6. 資源がなくなったらキャンプを移す

### 4.3 そのほかのオブジェクト

| オブジェクト | 主なパラメータ | 役割 |
|---|---|---|
| 植物 (木の実・芋) | 実る季節、量、回復の速さ、見つけにくさ | 主な食べ物。採ると減る |
| 動物 (獲物) | 体の大きさ、逃げる速さ、群れ、増え方 | 大きな食べ物。1 人では捕りにくい → 協力の理由になる |
| 動物 (捕食者) | 危険度、活動する時間 (夜) | 危険。集団でいる理由になる |
| 水場 (川) | 位置、季節の水量 | のどの渇き |
| 道具 | 石器・槍・入れ物・火 | 作る手間と効果 (狩りの成功率、運べる量、夜の安全) |
| キャンプ | 位置、火、寝床 | 集まる場所 |
| (後半) ヒューマノイド | 電池、充電、速さと電力 (階層 0)、運べる量、故障、製造で増える | Society 5.0・宇宙の段階 |
| (後半) AI (体なし) | 知識、助言 | Society 4.0〜5.0 の段階 |

## 5. 模倣と創発の見分け方

| 観察すること | 測り方 |
|---|---|
| 分け合い | 自分で取った食べ物を他人に渡した割合 |
| 集団 | 近くにいる人どうしのまとまり (クラスター) の大きさと続く時間 |
| 役割分担 | 人ごとの行動の偏り (狩りばかり、採集ばかり) |
| 縄張り | 集団ごとの行動範囲の重なり |
| 決まりごと・呼び名・神話 (C) | 会話から繰り返し出てくる言葉や決まりを抜き出し、誰から誰へ広がったか |
| 農耕の芽生え | 種を意図的に同じ場所に落とす行動 (「種から育つ」仕組みだけ用意する) |

判定のラベル: **創発** (4.2 に無く、教えていない) / **模倣と一致** (4.2 と同じ) / **知識の再現の疑い** (C で、既存の人類文化の概念に似ている)。
C では現実の言葉 (地名・「宗教」「王」など) を与えず、架空の名前を使う。

## 6. アプリ (画面)

データを保存できる Web ページ (サロンアプリと同じ仕組み)。スマホでも見られる。

1. **地図**: 上から見た世界。人・動物・植物・キャンプ。日付と季節
2. **人の一覧**: 名前、年齢、性格、技能、空腹、最近の行動
3. **会話と出来事**: 時系列 (「ア が大きな獲物を分けた」「イ が川の名前を付けた」)
4. **生まれたもの**: 決まりごと・呼び名・物語。ラベル (創発 / 模倣と一致 / 知識の再現の疑い) 付き
5. **グラフ**: 人口、食べ物、分け合いの割合、集団の大きさ
6. (あれば) **拡大映像**: 棒人間が実際に歩く場面 (階層 0)

## 7. クラウド版 (スケジュール実行) の流れ

```
[決まった時刻に、クラウドの Claude Code が起動]
 1. 世界の状態を読む (リポジトリの JSON またはアプリのデータベース)
 2. 世界を 1 日分進める (移動・採集・食事・動物。Python、CPU で数秒)
 3. 各キャラクターの今日の行動と会話を決める
    - 1 人ずつ別のサブエージェントに考えさせる (互いの心の中を見ないように)
    - 答えは決まった形 (JSON): 行動 / 話すこと / 覚えること
 4. 行動を世界に反映し、出来事と会話を記録する
 5. アプリのデータを更新する (リポジトリにもコミット)
```

利用量の安全策: 試作は 5 人・1 日 1 回。1 回の実行で使う量を記録し、多ければ人数や頻度を減らす。
この会話や開発作業と同じサブスクの枠を使うことに注意。

## 10. リスクと対策

| リスク | 対策 |
|---|---|
| サブスクの利用上限にかかる、開発作業が止まる | 試作は 5 人・1 日 1 回。1 回ごとの利用量を記録 |
| C が「人類の歴史の再現」ばかりになる | 架空の名前、現実の言葉を与えない、ラベルで明示 |
| スケジュール実行の途中で失敗して世界が壊れる | 1 日分ずつ保存 (Git の履歴で戻せる)。失敗したら前の状態のまま |
| 面白くならない | 1 週間で振り返り、出来事が起きやすい設定 (季節の不作・獲物の群れ) を足す |
