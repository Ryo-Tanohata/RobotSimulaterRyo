## 1. 変えたこと (どれも選んだときだけ働く。選ばなければ G1〜G7 は前と 1 バイトも同じ)

### 1.1 決める段の数え方 "v2" (`g7.count = "v2"`)

- わけ: 実験 A2 で、本物の村の数え方では、村の役の人の下がいつも「村の家々」だけ (`yardstick.py` の `officials`) なので、
  村の段が A1 (地域だけ) の数え方より 1 つ低く出ることがわかった (`state_emergence_A2.md` 3.)。v2 は、村をまわりの集落と同じに数える。これで A1 の c1 の数がそのまま当てはまる。
- `yardstick.levels` は、v2 のとき `region.levels(..., village_rules=True)` を呼ぶ (`yardstick.py:51`)。
- `region.levels` (`region.py:899`): 村の役の段 (org。`g7._v0_org` = この 1 年に「取り立てる」か「守る」を 20 日以上した役の人がいれば 2、まとめ役だけなら 1) が 2 以上で、
  貢いでくる集落があれば、村の長の下に、貢いでくる集落みなを下にもつ役 ("役", "V0") を置く (まわりの集落と同じ)。このとき役の人 (officials) の数え方はとばす。
  貢いでくる集落がないか org が 2 より下なら、前のまま (役の人の数え方)。`village_rules` を渡さないときは前と同じ。
- 例 (試し `R_CountV2World.test_levels_v2`): 村 org 2 + 貢ぐ集落 2 → 段 2 (前は 1)。そのうち 1 つが 2 つの集落に貢がれていれば → 段 3 (前は 2)。org 1 → 前と同じ。貢ぐ集落なし → 前と同じ。

### 1.2 世界の選び (`g7.world = {"desert": true, "no_flee": true}`)

- A1 の「中間」の世界 = G7 のまま (K の 10%) + 草原を砂地に (住めない) + 逃げ場なし。A1 の `lab_region.py` の差しかえ (circ "nofl") を、本物の道に入れた。
- `region.DESERT` (`region.py:53`): 草原 (s) の K を 0 にし (`region._k`・`cap`・`kcap`)、ますの一覧 `cells` から除く。はじめに置く人数は、今の地図の K の割合のまま (`g7.enter` が `fill_cells(target=…)` で渡す。A1 と同じ)。
- `region.NO_FLEE` (`region.py:54`): 逃げ場 `refuge` がいつも None (まわりの集落は求められても逃げられない。囲まれている)。
- `g7.sync_world` が、state の `g7.world` を region に入れる (`g7.region_on` と `new_other` と `enter` から。鍵がなければ両方 False)。
- **村にとっての「逃げ場なし」** (書いておくこと):
  - 村ごと逃げることは、もとからない (`region.py:593`。村の「逃げる」は家ごとに出ていくこと)。
  - 家ごとに村を出る答え (leave。求め・貢ぎ・取り立てから逃れて出ていく) は、欄も決まりの文も出さず、書いても何もしない (`g7._leave_on`)。
  - 求めへの答えから「逃げる」を外す (お題の欄と決まりの文。`g7.NO_FLEE_TEXT`。書いても数えない `g7.village_answers`)。決まりの文は「払う・戦う・ほかの村に助けを頼む のどれかを選ぶ (まわりに空いた住める土地はなく、逃げる道はない)」になる。
  - そのまま残すもの: もめごとが収まらずに家が分かれる G5 の決まり (`era2._split`)・ききんで、よそから来た空腹の大人が去る決まり (`era2._famine_leave`)。どちらも求めから逃げることではないので。分かれた家の集落は、砂地でないますに置かれる。
  - 村のまわり (80 × 80 の村の地図。草原の採集など) は変えない。砂地にするのは地域の地図 (11 × 11 のます) の草原だけ。
