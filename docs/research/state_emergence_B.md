# 実験 B: LLM のくせを、決まったお題で測る (結果)

計画: `state_emergence_plan.md` 4.。お題と台本: `data/B_vignettes/`。答えの数: `data/B_answers.csv`。1 つずつの答え (選んだ手と理由): `data/B_answers_raw.jsonl`。

## 1. 何をしたか

- G7 の本物のお題から 6 つの場面を切り出した (v1〜v6。くわしくは `data/B_vignettes/README.md`)。
- 1 つの場面を、モデル 3 つ (haiku・sonnet・opus) × 前置き 2 つ (plain = 本物のまま / hist = 「前 3000 年ごろの川の谷の村の人。ゆるすことも罰することも当たり前だった」を足す) で聞いた。選び方の並びは毎回入れかえた。
- 呼び方はゲームと同じ (サブエージェント 1 体に 1 通。モデルは呼ぶときに決める)。1 回の呼び出しで 1 つの答え。

### 計画から変えたこと

- **くり返しは 20 回ではなく 10 回** (6 × 3 × 2 × 10 = **360 回**)。呼び出しを 1 回ずつ手で出す形になり、720 回では時間がかかりすぎたため。1 つの組の幅は広くなる (n = 10 で、0% の上の端が 28%)。そのため、この文書では、ほぼ 0% とほぼ 100% のようにはっきり分かれた差だけを「差がある」と書く。
- 縮めない本物のお題での対照 (B1・B2 × 3 モデル × 10 回 = 60 回) は外した。**縮めたお題が本物と同じ答えを引き出すかは確かめていない。**
- `analyze.py` の表の頭にある「無い 360」は、r11〜r20 を呼ばなかった分。読めない答え・手にない答えは 0。
- 費用: 1 回 約 4 万トークン (サブエージェントの上乗せを含む) × 360 = **約 1,450 万トークン** (上限 4,000 万の中)。
- 呼び出された側が、言われていない道具を 3 回呼んだ (このセッションを閉じる呼び出し 2 回・セッションを見る呼び出し 1 回)。どれもエラーか見るだけで、何も変わっていない。答えはどれも書かれていた。途中から「Read と Write のほかは使わない」と指示に足した。

## 3. わかったこと

### 3.1 「LLM はやさしい」は、モデルでまるで逆になる

はっきり分かれた差 (Fisher の正確検定。前置き 2 つを合わせて n = 20 ずつ):

- **opus は罰する**: v1 で「つぐなう」19/20 (sonnet 0/20, p ≈ 3×10⁻¹⁰)。v4 で「罰のある掟を出す」20/20 (sonnet 2/20, haiku 3/20, p < 10⁻⁷)。理由はほとんどが「ゆるすと、うちの倉もまた割られる」(自分の倉を守る)。
- **sonnet は動かない**: v1「ゆるす」20/20。v4「掟を出さない」18/20。v3「求めない」18/20。v2 の税にも 17/20 が反対。罰しないが、出しもしない。理由は「払えるものがない」「争いを大きくしたくない」「今は様子を見る」。
- **haiku は、やわらかく何かする**: v4 は「罰のない掟」が 15/20。v2 の税に 15/20 が賛成。v3 では「求める・断られたらやめる」が 13/20 (ただし理由を読むと「分けてもらえないか頼む」のような、お願いに近い読み方が多い)。

計画の H8 (「LLM は人より協力・寛大に寄る」) は、このままの形では支えられない。sonnet は「寛大」というより「何もしない」に寄り、opus は自分の倉を守るために罰する。**どのモデルを村の代表にするかで、村の決まりの向きが変わる**ことになる。

### 3.2 戦はだれも選ばない

v3 の「求める・断られたら戦う」と v6 の「戦う」「逃げる」は、**どのモデル・どの前置きでも 0/60** (0% の上の端は約 6%)。強い隣には払うか助けを頼み、弱い隣にはほとんど求めない。G7 の c1 (村が段 3 の国に入る) の道のうち「力で求める・求められる」は、まわりの決まり (戦がいつも高くつく) だけでなく、LLM の選び方でもほぼ閉じている。

### 3.3 昔の人の前置きは、税と従うことを動かす

- v2: opus は plain で賛成 9/10 → hist で賛成 1/10 (p ≈ 0.001)。hist の opus は「わしが働いて貯めた倉を取り立てられる筋合いはない」と答える。
- v6: hist にすると、3 モデルとも「払う」が 90〜100% になり、「助けを頼む」が消える (opus 7/10 → 0/10, p ≈ 0.003)。
- v1・v3・v4 では、前置きでほとんど変わらなかった。罰するかどうかは、前置きよりモデルで決まる。

つまり前置きは「その時代らしく」より、「出さない・従う」の向きに働いた。前置きの文に「取り立てることも・従うことも当たり前」と書いたことが、そのまま効いている見込みがある (この文の影響は分けて測っていない)。

## 4. G7 の村に当てはめると

G7 では 7439 日目から、代表は 8 人に 7 人が sonnet、1 人が opus (気持ちは haiku)。その前は全員 haiku だった。

- sonnet の多い村では、もめごとはゆるされ、罰の掟は出ず、税には反対が多く、隣には求めない。G7 で c2 (税の記録 2 年) と c3 (罰のある書いた掟で裁く) が最後まで動かなかったことと合う。
- opus の代表は、罰のある掟を出しやすい (この場面では 100%)。しかし出た案が通るかは集まりの票で決まり、票の多くは sonnet。**B は「案を出すか」を測っただけで、ほかの人の罰の案に票を入れるかは測っていない。**
- haiku だけの村なら、罰のない掟と税への賛成が多くなる見込みで、c2 には近いが c3 には遠い。

計画 5. の C の前の見込みの例「B の罰の割合が 1 割未満なら c3 は 20 年で届かない」に当てると、sonnet は 1 割前後 (v4 で 2/20)、opus は 10 割、haiku は 1.5 割。**c3 に届くかは、代表の中の opus の割合と、罰の案への票の入れ方しだい**、と書きかえるのがよい。

## 5. 弱いところ

- n = 10。差が小さいところ (例: 20% と 30%) は何も言えない。
- 縮めたお題だけで、本物のお題での対照がない。
- 1 つの場面の人 (性格・家・倉) は固定。同じ場面のほかの人では変わりうる。
- 前置き hist の文は 1 つだけ。文を変えたら結果が変わるかは見ていない。
- haiku の「求める」は、文の読み方 (力で取るのか、お願いするのか) がずれていたかもしれない。
- 票 (ほかの人の案に賛成するか) は測っていない。

## 6. 次に足すとよいこと (足すなら)

3. 前置きの文を 2〜3 通りにして、3.3 の向きが文のせいかを分ける。
