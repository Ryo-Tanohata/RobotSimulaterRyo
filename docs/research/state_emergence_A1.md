# 実験 A1: 地域だけで、どの世界なら「段 3」ができるか (結果)

計画: `state_emergence_plan.md` 3.1 (と 9. の 1・3)。コード: `sim/society/tools/lab_region.py`。1 回ずつの数: `data/A1_runs.csv.gz` (86,400 行。列は 1. の終わり)。
書いたのは Claude (2026-10-23)。トークンは使っていない。数はみな【シ】(この模型の中の数。史実の数ではない)。

## 0. まとめ (先に)

- **c1 (村が段 3 のまとまりにいる) は、ほとんど「村が自分から求めるか」で決まる。** ほかを平均すると、村が求めないと 20.4%、まわりと同じ決まりで求める (1.5 倍強いときだけ・1 年 0.3 の見込みで動く) と 89.7%、いつも求めると 97.6% (60 年のうちに一度でも)。20 年までなら 2.9%・46.4%・88.7%。
- **世界の形 (埋まり・強さ・囲み・水路・日照り) だけでは、c1 はほとんど動かない。** 村が求めず、分かれた家のつながりもないと、c1 は 3.1% (72 の世界の組で 0%〜27.5%。25 組は 0%)。そのときの c1 は、みな「村がまわりのまとまりに貢ぐ側として入った」もの (中身を見た 200 回のうち 200 回)。
- **いちばん効いた世界の要因は「逃げる手がない」(砂地 + 逃げる手なし)。** 地域のどこかの段 3 は 88.6% → 99.0%、c1 は 66.6% → 77.3%。ただし草原を砂地にしただけでは、逃げ場はほとんど残り (囲まれていた答えは 10%)、段 3 はかえって少し減った (85.7%)。
- **案 d (村を出た家の集落が親村に貢ぐ) を入れると、村が求めなくても c1 が 3.1% → 37.7% になる。** 逃げる手がない世界では 64.8%。ただし中身は、5〜10 人の「村を出た家の集落」どうしが貢ぎあってできた段 3 (見た 200 回のうち 92% は、村のほかは村を出た家の集落だけ。村のほかの人は真ん中で 24 人)。物差しの「国」とよぶには小さすぎる (3.5)。
- **地域のどこかの段 3 は、ほとんどの世界でできる** (全体 91.1%)。下げるのは日照り 0.35 (96.6% → 85.5%) と水路の代わり (92.6% → 89.5%)。上げるのは、逃げる手なし・まわりの人数 2 倍・30% の埋まり。
- **戦は、86,400 回で 16 回だけ** (みな「逃げる手なし + 大きい隣 + 村がいつも求める」の組)。決まりの損のくらべでは、戦がほとんど選ばれない (G7_sweep.md と同じ)。H2 (戦が大きなまとまりを作る) は、この模型では試せていない。
- **大きい隣 (村の 2 倍) を置いても、村は求められない。** 大きい隣は、いちばん弱い相手に求める決まりなので、村 (強い) を選ばない。村に求めが来た回は全体の 1.7%。
- **G7 にいちばん近い組** (K の 10%・今のまま・求めない・つながりなし・水路なし・日照り 0.2) は、c1 2.0% (0.8%〜5.0%)・地域のどこかに段 3 74.0% (年の真ん中 25 年。22 年までなら 32%)。G7 で地域に段 3 ができなかったのは、この見込みの中で起きうること。

## 1. 何をしたか

- 回したもの: `region.py` の 1 年の決まり (4.B.3) だけ。土台は `tools/region_sweep.py` (G7_sweep.md)。川辺の村は「決まりで動く集落」(V0)。世界 (era2・world) は動かさない。
- はじめの state: G7 に入る前の 5849 日目 (`git show e436dfc^:sim/society/data/state.json` を /tmp に写して読んだ。村 151 人・まわり 3 集落 43 人)。まわりの置き方は G7 と同じ `fill_cells` の決まりで、種ごとの列 (G7_sweep と同じ)。
- 要因 (計画 3.1 の表)。2 × 3 × 3 × 3 × 2 × 2 × 2 = **432 組 × 種 200 = 86,400 回 × 60 年**。どの組も同じ種の列を使う (組どうしのちがいは要因だけ)。

| 要因 | 水準 | どう作ったか (試しのプロセスの中だけ) |
|---|---|---|
| まわりの埋まり | K の 10% (G7)・30% | はじめの集落の人数 (村を除く) を、今の地図の K の合計 5,000 人の 10%・30% にする |
| まわりの強さ | 今のまま・大きい隣 1 つ・まわりの人数 2 倍 | 大きい隣: 村の 2 倍 (302 人) の集落を、村から 2 ます北の川ぞい (5,3) に置く。村と同じく、地図の K で減らず、決まりで分かれない。2 倍: はじめのまわりの集落の人・蓄え・ヤギを 2 倍 |
| 囲み | 今のまま・草原を砂地・砂地 + 逃げる手なし | 砂地: 草原 (64 ます) の K を 0 にし、住めない (置かない・分かれない・逃げない)。置く人数は今の地図の割合のまま (空いた土地だけが減る)。逃げる手なし: 逃げ場をいつも「なし」にする |
| 村の求め | 求めない・1.5 倍強いときだけ・いつも | 1.5 倍: まわりと同じ決まり (1 年 0.3 の見込みで動き、自分がいちばん弱い相手の 1.5 倍強いときだけ)。いつも: 毎年、1.2 倍 (region_sweep の「いつも求める」) |
| 分かれた家と親村 | つながりなし (G7)・親村に貢ぐ (案 d) | 村を出た家 (5 人) の集落が、次の夏から村に貢ぐ (量は求めと同じ、余りの 2 割)。やめるかは決まりのまま |
| 水路の代わり | なし・段 1 以上で川ぞい満額 | 川ぞいの集落は、役の段が 0 なら余りが雨で育つ畑と同じ (100 → 70) |
| 日照り | 悪い年 0.2 (今)・0.35 | 地域が悪い年になる見込み |

- どの組にも入れたこと【仮定】: 村の家が出ていく見込み 1 年 0.25 (1 回 5 人)。G7 で村を出た家は 22 年で 27 人 (1 年 約 1.2 人) なので、それに合わせた。このため 60 年後の村は平均 103 人 (はじめ 151 人) に減る。
- 確かめ: 足した要因を「今のまま」にし、出ていく見込みを region_sweep と同じにすると、`region_sweep.run` と同じ数になる (`lab_region.py check`。24 回のうち 24 回同じ)。G7_sweep の 10%・求めない・出ていく 0.15 の行 (c1 2%・地域に段 3 74%) と、この G7 に近い組 (c1 2.0%・74.0%) も合う。
- 時間: CPU 合計 8.2 時間。2 つのプロセスで、入れ物の再起動をはさんで約 4 時間 15 分 (途中から続けた)。
- 本物の `sim/society/data/state.json` の sha256 は、はじめと終わりで同じ (5c1bf5fc…9442)。region.py・g7.py・era2.py・yardstick.py は変えていない。

1 回ずつの数 (`A1_runs.csv.gz`) の列: 要因 7 つ・seed・reach (c1 に届いた)・reach_yr・any3 (地域のどこかに段 3)・any3_yr・maxD (段の最大)・vmaxD (村のいるまとまりの段の最大)・wars・flee・breaks (崩れ)・gone (なくなった集落)・dec (求めへの答え)・boxed (そのうち逃げ場がなかった)・dem (求めの数)・v_dem_out / v_dem_in (村が出した・村に来た求め)・v_trib_end (60 年後に村へ貢ぐ集落)・kids_trib_paid (村を出た家の集落が 1 年に貢いだ数の最大)・setts_end・people_end (60 年後のまわりの集落と人)・v0_end (村の人)・secs (CPU 秒)。

## 2. 数え方

- **c1**: 決める段 D (4.D.2。この 1 年に払った記録のある貢ぎだけ) が 3 以上のまとまりに、村 (V0) がいる年が 60 年のうちに一度でもあったか。村は「決まりで動く集落」なので、段 2 なら「集める役」がいるとみる (G7_sweep と同じ)。年は、届いた回の届いた年 (何年目か) の真ん中。
- **地域のどこかに段 3**: 村が外でもよい (計画 9. の 3 で、並べて出すと決めたもの)。
- 割合の 95% の幅は、Wilson の幅 (回が独立とみたとき)。主効果の幅は、ほかの要因の組をまぜた回の幅なので、「この組み方で平均したときの」幅。
- 戦・逃げた・崩れ・なくなった は 60 年の回数の平均。囲まれていた答え = 求めに答えたときに逃げ場がなかった割合。

## 4. 読み方 (短く)

1. **c1 の壁は、世界の形では越えられない。** G7.md 4. の 1 の「村が答えないかぎり c1 に届かない」は、埋まり・強さ・囲み・水路・日照りのどれを変えても、ほぼそのまま (村が求めず、つながりもないと、要因の水準ごとの平均で 0.4〜6.8%、組ごとでも 0〜27.5%)。まわりが村を求めないのは、まわりの集落が「いちばん弱い相手」に求める決まりで、村がいつも強いため (大きい隣を置いても同じ)。
2. **村がまわりと同じ決まりで求めるだけで、c1 は 9 割に届く。** 村に特別なことをさせなくても、「1.5 倍強いときだけ、ときどき求める」で 60 年なら 83〜96%、20 年なら 34〜54% (どちらも囲みの水準ごと)。c1 に届くかどうかは「村の人が求めると答えるか」にかかっていて、これは実験 B (LLM のくせ) と C で見ることになる。B では、v3 (弱い隣への求め) で sonnet は 18/20 が求めなかった。
3. **囲み (H1) は「逃げる手がない」ときだけ効く。** 草原を砂地にしても、求めた集落の届く範囲 (2〜4 ます) の外には、ほとんどいつも空いた住める土地が残るので、囲まれた答えは 10% にとどまり、段 3 はむしろ少し減った (住める土地が減って、集落と求めの相手が減るため【読み】)。逃げる手をなくすと、地域のどこかの段 3 は 99%、村が求めないときの c1 は 3 倍 (12.8% → 35.8%)。Carneiro の囲みの向きと合うが、この模型では「土地が狭い」より「逃げられない」がそのまま効く形になっている。
4. **案 d は c1 を動かすが、中身は小さい。** 村が求めなくても 37.7% (逃げる手なしなら 64.8%) に届くが、その 9 割は 5〜10 人の家の集落どうしの貢ぎで作った段で、村のほかは真ん中で 3 集落・24 人。物差しの段の数え方 (下が 2 つ以上なら段が上がる) は、まとまりの人数を見ないので、こういう小さな段 3 も数える。c1 の数え方を案 d とあわせて変えるなら、人数の下限などを足すかを先に決める必要がある【読み】。
5. **水路の代わり (H4) は、この形では国を作る向きに効かない。** 段 0 の川ぞいの集落の余りを減らすだけなので、人が減り、段 3 は少し減った (92.6% → 89.5%)。「みんなで造る仕事があると、まとめ役ができる」を試すには、段が上がる道 (造るために組を作る) を足す必要がある【読み】。
6. **日照りが多いと、段 3 は減る** (96.6% → 85.5%)。人が減り、逃げる回が増え、貢ぎの崩れが減る (払う相手が少ない)。「困窮が従属を生む」とは逆向き。
7. **戦はほとんど起きない。** 決まりの損のくらべでは、求められた側は払うか逃げるを選び、戦うを選ぶのは 86,400 回で 16 回。H2 は A1 では試せていない (G7_sweep.md の 4. の 4 と同じ)。
8. **G7 の 22 年で地域に段 3 ができなかったのは、見込みの範囲。** G7 に近い組で 22 年までに段 3 ができたのは 32%。

## 5. 【シ】この数をどう見るか

- この表の「段 3」「c1」は、`region.py` の決める段 D (4.D.2) で数えた【シ】の数で、王・役所・税・書いた法があったことを意味しない。D は「貢ぎのつながりの形」だけを数え、まとまりの人数・続いた年・取り立ての記録は見ない (3.5 の小さな段 3 はその例)。
- 割合は「この決まりと、この要因の組み方の中で、種を変えたときに何割で起きたか」で、史実でどれほど起きやすかったかの見込みではない。主効果は、ほかの要因を、ここで選んだ水準で等しくまぜた平均なので、水準の選び方が変われば変わる。
- 95% の幅は、種ごとの回の偶然だけの幅。決まりの数 (【仮定】の K・余り・損の式など) のまちがいによる幅は入っていない。

## 6. この表の限り

- **地域だけ**: 世界 (era2) の村は動かしていない。村は「決まりで動く集落」で、人数・蓄えは決まりの式で増減する (本物の村の畑・ききん・家の倉・人ごとの判断はない)。村の病も数えない。
- **村は人ではなく決まり**: 村の求め・答えは決まりの手だけ。LLM の村の人が「求める」「払う」「戦う」を選ぶ割合は、実験 B と A2 で見る。
- 村の家が出ていく見込み 0.25 (1 回 5 人) はどの組にも入れた【仮定】。60 年後の村は平均 103 人に減っていて、G7 の村 (84〜161 人) の範囲の中だが、出ていく量を変えた比べはしていない。
- 大きい隣は「分かれない・K で減らない」とした【仮定】。分かれる決まりのままだと、すぐに小さな集落に分かれて「大きい隣」にならないため。
- 案 d の貢ぎの量は求めと同じ形 (余りの 2 割) にした【仮定】。村を出た家が種を持って出ること (G7 ではあった) は入れていない (出た家の蓄えは 0 から)。
- 便り (4.C) はない。まわりの集落の集まり (LLM) もない。どれも決まりの手。
- 60 年・1 つの地図 (11×11)・1 つのはじめの state (5849 日目) だけ。
