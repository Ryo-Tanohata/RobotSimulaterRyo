## 3. 前もっての見込み (A1・A2・B・本物の G7 から)

1. **c1 には届かない見込み** (20 年で)。v2 で c1 に届くには、村が貢がせる集落を 2 つ以上持ち、役の人が「取り立てる」か「守る」をすることの両方が要る (C の準備の 3.)。B と本物の G7 では、sonnet と opus の代表は隣に求めなかった (B 3/40・本物 0/300)。決まりの村でも、G7 に近い束 (B0) はこの世界で 0/4。逃げ場がなくても、村より強い集落がないので、村が求められることもない。
2. **c2 は届くかもしれない** が、半分より低い見込み。本物の G7 では opus の代表が税の案 (L219) を出したが通らなかった。sonnet の代表は案を出さず、票もほとんど入れない。
3. **c3 はほぼ届かない見込み**。罰の案は本物の G7 で 0 (B では倉の多い家の席の opus だけが出した)。もめごとは食べ物が足りないときに起き、決まりの村では蓄えが 700〜1,000 日分あった。
4. **ききんは起きにくい見込み** (G7 の直しのあと。決まりの村では 15 年で 0)。起きたら、G7 のききんとくらべる。

この見込みがはずれたら (たとえば c1 に届いたら)、何が起きたかを答えからたどって書く。
