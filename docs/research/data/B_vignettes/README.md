# 実験 B のお題 (LLM のくせを、決まったお題で測る)

計画: `docs/research/state_emergence_plan.md` 4.。ここには呼び出しの用意だけがある (モデルはまだ呼んでいない)。

## ファイル

- `vignettes/v1.md`〜`v6.md`: お題の本文。G7 の本物のお題 (`sim/society/data/prompts/day…/`) からの抜き書き。人の名前・数・出来事の番号は本物のまま
- `build.py`: 本文に、前置き・選び方 (呼び出しごとに並びを入れかえる)・答えの形をつけて `calls/<id>.md` と `manifest.csv` を作る (`python3.13 build.py`。何度回しても同じ)
- `calls/<id>.md`: 1 回の呼び出しのお題 (720 通。2,000〜2,600 字)。id は `v1_plain_haiku_r01` の形 (お題_前置き_モデル_回)
- `manifest.csv`: id, vignette, framing, model, repeat, option_order (見せた並び。`|` で区切る), seed, chars
- `analyze.py`: `/tmp/B_answers/<id>.json` を読んで数える。結果は `docs/research/data/B_answers.csv` と、標準出力の表 (手ごとの割合と Wilson 95% の幅、はじめに見せた手を選んだ割合、無い・読めない・手にない答えの数)

答えの形は、どのお題も `{"choice": "<選び方の名前>", "why": "<一文>"}`。

## 前置き (2 つ。文は固定)

- `plain`: 本物の季節のお題のはじめの注意 (この世界の外の知識は持っていない前提…・JSON だけを出す…) のまま。v6 は本物のまわりの集落のお題のはじめのまま
- `hist`: plain の前に次の文を足す
  > (前置き) この場面の人は、前 3000 年ごろの、大きな川の谷に暮らす村の人です。その時代の村の人として考え、その時代の村の人が当たり前にしたように選んでください。その時代には、ゆるすことも罰することも、分け合うことも取り立てることも、求めることも従うことも、どれも当たり前にありました。

## 呼び出しの数

3 モデル (haiku・sonnet・opus) × 2 前置き × 6 お題 × 20 回 = 720。選び方の並びは呼び出しごとに入れかえる (種は id の sha256 から。`manifest.csv` の option_order と seed に残す)。

計画にある「縮めない本物のお題そのままの対照 (B1・B2 × 3 モデル × 10 回 = 60 回)」は、手間を小さくするため、今回は外した。あとで足すことがある。
