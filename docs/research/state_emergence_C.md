## 2. 結果

- **c1 (決める段 3 のまとまりに村がいる): 届かなかった。** 村の決める段は 20 年ずっと 0 (村は中心で、貢いでくる集落も、村が貢ぐ相手もない)。
- **c2 (取り立ての記録 2 年): 届かなかった。** 税の案は 0。
- **c3 (書いた罰の掟で裁いた): 届かなかった。** 罰の案は 0。もめごとはほぼみな「ゆるす」。
- **F1〜F6: どれも届かなかった。** 役の人 (取り立てる・守る) は 20 年で 0 人、まとめ役も 0。
- ただし、**最後の年 (8279 日目) に、地域のどこかに決める段 3 のまとまりができた** (いちばん上は N6。村は外)。

## 4. 読み (Claude の判断)

- **この世界と数え方なら、決まりの村は国に届く (B1 で 4 回のうち 3 回) が、LLM の村は届かなかった。** 届かなかったのは、しくみではなく、代表の選び方による。国に要る手 (役の人が取り立てる・守る / 隣に求める / 税・罰の案) を、20 年でだれも 1 回も選ばなかった。
- **opus は動くが、国の方には動かない。** opus は毎年案を出し、票で反対もするが、中身はみな「暮らしをうまく回す」決め (ヤギ・畑・住まい)。豊かで困っていない村では、税・罰・役所を作る理由が答えの中に出てこない。
- **sonnet は動かない。** 案を出さず、賛成するだけ。実験 B・本物の G7 と同じ。
- **豊かさが続いたことも効いている見込み。** 蓄えが 1 年以上あり、もめごとは小さく (数十つかみ)、ききんがない。A2 でも c3 は「食べ物が足りないとき」にしか動かなかった。
- **地域では段 3 ができた** (最後の年)。逃げ場がない世界では、まわりの集落どうしは決まりで国を作りうる (A1 と同じ向き)。村がそれに入らないのは、村がまわりよりずっと大きく、だれも村に求めないから。

## 5. 弱いところ

- 1 回だけ (種 1 つ)。同じ手順でもう 1 回回すと、ちがう道を通るかもしれない。
- はじめの state が豊かな年 (5849 日目) で、そのあとも豊かな年が続いた。苦しい年が続く世界では、ちがうかもしれない。
- モデルの割り当ては 1 通りだけ (sonnet が多い)。opus を多くした村や、haiku だけの村は見ていない。
- トークンの上限に届いたので、20 年をこえては回せない。

## 6. G8 に向けて (相談の材料)

- 国に届くかは、「村の代表が、国に要る手を自分から選ぶか」で決まる。今の LLM の代表は、豊かな村ではその手を選ばない。
- G8 を考えるなら、次のどれかが入口になる (どれも本人の決め):
  1. 村の外から押す世界 (村より強い集落がいる・苦しい年が続く) で回す
  2. 代表のモデルの割り当てを変える (opus を多くする、など)
  3. 「国」の条件を、今の村の向き (暮らしの決め・貸し) に合わせて考えなおす
