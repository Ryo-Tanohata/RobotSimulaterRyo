# 問い 1: 実際の人類史と、何が同じで何が違うのか

書いたのは Claude (2026-10-29)。本人の問い「実際の人類史とは何が同じで何が違うのか、その中でテクノロジーはどういう役割を果たしているのか、そこでの人間らしさは何か」の 1 つめ。3 つの調べのうちの 1 つ。読んだだけで、世界も記録も変えていない。

材料: `docs/society_phase/` (F・G の評価、`part2〜4.md`、`fidelity_checklist.md`、`G8.md`・`G8_heavy.md`)、`docs/research/state_emergence_*.md`、`docs/tech_tree.md`、`sim/society/techtree/plan.json`・`emerged.json`、`sim/society/HANDOFF.md`、`data/run_log.md`、`data/records/season_village.jsonl`。数は 109年の初め (13079 日目) まで。

**印**: 【文献】調べの文書が文献から引いたこと (そこに【二次】【未確認】【議論あり】とあれば、それも受けつぐ) / 【記憶】Claude の記憶だけで、確かめていない / 【仮定】Claude の読み・見込み / 【シ】このシミュレーションの記録から出た数や出来事。

**読むときの約束**: この世界の 1 年は 120 日。「思いつくまでの待ち時間」を縮めているので (`society2_phase_plan.md` の 3.)、長さは比べない。比べるのは **順番** と **どんな条件で起きたか** だけ。

## 0. まとめ (先に)

- 【シ】**村の「暮らしの道具」の道のり (定住 → 栽培 → 家畜 → 鎌・土器 → 家の倉 → 受けつぎ) は、西アジアの順とほぼ同じ**だった。ただし細かい順は、何か所かで入れかわった (土器が家より先、火がとても遅い)。
- 【シ】**「まとめる仕組み」は、史実の手前で止まった**。集まり・長老・祭りでもめごとを収め、まとめ役は出ても続かなかった。罰を払わせたことは 0、村の中の税も 0、役所も 0、戦も 0。
- 【シ】**国には「入った」が、「作らなかった」**。外から強い村に押されると貢いで国の下に入り (80年30日目)、重くなると払うのをやめて外へもどった (103年の終わり)。
- 【仮定】違いのわけは 3 つに分けられる。(1) 作る側の設計 (いつ何が使えるか・置いた集落・便りの札・途中の直し)、(2) LLM の選び方 (ゆるす・今の決まりを変えない・困った時だけ動く)、(3) 世界の数の決まり (ただで取れる木の実・減らない壺の種など)。「国が生まれない」は (2) がいちばん大きく、「町が生まれない」は (1) と (3) が大きい。

## 2. 史実とよく合ったこと

1. **定住 → 栽培 → 家畜の順**。【シ】住まい (153 日目) → 木の実を育てる (335 日目〜) → 畑 (4年31日目) → ヤギ (4年91日目)。【文献】レバントでも、畑のない採集民の村 (アイン・マラッハ) が先で、栽培とヤギは近い時期。ただし 4. のとおり、進んだのは作る側が足した仕組み (ごみ捨て場から育つ木・夕方に取る・埋める) のあと。
2. **まず話し合い、あとからまとめ役。まとめ役は弱い**。【シ】G5 のもめごと 44 回はみな収まり、31 回は集まり。まとめ役セナの呼びかけに大人の半分以上が応じたのは 6 回のうち 2 回。【文献】Johnson 1982 の「順番の階層」、Fried のランク社会のまとめ役と同じ向き (`part3.md` 4.)。
3. **罰の掟が出ないこと自体は、ウバイド期と合う**。【文献】罰の記録はウル・ナンム (前 2100 年ごろ) から。ウバイド期に罰の証拠はない (`part3.md` 4.、E2)。
4. **記録は帳簿として生まれ、もめごとの量を確かめるのに使われた**。【シ】村は「覚えだけでは量がはっきりせず、もめごとのもとになる」と書いて板の掟を出し (L158)、板で量を確かめたもめごとは 15 回 (`part4.md` 2.)。【文献】原楔形文字の約 85% は帳簿 (Englund 2011)。
5. **封は「だれが倉を開けたか」の見張り**。【シ】L172「封のかけらで、割った家を確かめる」(E4)。【文献】サビ・アビヤドの封も、そう読む見方がある【議論あり】。
6. **黒曜石だけを遠くに求めた**。【シ】自分から交換に行った 5 回はみな黒曜石 (E6)。【文献】黒曜石は町より前から遠くへ動いた (Renfrew ほか 1968)。
7. **よそから来た人で大きくなった**。【シ】G6 で 43 → 151 人のうち 67 人がよそから。【文献・二次】ブラクも移り住んだ人で大きくなったという調べ。
8. **強い国に従い、重すぎると離れる**。【シ】G8 で村は求めにすぐ「払う」(戦う・助けを頼むは 0)。重い押しで蓄えが尽き、103年に子 12 人が亡くなると、払うのをやめ、弱った北の大きな村は求め直さなかった (E11、`G8_heavy.md` 11.)。【記憶】初期の国がふくらんではばらける形 (Marcus の「動く模型」など) や、払えない人が国の外へ逃げる話 (Scott 2017) と向きは合う。
9. **文字のない年代記**。【シ】年に名前をつけ、多くは人の死や「よそから人が加わった」(E1)。【文献】ラコタの「冬の数え」の形に近い。

## 3. 違ったこと と そのわけ

わけを 3 つに分ける。どれか 1 つに決められないものは、両方に書いた。

### 3.1 作る側の設計から来たもの (正直に書く)

- **使えるものの順は、作る側が決めた**。家族の家は G3 から、印は G6 から (part2.md 6. の 3)、数え札・封筒・板は「困りごとが起きてから使えるようになる」作り (part4.md 4.)。だから、印や数え札が史実より遅いこと、記録が困りごとのあとに来ることの一部は、設計のとおり。
- **ほかの村は G6 まで世界になかった**。交換が「遅い」のはこのため。G6 のよその村は 12〜17 人と小さく、出せる物はほぼヤギだけ (part4.md 4.)。**町が生まれなかったのは、村の判断より世界の作りによるところが大きい** と評価済み (part4.md 8.)。
- **国はまわりから生まれるのを待つ** (本人の答え 3。`society2_extension_plan.md`)。G7 ではまわりに 18 集落を置き、G8 では強い集落 (北の大きな村、203 人) と逃げ場なしを置いた。**国の下に入ったのは、この置いた押しのおかげ**。G7 では、村がまわりより強すぎて、村が自分から求めないかぎり段 3 に入れない「壁」があった (G7.md 4. の 1、A1)。
- **便りの札 (史実のヒント)** が 1 年に約 1 通届いた。青銅の刃 (E10) は札が運んできた。G9 では「交換しなくても遠くの商人が来る」ように変えた (本人の決め 2026-10-29)。
- **途中の直し・やり直し**。Society 1.0 では全員の飢え死に 2 回のあと戻してやり直し、秋の実り 2 倍・住まいの手間半分・ごみ捨て場から育つ木・夕方に取る/埋めるを足した (`society1_overview.md`)。G5 では罰の条件を外し「まとめ役なしの道」を足した。G7 では 53年90日目に時を戻し、代表のモデルを haiku から sonnet・opus に変えた。**G7 のききんの多くは、お題と仕組みのまちがいから** (G7.md 6.)。史実の飢饉とそのまま比べられない。
- **閉じ方**。G6・G7・G8 はどれも、条件がそろわないまま本人の決めで閉じた。

### 3.2 LLM の選び方から来たもの

- **今やっていることを上手にするが、新しいことを試さない**。【シ】Society 1.0 で「屋根を作ろう」の掟が 20 本以上通っても、建てに行ったのは 5 日だけ。火は 6年まで使わなかった。新しい行動は「夕方にその場でできること」として出したときに選ばれた (`society1_overview.md` 5.・6.)。
- **目の前の困りごとに 1 つずつ答える**。【シ】刈りきれない → 鎌、虫やネズミ → 土器、雨に濡れる → 家。【仮定】これが「土器が家より先」の順を作った一因 (part2.md 4.)。史実の順は、ゆっくり何百年もかけて別のわけで決まった。
- **ゆるす・罰を嫌う・決まりを変えない**。【シ】G7 のもめごと 177 回のうち 176 回が「ゆるす」。税の案はききんの 1 季節に 4 本出て、みな通らなかった (E8)。G8 の 34 年も、重い押しで子が亡くなっても、税・罰・役の人の案は 0。実験 B では sonnet は「今の決まりを変えない」、opus は倉の多い家の席なら罰を出すが、本物の村の opus は暮らしの決めしか出さなかった (`state_emergence_B.md` 0.、`state_emergence_C.md` 4.)。
- **足りていると、何もしない**。【シ】G6 は「足りている村は交換しない」(E6)、G7 の豊かな 6 年は案が出ても通らなかった。【仮定】史実でも「余りがあっても王を作らない」ことはある (Graeber & Wengrow 2021、Boehm 1999【文献・議論あり】)。ただ、LLM の人のよさ (H8) と分けられない。
- **ききんには「出ていく」で答えた**。【シ】G7 で 62 人が村を出て、7 家は倉の種を持って出た。【文献】逃げ場があると従わない (Carneiro 1970 の囲みの説の裏、Hirschman 1970)。ここは史実と合う面もある。
- **外に閉じる**。【シ】G7 で、よその群れを 12 回断った (E7)。計画の木になかった道。

### 3.3 世界の数の決まりから来たもの

`fidelity_checklist.md` が数で示した。

- **夕方の木の実がただで取れ、埋めた木の実が 20 日で実る** → 食べ物の 37% が働かずに手に入る (1.)。だから食べたのは木の実が 77〜94% で、草の種は 0.6〜19% (G1〜G6)。【文献】最初の農耕民は穀物を主に食べ、麦作りは採集より得ではなかった (Bowles 2011)。この村は向きが逆。
- **壺の種が減らない** → 種がたまり続け、持ち物のジニ係数が 0.73 など高くなった (2.)。【文献・未確認】農耕・牧畜の人びとの財産のジニは平均 0.4〜0.5。刈り入れの決まり (よその家の人が刈っても畑の持ち主の倉に入る) も差を作った (part3.md 4.)。土地や犂が差を作った史実とは、もとが違う。(G7 から壺の種は 1 年 3% へる直しが入った)
- **子の生まれる数 8.35** は農耕民の幅より高い (7.)。それでも人が増えたのは、多くがよそから来た人 (G1 で 11 人のうち 8 人)。【文献】新石器の人口転換は、生まれる子が増えたことによる (Bocquet-Appel 2002)。
- **牛がいない・水路や神殿の仕組みがない** → 犂・水路・神殿は起きようがない。

【仮定】まとめると、**「必要が出れば制度が自然に生まれる」とは、この村では言えなかった**。ききんでも、重い貢ぎでも、豊かさでも、村は「ゆるす・出ていく・払うのをやめる・ヤギをつぶす」で答えた。国の形 (税・記録の役・罰) は、決まりで選ばせれば育つ世界なので、止めたのは主に代表の選び方 (A2 と C のくらべ)。

## 5. 気をつけること

- **1 回の走りだけ**。乱数の種も 1 つ。G7 の前半と後半は、モデル・お題・仕組みが変わっていて、どれが効いたか分けられない (G7.md 3.)。
- **やり直しのある歴史**。全員が飢え死にすると戻してやり直す決まりがあり、Society 1.0 で何度も使った。史実には「やり直し」はない。
- **LLM は人類史を知っている**。板の掟 (L158) や 1 割の利子 (E9)、すぐ「払う」ことは、経験からでなく **知識の再現** かもしれない (G7_design.md 4.D.6 の心配)。逆に、知っているのに税・王を選ばないのは、【仮定】今のモデルの「人のよさ」の向き (実験 B の H8) が、知識より強く出ているのかもしれない。
- **体の時間は縮めていない**。1 年で 1 歳。だから G5 の 15 年は 1 世代にも足りず、史実の約 2,000 年 (数十世代) とくらべると、**世代をこえて積み重なること** (家の格・受けつぐ富・しきたり) は起きにくい。【仮定】まとめ役が続かず、身分も受けつがれなかったのは、これも効いている。
- **大きさが違う**。町の目安 50 人は、ブラクの推定の 1/55〜1/110。国も本物よりずっと小さいままの見込み (`society2_extension_plan.md`)。
- **物差しは西アジア 1 つ**。土器は東アジアではずっと早い (大平山元 I 約 1.65 万年前【文献】)。「史実の順」も 1 つではない。
- **読みは Claude の読み**。【仮定】の行は、ほかの読み方もありうる。
