## 1. 問い

1. **そろいすぎ:** LLM の答えは、人どうしよりそろっているか (ばらつきが小さいか)。人間の主成分の形 (第 1 主成分の大きさ) とくらべて、どう違うか。
2. **規範に寄る:** LLM の答えは、論文の「常識的な回答の予想」(規範の答え) にどれだけ近いか。規範より厳しいか、ゆるいか。
3. **人格:** ビッグファイブの人格を持たせると、ばらつきは増えるか。
4. **本音:** 「まず本音を書いてから選ぶ」と、グレーゾーンの問いで「問題でない」の側へ動くか (修士論文の「人は条件を見て調整する」に近づくか)。
5. **5 つの意識:** 人間の 5 つの主成分 (権利・所有・情報・プライバシー・自己責任) の上位の問いは、LLM の主成分でもいっしょに出るか。

## 4. 人格の作り方 (`personas.py`。種 20261029、何度動かしても同じ)

- **ビッグファイブ:** 外向性・協調性・誠実性・神経症傾向・開放性を、1 人ずつ標準正規分布の z で引く。
  - 5 つの間の相関は **0 (独立)** にした。大人の 5 つの相関の表としては、メタ分析 van der Linden, te Nijenhuis & Bakker (2010)「The General Factor of Personality: A meta-analysis of Big Five intercorrelations and a criterion-related validity study」Journal of Research in Personality 44(3), 315–327 (doi:10.1016/j.jrp.2010.03.003。212 標本・約 14 万人) があることは確かめた【文献】。しかし、このセッションでは表の数そのものを読めなかった (表の載ったページに届かなかった)。確かめていない数を入れるより、独立にしたほうが正直なので、そうした。表の数が確かめられたら、`personas.py` の `CORR` に入れれば同じ手順で引ける (そのときは人格がみな変わるので、実験の前に限る)。
  - z は人の中の位置なので、平均と SD (尺度ごとの点) は要らない。プロンプトには数ではなく、5 段階の言葉で書く: とても低い (下から 10% 未満) / 低め (10〜30%) / ふつう (30〜70%) / 高め (70〜90%) / とても高い (90% より上)。高め・低めのときは、短い説明をつける (`personas.py` の `DESC`)。
- **MBTI ふうのラベル (見せるためだけ):** z の符号から 4 文字と -A / -T を決める。外向性 → E/I、開放性 → N/S、協調性 → F/T、誠実性 → J/P、神経症傾向 → -T/-A。向きは McCrae & Costa (1989) の、MBTI の 4 軸とビッグファイブの相関に合わせた【記憶】。**プロンプトには出さない** (分析にも使わない)。
- **年齢・性別・住む所【仮定】:** 修士論文の 84 人は知り合いを中心に集め、10 代以上だったことしかわからない。だから簡単な仮定で引く。
  - 年齢: 18〜19 歳 5%、20 代 20%、30 代 25%、40 代 25%、50 代 15%、60 代 10% (年代の中は一様)。
  - 性別: 男性・女性 半々。
  - 都道府県: 2020 年の国勢調査の人口 (およその数)【記憶】の重みで引く。
  - みな「パソコンを持ち、インターネットにつないでいる」とする (2016 年の調査で聞いた属性)。
- できたもの: 100 人。男性 52・女性 48、年齢 18〜67 歳。名前など、本物の人の情報は入れない。

## 5. プロンプトの文面 (`prompts.py`。1 人 1 枚、`prompts/<ID>.md`)

- `survey_workflow.js` が 1 人に 1 つの agent を立てる。agent は紙を読み、スキーマの形で答えを返す。台本はファイルを書かず、答えをまとめて返す。メインのセッションが `save_answers.py` で `answers/<ID>.json` に分ける。

## 7. 分析 (`analyze.py`。numpy と matplotlib だけ)

1. **問いごと:** 条件ごとに、平均・SD (n−1)・いちばん多い答えの割合。規範の数との差 (絶対値の平均と、符号つきの平均)。人ごとの平均点 (54 問の平均 = 厳しさ) の SD。
2. **主成分分析:** 修士論文と同じく、問いを標準化して (R の `prcomp(scale.=TRUE)` と同じ。相関行列の固有値・固有ベクトル) 行う。C1・C2・C1+C2 (200 人) で。SD が 0 の問いは標準化できないので除き、除いた数を書く (割合は使った問いの数で割る)。
   - 固有値・寄与率・累積。50.3% (人間の 5 つの固有値から計算した累積) と 81% (印刷) に届く主成分の数。
   - **でたらめの基準:** 答えが互いに無関係な 84 人 × 54 問 (正規乱数、200 回の平均) の固有値 (平行分析)。第 1 固有値は約 3.0。LLM の固有値がこれと同じくらいなら「形がない」。
   - 固有ベクトルの表 (主成分 1〜10)。
3. **一致の点 (H5):** 人間の主成分 k ごとに、上位 5 問 S_k と符号 s_i を使う。
   - LLM の主成分 j = 1〜10 のそれぞれで、符号をそろえた和 |Σ_{i∈S_k} s_i v_ji| を出し、いちばん大きい j* を「いちばん合う主成分」とする (主成分の順番は問わない)。
   - **重なり** = j* の |固有ベクトル| の上位 5 問と S_k の共通の数 (0〜5)。**符号の合う割合** = S_k の問いのうち、j* の向きをそろえたときに符号が人間と同じものの割合。
   - **偶然の基準:** でたらめに選んだ 5 問・でたらめな符号で同じ手順を 2,000 回くり返し、重なりがそれ以上になる割合を p とする (でたらめの重なりの平均は 1 前後)。
   - 5 つの主成分すべてを、C1・C2・C1+C2 のすべてで書く (よいものだけを選ばない)。
4. **ブートストラップ:** 人を引き直して (1,000 回、一致の点は 300 回) 95% の区間を出す。第 1 主成分の割合は、人間と人数をそろえるため、引き直した中から 84 人で出す。H3 は C0 と C1 を別々に引き直す。H4 は対 (同じ人格) ごとに引き直す。
5. 図: 問いごとの平均と規範 / 問いごとの SD / 固有値の並び (人間・でたらめの基準といっしょ) / グレーゾーンの C1 と C2。見出しは英語と日本語。

検定をたくさん並べるので、偶然の当たりがありうる。主な判定は 8. の線だけで行い、ほかは「探索」と書く。多重比較の補正はしない (そのぶん、区間をそのまま見せる)。

## 8. 仮説と決めの線

| | 仮説 | 数 | 支持とする線 |
|---|---|---|---|
| H1a | 人格なしの LLM の答えは、そろいすぎる | C0・C3・C4 それぞれの、問いの SD の平均 | **0.5 未満** |
| H1b | LLM の主成分の形は、人間と違う | C1・C2・C1+C2 の第 1 主成分の割合 (84 人に引き直した 95% 区間) | 区間が **0.268 をふくまない** |
| H2 | 人格なしの LLM の答えは、規範の答えに近い | C0・C3・C4 の、規範との差 (絶対値) の平均 | **0.5 未満** |
| H3 | 人格を持たせると、ばらつきが増える | 問いの SD の平均 C1 − C0 (95% 区間) | 区間の下が **0 より大きい** |
| H4 | 本音を先に書くと、グレーゾーンの問いで「問題でない」へ動く | 対ごとのグレーゾーン 14 問の平均の差 C2 − C1 (95% 区間) | 差が **−0.2 以下**で、区間の上が **0 未満** |
| H5 | 人間の 5 つの主成分の上位の問いは、LLM でもいっしょに出る | 人間の主成分ごとの重なりと偶然の p (C1 を主に) | 重なり **3 以上**かつ **p < 0.05** を「再現」とし、**5 つのうち 3 つ以上**再現なら支持 |

線の決め方【仮定】:
- **H1a の 0.5:** 人間の SD は表にないので、人とは直接くらべられない。5 段階の問いで人の答えの SD はふつう 0.8〜1.3 くらい【記憶】。0.5 未満なら、多くの人が同じ答えか隣の答えを選んでいることになる。
- **H1b の 0.268:** 人間の pc1 の割合 (固有値から)。人間の pc1 は 54 問みなが同じ向き (−0.18〜−0.19 の問いが並ぶ) で、「どれも問題だと思うかどうか」の一般の厳しさに見える【仮定】。
- **H2 の 0.5:** 選択肢の半分の幅。規範は論文の予想で、人の平均ではない。人の平均がないので、H2 は「LLM が規範にどれだけ近いか」だけを言い、「人より近いか」は言わない (元データが使えるようになったら足す)。
- **H4 の −0.2:** 14 問の平均で選択肢 1 段の 5 分の 1。小さすぎる動きは「動いた」と言わない。グレーゾーン以外の 40 問の差も出し、差の差 (グレーゾーン − ほか) の区間が 0 未満なら「グレーゾーンだけの動き」、そうでなければ「全体がゆるくなった」と書く。
- **H3b (探索):** C1 の人ごとの平均点 (厳しさ) と、ビッグファイブの 5 つの z の相関を出す。線は決めない。

**結果が何を意味するか:**

| 結果 | 読み |
|---|---|
| H1a・H2 を支持 | 人格なしの LLM は、1 人の「よい答え」をくり返す。村の村人がそろって「ゆるす」を選んだことと同じ向き。人の物差しとしては、そのままでは使えない |
| H1a を支持しない | LLM にも、呼ぶたびのゆれがかなりある (村のそろい方は、お題や前の例のせいかもしれない) |
| H2 で規範との差の符号が + | LLM は論文の予想より厳しい (「どれも問題」と言いがち)。− ならゆるい |
| H3 を支持 | 人格でばらつきは作れる。H1b・H5 と合わせて、そのばらつきが人間の形 (5 つの意識) を持つかを見る |
| H3 を支持し、H5 を支持しない | ばらつきは増えたが、人間と違う形 (人格の書き方そのものに引っぱられた形など)。人格の与え方を変える必要がある |
| H4 を支持 (グレーゾーンだけ) | 本音を先に書かせると、人が「条件を見て調整する」ところに近い動きが出る。論文 2 の「欲求 → 規範 → 調整」の村人のしくみ (E1) を試す意味がある |
| H4 を支持しない | 本音を書かせても答えは変わらない (しつけが強い)。本音そのものが「よい答え」になっていないか、本音の文を読む |
| H5 を支持 | 問いの意味の近さ (どの問いが同じ仲間か) は、LLM も人間と同じに持っている |
| 第 1 固有値がでたらめの基準 (約 3.0) とほぼ同じ | LLM の人どうしの違いに、まとまった形がない (人格がばらつきの雑音にしかなっていない) |

## 9. 答えがない・形が違うときの扱い

- スキーマに合わない答え・ID の違う答え・答えがない (断った・止まった) ときは、**1 回だけ聞き直す**。それでもだめなら「欠け」として、その人を分析から除く (一部の問いだけ使うことはしない)。
- 欠けの数を、条件ごとに書く。聞き直した ID も書く。
- 欠けが条件の 1 割をこえたら、その条件の結果に「欠けが多い」と書き、断った理由 (agent の返した文) を読んで報告する。断ること自体を、LLM のくせとして記録する。
- C2 で本音が空・「答えられない」などの数も書く。

## 11. 限界

- **人間の側は、表 3 の数だけ。** 人の問いごとの平均・SD・相関がないので、H1a と H2 は人と直接くらべられない (決めの線は仮定)。表 3 の累積寄与率は固有値と合わない (2.)。元データが使えるようになったら、同じ `analyze.py` に人の答えを足してくらべ直す (そのときは「変えたこと」に書く)。
- **人数:** 人間 84 人・LLM 100 人で、54 問の主成分分析をする。人数が少ないので、固有ベクトルの上位の問いは、引き直しでかなり入れかわりうる (一致の点の区間で見る)。
- **時代:** 調査は 2016 年。CD・DVD・レンタルビデオ・チェーンメールなど、いまでは少ない場面がある。LLM はいまの知識で答える。人の答えも、いま聞けば違うかもしれない。
- **LLM が似た調査を見たかもしれない:** 著作権・情報モラルのアンケートは多いので、「よい答え」を覚えている見込みがある。修士論文そのものは公開されていない見込みが高い【仮定】。
- **呼び方:** API を直接呼ぶのではなく、Claude Code の Workflow の agent として呼ぶ。agent のしくみの文 (道具・ふるまい) が答えに影響しうる。温度も決められない。
- **人格:** ビッグファイブの相関を 0 にした (4.)。年齢・住む所の分布は仮定。人格を言葉で書くので、LLM が言葉に強く引っぱられる (誇張する) 見込みがある。
- **日本語:** 紙はみな日本語。答える LLM の日本語の読み方が、結果にまざる。
- **規範の答え** は論文の書き手の予想で、正解ではない。A03 の 1.5 は仮定。
