## 1. 問い

1. **席で変わるか:** 自分の家が損をしたもめごと (言い出した家) と、かかわらないもめごとで、裁き (ゆるす / つぐなう) が変わるか。(修士論文: 人は「自分を主体に、条件を見て」決める。`part3` の物差し (a))
2. **まわりの様子で変わるか:** 「みんながやっている」「払わされた家はいない」を事実として見せると、自分の家を先にする手 (家の倉を持つ) が増えるか。罰・税の案は増えるか減るか。(修士論文の「はみ出しやすい時」。実験 2 の H8)
3. **立場で分かれるか:** 持ち物のある家と、何も持たない家で、答えが分かれるか。(修士論文の「自分が弱い立場」。実験 2 の H9)
4. **人ごとにばらつくか:** 同じ集まりで、代表の答えが今よりばらけるか。(`part3` の物差し (c)。実験 2 の H10・H11)
5. **条件で変わるか:** 村の蓄えが少ない集まりと多い集まりで、答えが変わるか (少ないと自分の家を守り、多いと戻るか)。(`part3` の物差し (b))

## 2. 村で「はみ出す」ことができる手 (今の答えの形で)

世界の決まりは変えないので、使えるのは今の答えの形にある手だけ。【シ】(`era2.py`・`g7.py` を読んだ)

| 修士論文の考え | 村の手 (答えの欄) | 村の人が選べるか |
|---|---|---|
| 人のものを取る (倉から取る・村の蓄えから多く取る) | なし。ひどく空腹の人が、村の蓄えにも自分の家の倉にもないとき、よその家の倉から **自動で** 取る (`era2._steal`)。村の蓄えから多く取るのも、毎日の食べ物の出し入れ (自動) | **選べない** (世界の決まり)。もめごとの数として、結果だけを見る (探索) |
| 自分の家を先にする | 家の倉を持つ (keep: 刈った草の種を村の蓄えでなく家の倉に入れる)・家の印を作る (seal)・家の倉を出さない (share を書かない)・家ごとに村を出る (leave) | 選べる |
| 取った人を責める / ゆるす (所有意識) | もめごとの裁き (judge)・裁きの方針 (judge_rule): つぐなう / ゆるす | 選べる |
| 決まりを作る (超自我) | 掟の案 (proposal)。罰 (penalty)・税 (tax) をつけられる。票 (votes)・村の蓄えの封 (seal_store) | 選べる |
| 借りたら返す | ほかの村が村に返しに来る (自動)。村がほかの村に貸すときの上乗せ (利子) | 返す・返さないは **選べない**。上乗せは選べる |
| よそ者を入れない | 受け入れの方針 (accept_rule) | 選べる |

だから「倉から取る・借りたものを返さない」は、村の人の **選び** としては測れない (12. の限界)。測るのは、上の「選べる」手と、そのあとの世界の数 (探索)。
新しい手 (たとえば「よその家の倉から取る」を答えで選べるようにする) は、世界の決まりを変えるので、この実験には入れない (14. の問い 5)。

## 12. 限界

- **村の人が「取る」を選べない。** 倉から取る・村の蓄えから多く取るは、世界の決まりで自動に起きる。測れるのは、家の倉・裁き・掟・票などの「選べる手」と、そのあとの世界の数だけ。
  借りたものを返すかどうかも、村の人の選びではない。修士論文の「はみ出す行い」そのものではなく、それをめぐる判断と、家を先にする手を見ている。
- **まわりの様子は、その日の事実だけ。** 実験 2 のように両方の側をくじで分けられない。A2 の効き目は「事実を見せた」効き目。3 つの様子 (みんな・払わされない・封) を分けることもできない。
- **写しは少ない。** おすすめの案では、組ごとに 1 つ。ゆれの目安は、くらべる組の 2 つ (A0 と H0) の差だけ。H0 は 1 日前 (2026-10-29) に答えたもので、モデルの中身が同じとはかぎらない。
