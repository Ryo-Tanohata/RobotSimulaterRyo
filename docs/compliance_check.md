### VOICEVOX ソフトウェア利用規約 (要点)
- 商用・非商用問わず利用できる
- 作成した音声を使うときは、各音声ライブラリ (ずんだもん) の規約に従う
- 音声の利用を他者に許諾する場合は、その人にも規約を守らせる
- 禁止: ソフトウェアの無断再配布、逆コンパイル・リバースエンジニアリング、製作者や第三者に不利益をもたらす行為、公序良俗に反する行為
- VOICEVOX を利用したことがわかるクレジット表記が必要

### ずんだもん 音源利用規約 (要点)
- 商用・非商用ともに利用できる
- クレジット表記が必要 (例: `VOICEVOX:ずんだもん`)。動画サイトでは説明画面や動画内のクレジットなど、見にいけばわかる場所に書く
- 禁止: 公序良俗に反する利用、政治・宗教活動や特定の個人・団体を非難・応援する目的、情報商材、**意図的な嘘やフェイク (誤解を招く内容)**、風俗営業など、反社会的勢力の利用
- クレジットを書かない商用利用は有料契約
- イラストの利用は別のガイドライン

## 3. 公開先 (GitHub) について

- GitHub の規約で、合成音声を使った動画をリポジトリに置くことや、AI で作った内容であることの表示を求める規定は、Claude の知る限りない
  (この環境から規約のページを開けなかったため、最新の文面は未確認)
- 念のため、公開ページの入口とアプリに「ナレーション: VOICEVOX:ずんだもん」(合成音声であることがわかる表記) を書いた
- YouTube・SNS などに動画を載せる場合は、その公開先の「合成・改変コンテンツの表示」のルールを確認し、説明欄にも「VOICEVOX:ずんだもん」を書く (これは本人が投稿するときの作業)

## 5. GitHub Pages で公開すること

- このリポジトリは公開なので、GitHub Pages を無料で使える
- Pages は個人のプロジェクトの紹介に使うもので、オンラインの商売や大量の配信には使えない。今回の用途 (学習の記録とシミュレーションの表示) は問題ない
- サイズの上限 (公開サイト 1 GB) に対し、リポジトリの追跡ファイルは約 350 MB
- **Pages の有効化は本人の作業**: リポジトリの Settings → Pages → Source「Deploy from a branch」、ブランチ `claude/physics-engine-robot-simulator-xmyxdn`、フォルダ `/ (root)` を選んで保存する
  (この環境からは Pages の設定を読み書きできない)
- 有効にした後の URL: https://ryo-tanohata.github.io/RobotSimulaterRyo/ (入口のページ `index.html`)
