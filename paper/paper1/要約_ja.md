# 論文 1 (下書き) のやさしい要約

書いたのは Claude (2026-10-29)。英語の論文 `main.tex` (PDF は `main.pdf`、20 ページ) の中身を、短く日本語でまとめたもの。

## 題

「LLM の村は人類の歴史をたどるか? — 決めておいた先史から国への順に進めた LLM の村の 108 年の観察」

## なにをした論文か

- 新しいシミュレーションは回していない。いまある 108 年分 (13079 日目まで) の記録を読んで、本物の歴史 (西アジア) とくらべた。
- くらべるのは「長さ」ではなく「順番」と「どんな条件で起きたか」。この世界の 1 年は 120 日で、思いつくまでの待ち時間を縮めているから。

## わかったこと (3 つ)

1. **暮らしの道具の順番は、歴史とほぼ同じ。社会のしくみは止まった。**
   定住 → 植物を育てる → 畑 → ヤギ → 鎌・土器 → 家の倉 → 受けつぎ、はほぼ同じ順。でも、土器が家より先、火がとても遅い、など入れかわりもあった。
   税・守らせた書いた法・役所・王・戦・町・字は、一度も生まれなかった。
2. **テクノロジーは「社会を動かすエンジン」ではなく「できることの床」だった。**
   多くは作る側の関門で開いた。土器で虫の害は 0 になり、蓄えも増えた。家の倉が開いた季節に、持ち物の差 (ジニ) は 0 から 0.84 にとんだ。
   粘土の板は、もめごとの量を確かめるのに使われたが、税には使われず、記録をつける人が亡くなると止まった。
3. **人間らしいところと、LLM らしいところがまざっていた。**
   人間らしい: 祭りで仲直り、苦しい年によそ者を断る、子のために貢ぎをやめる。
   LLM らしい: 50 年からは「つぐなう」が 0 (いつもゆるす)、人に殺された人・戦・怒りのことばが 0、「みんなで」と言うのに家の倉を出したのは 1,134 回のうち 0 回、答えが人ではなくモデル (sonnet と opus) で分かれる。

決まりで答える村 (実験 A2) や場面の問い (実験 B) を見ると、国のしくみが生まれなかったのは「仕組みの壁」ではなく、主に「LLM の代表がそれを選ばなかった」から、と読める。

## 正直に書いた弱いところ

- 走りは 1 回だけ (種 1 つ)。やり直し・とちゅうの直し・62 年からのモデルの切り替えがある。
- 多くの道具は作る側の関門で開いた。G8 の国の下に入ったのも、外から押す設計のため。
- LLM は歴史を知っているので、「知識の再現」かもしれない。
- 物差しは西アジアだけ。お題は日本語。トークンの費用が大きい。
